# 도현의 블로그
정적 블로그(GitHub Pages). 글은 `posts/글이름.md` + `posts/index.json`에 한 줄(제목·날짜·태그·시리즈·이모지).
댓글 대신 글 아래 메일 버튼(mailto / Gmail)으로 연락을 받음.

글 쓰는 방식은 STYLE.md 참고(일기장 톤).

## 화면 구조 (2026-11-25 리디자인)
- `ui.css`: style.css 뒤에 읽히는 리디자인 레이어(색·글꼴·카드·목차·코드 블록·CS 페이지). 빼면 예전 화면.
- 글 화면: 본문(최대 760px) + 오른쪽 목차(1100px 이상), 좁은 화면은 본문 위 접는 목차.
- `#/cs`: CS 공부 순서. 순서는 `cs.json`(slug 목록), 제목·요약은 index.json에서 가져옴. 없는 slug·planned는 '준비 중'.
- 용어 자동 링크: `glossary.json`(용어 → 설명 글 slug, 언어별 별칭). 글을 그릴 때 본문에서 처음 나온 곳만 링크(코드·제목·기존 링크·자기 글 제외).
- `backlinks.json`: "이 개념을 언급한 글" 목록. 새 글을 올린 뒤 push 전에 `python3 tools/glossary.py --write` 실행(검사도 같이 함).
  안 돌려도 새 글은 제목·요약 기준으로 화면에서 바로 잡히고, 본문 기준 목록만 다음 실행 때 반영된다.
- index.json·글 파일 형식은 그대로다.
