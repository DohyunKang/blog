ニューラルネットワークは「掛け算と足算を繰り返して一度曲げる」計算を層ごとに積み重ねた関数であり、バックプロパゲーションはその中にある数字（重み）をどの方向にどれだけ修正すべきか、出力側から逆算して教えてくれる手法である。

## ニューロン 1 つ

ニューロンは名前だけが大げさだが、計算自体は単純だ。入力された数字に重みを掛けて足し合わせ、バイアスを加えた後、活性化関数に通す。

```
출력 = 활성화( w1*x1 + w2*x2 + ... + b )
```

重みとバイアスが学習によって変わる数字である。学習とは何か、損失や勾配降下法とは何かについては [詳しく → 機械学習・ディープラーニングの基礎](#/post/ml-basics) に別途記述しており、ここではそれをニューラルネットワークに適用する部分のみを見る。

## 層と活性化関数

ニューロンを一直線に並べたものが層（layer）である。入力層 → 隠れ層 → 出力層へとつなぐことでニューラルネットワークが完成する。1 つの層は行列積 1 回分の計算で済む。入力が 2 つ、ニューロンが 4 つの場合、重みは 2×4 の行列となる。

しかし、活性化関数がなければ層を何層積み重ねても意味がない。行列積を 2 回行うことは、足し合わせた 1 つの行列で 1 回掛けることと同じであり、結局直線（線形）関係しか表現できない。中間に非線形な関数を挟むことで、層を積んだ意義が生まれる。

| 関数 | 形状 | 用途 |
|---|---|---|
| シグモイド | 0~1 の範囲に圧縮する | 確率のように解釈したい出力 |
| tanh | -1~1 の範囲に圧縮する | 小さなニューラルネットワークの隠れ層 |
| ReLU | 負数は 0、正数はそのまま | 深いニューラルネットワークのデフォルト |

ReLU がデフォルトになった理由は計算コストが低く、正の側では勾配が 1 なので層が深くなっても信号が減衰しにくいためとされている。

## 順伝播

入力を加え、層を順番に通り抜けて出力を得る過程が順伝播（forward）である。出力と正解を損失関数で比較して、1 つの数字（損失）に変換する。学習とはこの損失を減らす方向に重みを少しずつ修正することだ。

問題は重みが数千万〜数兆個にもなり得ることである。それぞれについて「少し上げると損失はどう変わるか」を個別に計算すると、順伝播を重みの個数分だけ実行しなければならない。これを 1 つの逆算で終わらせるのがバックプロパゲーションである。

## バックプロパゲーション：後ろから掛けて戻す

バックプロパゲーション（backpropagation）の本質は連鎖律（chain rule）である。関数が f(g(x)) のように重なっている場合、x が f に与える影響は「x が g に与える影響 × g が f に与える影響」である。ニューラルネットワークは重ねられた関数の塊なので、損失から出発して層ごとに遡りながら影響（勾配）を掛けていけば、すべての重みの勾配を求めることができる。

CS231n のノートではこれをゲートが繋がった回路で説明している。各ゲートは自身の入力に対する局所勾配しか知らない。後ろから降りてきた勾配にその局所勾掛を掛けて前に渡せば終わりだ。いくつかの規則が導き出される。

- 加算ゲートは勾配をそのまま両側に渡す。
- 乗算ゲートは相対入力の値を掛けて渡す（入力値同士が入れ替わる）。
- 1 つの変数が複数の分岐で使われている場合、各分岐にわたる勾配を足し合わせる。
- 順伝播時に得た中間値を保存しておき、逆算のときに再度使用する。

最後の項目のため、学習中はメモリを多く消費する。推論では中間値を捨ててもよいが、学習はバックプロパゲーション用に保持しておく必要があるためだ。

ウィキペディアのまとめによれば、厳密にはバックプロパゲーションは勾配を求める部分のみを指し示しており、求めた勾配を用いて重みを修正するのは SGD や Adam などのオプティマイザーの仕事である。日常会話では両者を合わせて「バックプロパゲーションで学習する」と簡略化して言うことが多い。

速い理由もここにある。各層の勾配を一度だけ計算して前の層で再利用するため、重みごとに個別に再計算するよりもはるかに効率的だ。1986 年の Rumelhart, Hinton, Williams の論文がこの手法で隠れ層の学習を広めたとして引用されるが、ウィキペディアでは同様のアイデアが複数回独立に見出された複雑な歴史があると記している。

## XOR を実際に動かしてみた

XOR（2 つの入力が異なる場合のみ 1）は直線で分割できないため、隠れ層がないと解けない。numpy でしか組まない 4 つの隠れ層を持つニューラルネットワークを実行した。これは手書きのバックプロパゲーションコードである。

```python
import numpy as np
rng = np.random.default_rng(1)
X = np.array([[0,0],[0,1],[1,0],[1,1]], dtype=float)
y = np.array([[0],[1],[1],[0]], dtype=float)
W1 = rng.normal(0, 1, (2, 4)); b1 = np.zeros((1, 4))
W2 = rng.normal(0, 1, (4, 1)); b2 = np.zeros((1, 1))
sigmoid = lambda z: 1 / (1 + np.exp(-z))
lr = 1.0
for step in range(5001):
    # 순전파
    h = np.tanh(X @ W1 + b1)
    p = sigmoid(h @ W2 + b2)
    loss = np.mean((p - y) ** 2)
    # 역전파: 출력 쪽에서 거꾸로
    dp = 2 * (p - y) / len(X)
    dz2 = dp * p * (1 - p)            # 시그모이드 미분
    dW2 = h.T @ dz2; db2 = dz2.sum(0, keepdims=True)
    dh = dz2 @ W2.T
    dz1 = dh * (1 - h ** 2)           # tanh 미분
    dW1 = X.T @ dz1; db1 = dz1.sum(0, keepdims=True)
    # 경사하강법
    W1 -= lr * dW1; b1 -= lr * db1; W2 -= lr * dW2; b2 -= lr * db2
    if step % 1000 == 0:
        print(step, round(float(loss), 4))
print(np.round(p, 2).ravel())
```

実行結果(numpy 2.5.4, Python 3):

```
0 0.24
1000 0.0008
2000 0.0003
3000 0.0002
4000 0.0002
5000 0.0001
[0.   0.99 0.99 0.01]
```

損失は 0.24 から 0.0001 まで低下し、出力が [0, 1, 1, 0] に収束した。バックプロパゲーションのコードが正しいか数値微分でも確認した。重みをわずかに変えて損失の変化を計測すると -1.2166e-05 で、バックプロパゲーションで求めた勾配は -1.2169e-05 でほぼ一致した。手書きのバックプロパゲーションコードはこのような対照を行うことで安全だ。

面白かったのはシードを 0 にした場合である。同じコードでも損失が 0.125 付近で止まり、出力が [0.01, 0.5, 0.99, 0.5] で固まっていた。初期重みが悪ければ浅い谷に陥る可能性があることを示している 셈だ。シード 1〜4 はすべて解けた。

<details>
<summary>バックプロパゲーションのコードを一行ずつ解説すると</summary>

損失は $L = \text{mean}((p - y)^2)$ であり、$p = \sigma(z_2)$、$z_2 = h \cdot W_2 + b_2$、$h = \tanh(z_1)$、$z_1 = X \cdot W_1 + b_1$ である。損失関数に対して逆方向に層ごとに微分していく。

1. $dp = \partial L / \partial p = 2(p - y) / N$。二乗誤差の微分である。
2. $dz_2 = dp \cdot p(1 - p)$。シグモイド関数の微分は $\sigma(1 - \sigma)$ であることを用いる。
3. $dW_2 = h^\top \cdot dz_2$。$z_2 = h \cdot W_2$ であるため、$W_2$ に関する勾配は $h$ を掛けた形になる。これは乗法ゲートが相対的な入力に乗算して渡すという規則通りである。
4. $dh = dz_2 \cdot W_2^\top$。同じ乗算において $h$ 側へ向かう勾配である。
5. $dz_1 = dh \cdot (1 - h^2)$。$\tanh$ の微分は $1 - \tanh^2$ である。
6. $dW_1 = X^\top \cdot dz_1$。最初の層も同じ構造となる。

バイアスの勾配は加算ゲートなので勾配をそのまま受け取り、4 サンプル分の和になる (`sum(0)`)。各行は「後ろから来た勾配 × そのゲートの局所勾配」である。
</details>

## よくある誤解

- 神経ネットワークが脳を模倣したものであるという話は名称の由来に過ぎず、実際の計算は上記の行列積と非線形関数によるものである。
- 逆伝播は学習アルゴリズム全体ではなく、勾配を求める部分であり、修正を行うのはオプティマイザーである。
- 層を多く積み重ねるだけでは必ずしも良くなるわけではない。活性化関数を誤って選んでしまうと、勾配が層を通過するにつれて小さくなったり大きくなったりして学習が成り立たないことがある。そのため ReLU や残差接続などの仕組みが登場した。
- 「神経ネットワークは万能近似器である」というのは、理論上十分大きな場合であれば任意の関数を模倣できるという意味であり、学習がうまくいくという保証にはならない。上記のシード 0 の例のように学習に時間がかかることもある。
