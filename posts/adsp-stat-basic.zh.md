ADsP 第二科目的前半部分涵盖了如何抽取样本、以何种尺度读取数值、如何用单个数字进行概括，以及如何据此推断总体。随后出现的假设检验和回归分析均建立在此基础之上。

## 一览无余的流程

| 步骤 | 问题 | 核心术语 |
|---|---|---|
| 抽样 | 无法调查全部时如何抽取部分 | 简单·系统·分层·整群 |
| 尺度 | 数值属于何种类型 | 名义·序数·区间·比率 |
| 描述统计 | 如何将数据概括为几个数字 | 平均数·中位数·方差·四分位数 |
| 概率分布 | 数值以何种形态分散 | 正态分布·标准化 |
| 推断 | 如何用样本描述总体 | 点估计·区间估计·标准误 |

## 抽样

由于调查整个总体成本高昂或不可行，因此只抽取部分（样本）。考试中常涉及四种方法的区别。

| 方法 | 如何抽取 | 区分要点 |
|---|---|---|
| 简单随机 | 每个个体被抽中的概率相同 | 不分组或不排序，直接从总体中抽取 |
| 系统抽样 | 按顺序排列后，从随机起点开始每隔 k 个抽取一个 | 固定间隔 |
| 分层抽样 | 将总体分为若干组（层），然后在每层中抽取样本 | 所有层都包含在样本中 |
| 整群抽样 | 直接抽取整个群体并调查其内部情况 | 抽取的是群体而非个体 |

分层和整群抽样都涉及分组，容易混淆。分层抽样是从所有组中分别抽取部分样本，而整群抽样是仅选择部分群体进行调查。整群抽样虽然能降低调查成本，但若要达到相同的精度，通常需要更大的样本量。

[详见 → 分析方法论](#/post/adsp-methodology) 中关于数据准备的步骤，结合后续内容即可理清顺序。

## 尺度

将数值类型分为四个层级，越往下可进行的计算越多。

| 尺度 | 含义 | 示例 | 可计算的统计量 |
|---|---|---|---|
| 名义 | 仅有名称，无顺序 | 血型、性别 | 众数 |
| 序数 | 有顺序但不知间隔 | 排名、非常同意~非常不同意 | 中位数、众数 |
| 区间 | 间隔相等，无绝对零点 | 摄氏温度、年份 | 平均数等 |
| 比率 | 间隔相等且有绝对零点 | 重量、长度、时间 | 平均数等，可解释比例 |

区间和比率的区分在于零点的含义。摄氏 20 度并非 10 度的两倍温暖，因为 0 度并不代表“无”。而重量的 0 代表真正的“无”，因此可以说 20kg 是 10kg 的两倍。

考试中会给出示例并要求判断属于第几类尺度。若难以区分是序数还是区间，可先问“间隔是否相等”。例如满意度 5 点量表中的“一般”与“满意”之间的间隔，并不保证等于“不满”与“一般”之间的间隔，因此属于序数尺度。

## 描述统计

对收集到的数据进行数字概括的工作。分为两类：

- 集中趋势：平均数、中位数、众数
- 离散程度：方差、标准差、极差、四分位距（IQR）

平均数易受异常值影响，而中位数受影响较小。因此，像收入这样向右偏斜的数据，其平均数通常大于中位数。

标准差是方差的平方根，因此单位与原数据一致。变异系数（标准差 / 平均数）用于比较不同单位数据的离散程度。

四分位数是将数据按大小排序后取 25%、50%、75% 位置的值；IQR = Q3 − Q1。箱线图（箱形图）即基于此绘制，考试中常考查箱线图中中间线代表中位数，以及箱体外延伸的“须”末端点可能是异常值候选。

<details>
<summary>用小数据集亲自计算（用 Python 验证）</summary>

使用 8 个数据 `[2, 4, 4, 4, 5, 5, 7, 9]` 进行计算。总体方差除以 n，样本方差除以 n−1。

```python
import statistics as st, math
x = [2, 4, 4, 4, 5, 5, 7, 9]
print(st.mean(x), st.median(x), st.mode(x))
print(st.pvariance(x), st.pstdev(x))
print(st.variance(x), round(st.stdev(x), 3))
print(st.quantiles(x, n=4, method='inclusive'))
```

运行结果如下：

| 项目 | 值 |
|---|---|
| 平均数 / 中位数 / 众数 | 5 / 4.5 / 4 |
| 总体方差 / 总体标准差 | 4 / 2.0 |
| 样本方差 / 样本标准差 | 4.571 / 2.138 |
| Q1 / Q2 / Q3 | 4.0 / 4.5 / 5.5 |

同一组数据，除以 n 或 n−1 会导致方差分别为 4 和 4.571。当用样本估计总体方差时，应使用除以 n−1 的样本方差。
</details>

## 概率分布

概率分布表示随机变量取各值的概率。若取值可数则为离散型，若连续则为连续型。

- 离散：二项分布（n 次试验中成功的次数）、泊松分布（一定区间内事件发生的次数）
- 连续：正态分布、t 分布、卡方分布、F 分布

正态分布是以均值为中心、左右对称的钟形曲线。其形状由均值和标准差两个参数决定。均值为 0、标准差为 1 的正态分布称为标准正态分布；将任意值 x 转换为 z = (x − 均值) / 标准差的过程称为标准化。

计算发现，在标准正态分布中，−1 与 1 之间的概率为 0.6827，而两侧各保留 5% 的临界值为 1.96。考试中要求记忆"±1σ 约 68%，±2σ 约 95%，±3σ 约 99.7%"的原因正是这些数值。值得注意的是，精确对应 95% 的值是 1.96 而非 2，这一事实也直接应用于区间估计中。

t 分布、卡方分布和 F 分布的名称与用途总是成对出现。详细内容可参考 [假设检验](#/post/adsp-hypothesis)，其中按检验方法进行了分类介绍。

## 估计

估计是指用样本数据去推断总体参数（population parameter）的过程。

| 类型 | 内容 | 示例 |
|---|---|---|
| 点估计 | 用一个数值表示 | 样本均值为 5.2 |
| 区间估计 | 用一个范围表示 | 总体均值在 4.8~5.6 之间 |

一个好的估计量应具备以下条件：无偏性（期望值等于参数）、有效性（方差较小）、一致性（随着样本量增大趋近于真值）以及充分性。将样本方差除以 n−1 而非 n，正是为了校正偏差以满足无偏性要求。

衡量样本均值波动程度的指标是标准误。当总体标准差为 σ 时，样本均值的标准误为 σ / √n。考试常考知识点：若要将标准误减半，需将样本量扩大至原来的 4 倍。

中心极限定理指出：无论总体服从何种分布，只要样本量足够大，样本均值的分布就会趋近于正态分布。因此，即使不了解总体的具体分布形态，仍可对均值进行基于正态分布的估计与检验。

区间估计的形式为：样本均值 ± (临界值 × 标准误)。在 95% 置信水平下，若依据标准正态分布，临界值为 1.96。提高置信水平会使区间变宽，而增加样本量则会缩小区间。“95% 置信区间”的含义是：若以相同方式重复抽取多个样本并构建相应区间，则其中约 95% 的区间会包含总体参数；因此，若将其解读为“当前区间包含总体参数的概率为 95%"，则是错误的理解。
