本单元分为两部分：一是处理多变量信息的多元分析（主成分分析、多维尺度法），二是处理随时间累积数据的时序分析（构成要素、平稳性、ARIMA）。考试日程和应试费用可在官方网站查询。

## 多元分析：当变量较多时

当变量达到十个或二十个时，仅靠查看表格无法看清其结构。多元分析通过减少变量数量或将点的位置关系绘制成图来解决这一问题。本单元需要掌握的是主成分分析（PCA）和多维尺度法（MDS）。相关性与回归的基础在于 [详见 → 回归分析](#/post/adsp-regression)。

### 主成分分析 (PCA)

按照 scikit-learn 文档的描述，PCA 将数据划分为彼此正交的成分，且前面的成分尽可能多地解释方差。总结如下：

| 项目 | 内容 |
|---|---|
| 目的 | 将具有相关性的多个变量概括为少数几个新变量（主成分） |
| 主成分之间 | 相互正交，即互不相关 |
| 顺序 | 第一主成分解释方差最多，其次是第二主成分 |
| 用途 | 降维、可视化、减少多重共线性 |

这里有一个考试中的易错点。根据文档，PCA 仅通过减去每个变量的平均值来使数据居中，而不调整大小（尺度）。因此，方差较大的变量会主导成分的走向。当混合使用单位不同的变量时，必须先进行标准化（文档将此作为一般指南单独列出）。

我亲自运行过的示例如下：创建了三个变量，前两个在相同信号上叠加了噪声，使其彼此高度相似，而第三个保持独立（使用 numpy 对协方差矩阵进行特征值分解）。

| 成分 | 特征值 | 解释方差比例 | 累计 |
|---|---|---|---|
| PC1 | 4.771 | 0.933 | 0.933 |
| PC2 | 0.258 | 0.050 | 0.983 |
| PC3 | 0.087 | 0.017 | 1.000 |

如果存在相似的变量，第一个成分将占据绝大部分。因此，“保留几个成分”应根据解释方差比例的累计值来决定。特征值表示该成分所解释的方差大小，比例则是特征值除以总和的结果。

<details>
<summary>详细解析：使用 numpy 计算 PCA 的步骤</summary>

```python
import numpy as np
rng = np.random.default_rng(0)
n = 200
a = rng.normal(size=n)
X = np.c_[a + 0.3*rng.normal(size=n), 2*a + 0.3*rng.normal(size=n), 0.5*rng.normal(size=n)]
Xc = X - X.mean(0)                # 1) 평균을 빼서 중심 맞추기
cov = np.cov(Xc, rowvar=False)    # 2) 공분산 행렬
w, v = np.linalg.eigh(cov)        # 3) 고유값·고유벡터
w = np.sort(w)[::-1]
print((w / w.sum()).round(3))     # [0.933 0.05  0.017]
```

特征向量决定了成分的方向，特征值代表该方向的方差。将数据乘以特征向量即可得到成分得分。

</details>

### 多维尺度法 (MDS)

MDS 接收个体之间的相异性（距离）矩阵，并在低维空间（通常为二维）放置点，使得点之间的距离尽可能接近原始距离。这就像在地图上标注城市的位置一样。未能匹配原始距离的程度被称为压力（stress），数值越小表示拟合越好。

- **度量 MDS (metric)**：试图重现距离的实际值。
- **非度量 MDS (non-metric)**：只需匹配距离的顺序，即确保靠近的点对比远离的点对放置得更近即可。

文档指出，输入欧几里得距离的经典 MDS 会产生与 PCA 相同的结果。两者都是“从高维到低维”，但区别在于 PCA 从变量值出发，而 MDS 从距离矩阵出发。

| | PCA | MDS |
|---|---|---|
| 输入 | 变量值表 | 个体间距离矩阵 |
| 准则 | 尽可能保留方差 | 尽可能保留距离（最小化压力） |
| 结果 | 主成分（变量的组合） | 个体的坐标 |

## 时序分析：具有时间顺序的数据

时序数据是对同一对象按时间顺序观测得到的值。普通回归假设观测值相互独立，而时序分析的出发点则是今天的值与昨天的值相连。

### 构成要素

时序通常被视为由以下四种成分混合而成：

| 构成要素 | 含义 |
|---|---|
| 趋势 (Trend) | 长期上升或下降的方向 |
| 季节 (Seasonality) | 周期固定的重复（如月度、周度等） |
| 循环 (Cyclical) | 周期不固定的升降波动 |
| 不规则 (Irregular) | 无法用上述三者解释的剩余部分 |

季节与循环的区分容易混淆。以 Hyndman 教材为标准，季节是指周期固定且已知的波动，而循环是指长度不固定、难以预测高点和低点出现时间的波动。

### 平稳性

平稳时序是指统计性质不随观测时间点变化的时序。在图形上，其大致呈水平状且波动幅度恒定。如果存在趋势或季节性，则不属于平稳序列。白噪声是平稳的。令人意外的是，即使存在循环，只要周期未定，也可视为平稳。

判断平稳性的方法有两种。

- 图示与 ACF：若为平稳过程，自相关系数（ACF）会迅速降至 0 附近；若为非平稳过程，则下降缓慢。
- 单位根检验：Hyndman 教材中使用的 KPSS 检验，其原假设为“平稳”。p 值较小时（例如小于 0.05），意味着需要进行差分处理。由于不同检验的原假设可能截然相反，因此在考试中最好连同原假设一起记忆。关于假设检验的结构，详见 [详细 → 假设检验](#/post/adsp-hypothesis)。

这是直接验证的示例。生成了随机游走（每个时间点累积噪声的值）并计算了其 ACF。

| 滞后 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 随机游走 ACF | 0.98 | 0.97 | 0.95 | 0.93 | 0.91 |
| 一次差分后的 ACF | 0.03 | -0.02 | 0.20 | 0.04 | 0.03 |

原始数据下降缓慢，而差分后几乎为 0。这就是从非平稳转变为平稳的过程。

### 变换：差分

差分是取相邻两个观测值的差（y_t − y_(t−1)）。通过消除水平变化来稳定均值，并减少趋势和季节性。季节差分则使用与上一周期前值的差（y_t − y_(t−m)）。对于月度数据，m=12。对周期为 12 的正弦波形应用季节差分后，标准差从 3.59 降至 0.41。

需要注意的是，差分次数应恰到好处。过度差分会导致原本不存在的自相关出现。对数变换可以稳定方差，但无法消除趋势。

## ARIMA

ARIMA(p, d, q) 是 AutoRegressive Integrated Moving Average 的缩写，三个数字决定了模型结构。

| 符号 | 含义 |
|---|---|
| p | 自回归 (AR) 阶数：使用多少个过去值 |
| d | 差分次数：为使过程平稳而进行的差分次数 |
| q | 移动平均 (MA) 阶数：使用多少个过去预测误差 |

- AR(p)：对自身的过去值进行回归。y_t = c + φ1·y_(t−1) + … + ε_t
- MA(q)：过去误差的组合。y_t = c + ε_t + θ1·ε_(t−1) + …. 这与用于提取趋势的移动平均平滑概念不同，因此名称容易混淆。
- I(差分)：表示包含差分的逆运算（积分）。d 实际上很少超过 2，教材中也有提及。

常用的特殊情况如下：

| 模型 | 记号 |
|---|---|
| 白噪声 | ARIMA(0,0,0) |
| 随机游走 | ARIMA(0,1,0) |
| 带漂移的随机游走 | ARIMA(0,1,0) + 常数 |
| 自回归 | ARIMA(p,0,0) |
| 移动平均 | ARIMA(0,0,q) |

选择 p 和 q 时，ACF 可作为线索。通过直接模拟验证了理论与实际是否相符。

- AR(1), φ=0.7：ACF 依次为 0.69, 0.48, 0.32, 0.21, 0.15，逐渐下降。与理论值 0.7^k (0.70, 0.49, 0.34, 0.24, 0.17) 相近。
- MA(1), θ=0.8：滞后 1 处为 0.49，之后接近 0 (0.00, −0.02, …)。与理论值 θ/(1+θ²)=0.49 一致。

因此，AR 模型的 ACF 缓慢衰减，而 MA 模型在滞后 q 之后会突然截断。考试中常出现区分这两者的题型。

<details>
<summary>详细解答：使用后移算子表示的 ARIMA 公式</summary>

后移算子 B 将值向后移动一个时间点 (B·y_t = y_(t−1))。一阶差分是 (1 − B)y_t，d 阶差分则是 (1 − B)^d·y_t。因此 d 是 (1 − B) 的指数。完整公式如下：

(1 − φ1·B − … − φp·B^p)(1 − B)^d·y_t = c + (1 + θ1·B + … + θq·B^q)·ε_t

左侧包含 AR 多项式和差分项，右侧包含 MA 多项式。

</details>

## 常见误解

- 主成分是原始变量中的某一部分：不对。它是原始变量的新组合。
- PCA 无需考虑单位：如果不进行缩放，单位不同的变量中，数值较大的变量会占主导地位。
- MDS 总是重现原始距离：在降维过程中会产生误差，其大小即为压力 (stress)。
- 循环与季节性相同：季节性的周期是固定的，而循环的周期不固定。
- ARIMA 的 d 越大越好：应仅进行必要的差分，过度差分会导致虚假自相关出现。
