ADsP Study Notes: Twelve lessons compiled in one place. Subject 1 covers concepts, Subject 2 covers planning, and Subject 3 covers statistics and analysis. Please check the official website for any changes to exam schedules and fees.

## Overview of the Order

```
1과목 데이터 이해
 데이터의 이해 → 데이터의 가치와 미래 → 데이터 사이언스와 인재
2과목 데이터 분석 기획
 분석 기획 → 분석 방법론 → 분석 과제와 마스터플랜
3과목 데이터 분석
 R·데이터 마트 → 통계 기초 → 가설 검정 → 회귀 → 다변량·시계열 → 데이터 마이닝
```
