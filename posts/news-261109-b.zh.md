## 做什么
这是一个 Python Web 抓取框架。README 介绍其涵盖“从单个请求到大规模爬取”。说明称该库集成了获取静态页面、渲染由 JavaScript 绘制的页面、与网站交互以及从后台 API 调用中提取数据等功能。许可证为 BSD-3-Clause，需要 Python 3.10 及以上版本。

## 架构
- **Fetcher**：`Fetcher` 在发送 HTTP 请求时模拟浏览器的 TLS 指纹和头部信息。据称 `StealthyFetcher` 基于 Playwright 使用 Chromium 或 Chrome 打开页面，并支持处理 Cloudflare Turnstile 等验证界面。功能列表还包括代理轮换、广告/域名屏蔽、以及通过 CDP 附加到远程浏览器的功能。
- **解析器**：支持 CSS、XPath、BeautifulSoup 风格的 `find_all`、文本及正则表达式搜索。其特色是提供类似“自适应追踪”的功能，即使网站结构发生变化也能重新定位元素，并包含 `find_similar()` 方法用于查找相似元素。此外，可通过 `page.markdown()` 输出 Markdown，且解析器可单独使用。
- **Spider**：类似于 Scrapy 的 `Spider` 类，使用 `start_urls` 和异步 `parse` 方法。支持并发限制、按域名限制、遵守 robots.txt（可选）、通过 `crawldir` 中断/恢复，以及导出为 JSON、JSONL、CSV、XML。还包含 `SitemapSpider`、`CrawlSpider` 等模板。
- **AI 相关**：可通过 `pip install "scrapling[ai]"` 安装 MCP 服务器，README 中还提到了针对编码代理的 Agent Skill。此外，还有一个 `[rag]` 附加包，用于生成适合 RAG 系统的 Markdown 输出。
- **CLI**：使用 `scrapling extract` 可将页面保存为 .txt、.md、.html 文件，使用 `scrapling shell` 可打开 IPython 外壳。

## 最新发布
在发布页面确认的最新版本为 v0.5.1（11 月 4 日）。

- 录制带有时间戳帧的短视频，使代理能够跟随动作；支持针对鼠标按钮分别进行拖拽、点击和释放操作。
- 新增了 `RemoteSession` 和 `AsyncRemoteSession`，可通过 CDP 附加到已运行的 Chromium 实例。若设置 `new_context=False`，则复用该浏览器的登录状态。
- 由于远程浏览器连接需要新的会话类，现有代码将失效。官方提供了迁移指南。

在此之前的 v0.5（10 月 17 日）版本中，MCP 服务器扩展了处理表单、点击、滚动、按键输入和对话框的功能；新增了 `record_requests=True`（记录网络请求）、`save_state()` 和 `load_state()`（保存/加载 Cookie、本地存储及 IndexedDB）、以及 `pierce_shadow=True`（提取打开的 Shadow DOM）。该版本也包含大量破坏性变更。8 月的 v0.4.15 版本中，MCP HTTP 传输默认要求认证且仅限 localhost 使用。作为一个将浏览器交给代理的工具，这部分值得注意。

## 安装与示例
按照 README 说明，`pip install scrapling` 仅安装解析器。若要使用 Fetcher，需先执行 `pip install "scrapling[fetchers]"`，然后通过 `scrapling install` 下载浏览器；若在不安装附加包的情况下尝试导入 `scrapling.fetchers`，则会报错 `ModuleNotFoundError`。此外还提供了 Docker 镜像。最简单的示例如下：

```python
from scrapling.fetchers import Fetcher
page = Fetcher.get('https://quotes.toscrape.com/')
quotes = page.css('.quote .text::text').getall()
```
