## 무엇을 하나
파이썬 웹 스크래핑 프레임워크다. README는 "단일 요청부터 대규모 크롤링까지" 다룬다고 소개한다. 정적 페이지를 받아 오는 것, 자바스크립트로 그려지는 페이지를 렌더링하는 것, 사이트와 상호작용하는 것, 화면 뒤에서 오가는 API 호출에서 데이터를 뽑는 것까지 한 라이브러리에 넣었다는 설명이다. 라이선스는 BSD-3-Clause이고 파이썬 3.10 이상이 필요하다.

## 구성
- 페처(fetcher): `Fetcher`는 HTTP 요청을 보내면서 브라우저의 TLS 지문과 헤더를 흉내 낸다. `StealthyFetcher`는 Playwright 기반 Chromium이나 Chrome으로 페이지를 열고, Cloudflare Turnstile 같은 확인 화면을 처리하는 옵션이 있다고 한다. 프록시 로테이션, 광고·도메인 차단, CDP로 원격 브라우저에 붙는 기능도 목록에 있다.
- 파서: CSS, XPath, BeautifulSoup 스타일 `find_all`, 텍스트·정규식 검색을 지원한다. 사이트 구조가 바뀌어도 요소를 다시 찾아 주는 '적응형 추적'과 비슷한 요소를 찾는 `find_similar()`가 특징이다. `page.markdown()`으로 마크다운 출력도 된다. 파서만 따로 쓸 수 있다.
- 스파이더: Scrapy와 비슷한 `Spider` 클래스에 `start_urls`와 비동기 `parse`를 쓴다. 동시성 제한, 도메인별 제한, robots.txt 준수(선택), `crawldir`로 중단·재개, JSON·JSONL·CSV·XML 내보내기가 있다. `SitemapSpider`, `CrawlSpider` 같은 템플릿도 있다.
- AI 쪽: `pip install "scrapling[ai]"`로 MCP 서버를 깔 수 있고, 코딩 에이전트용 Agent Skill도 있다고 README에 적혀 있다. RAG에 넣기 좋은 마크다운 출력은 `[rag]` 추가 패키지다.
- CLI: `scrapling extract`로 페이지를 .txt·.md·.html 파일로 저장하고, `scrapling shell`로 IPython 셸을 연다.

## 최근 릴리스
릴리스 페이지에서 확인한 최신 버전은 v0.5.1(11월 4일)이다.

- 에이전트가 움직임을 따라갈 수 있도록 짧은 영상을 시간 표시가 붙은 프레임으로 기록하고, 마우스 버튼별로 드래그·누르기·놓기를 할 수 있게 했다.
- `RemoteSession`, `AsyncRemoteSession`이 새로 생겨 이미 떠 있는 Chromium에 CDP로 붙는다. `new_context=False`면 그 브라우저의 로그인 상태를 재사용한다.
- 원격 브라우저 연결은 새 세션 클래스가 필요해져서 기존 코드는 깨진다. 마이그레이션 가이드가 있다고 한다.

그 앞의 v0.5(10월 17일)에는 MCP 서버가 폼·클릭·스크롤·키 입력·대화상자까지 다루게 된 변경과 `record_requests=True`(네트워크 기록), `save_state()`·`load_state()`(쿠키·로컬 스토리지·IndexedDB 저장), `pierce_shadow=True`(열린 Shadow DOM 추출)가 들어갔다. 이 릴리스에도 깨지는 변경이 많다고 적혀 있다. 8월의 v0.4.15에서는 MCP HTTP 전송이 기본으로 인증을 요구하고 로컬호스트에만 묶이도록 바뀌었다. 에이전트에 브라우저를 쥐여 주는 도구라서 이 부분은 눈여겨볼 만하다.

## 설치와 예시
README 기준으로 `pip install scrapling`은 파서만 깐다. 페처를 쓰려면 `pip install "scrapling[fetchers]"` 후 `scrapling install`로 브라우저를 내려받아야 하고, 추가 패키지 없이 `scrapling.fetchers`를 가져오면 `ModuleNotFoundError`가 난다고 한다. Docker 이미지도 있다. 가장 단순한 예시는 다음과 같다.

```python
from scrapling.fetchers import Fetcher
page = Fetcher.get('https://quotes.toscrape.com/')
quotes = page.css('.quote .text::text').getall()
```
