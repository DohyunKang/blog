高度な分析手法は、基礎統計学をさらに一歩進めた 4 つのツールのまとまりである。多変量解析、時系列解析、ノンパラメトリック検定、ベイズ推論がそれらだ。計算自体を行う問題よりも、「この状況にはどの手法を使うか」を選ぶ問題が多いため、各手法の使用場面とセットで覚える方が効率的だ。試験日程と受験料は公式サイトで確認する。基礎統計学については [詳細 → 探索的解析と基礎統計](#/post/bd-eda-stats) を参照のこと。

| 手法 | こんな時 | キーワード |
|---|---|---|
| 多変量解析 | 変数が複数あり、互いに絡み合っている場合 | 主成分、因子、多次元尺度法、クラスタリング |
| 時系列解析 | 観測値が時間順に蓄積されている場合 | 平稳性 (stationarity)、自己相関、AR・MA・ARIMA |
| ノンパラメトリック検定 | 正規分布を信じるのが難しいか、サンプルサイズが小さい場合 | ランク、中央値、ウィルコクソン、マン＝ホイットニー |
| ベイズ | 事前の信念をデータで更新したい場合 | 事前・事後確率、尤度 |

## 多変量解析

2 つ以上の変数を持つデータを一度に扱う方法を総称して多変量解析と呼ぶ。試験では名称と目的を結びつける問題が出題される。

| 名称 | やる事 |
|---|---|
| 主成分分析 (PCA) | 分散の大きい方向に新しい軸を作り、変数の数を減らす |
| 因子分析 | 変数の背後にある共通の因子を探す |
| 多次元尺度法 (MDS) | 個体間の距離を可能な限り保ったまま 2〜3 次元平面上に配置する |
| クラスタリング分析 | 似たような個体を束ねる |
| 判別分析 | 既に知られた集団で新しい個体を分類する |

PCA は scikit-learn のドキュメントを基準として、分散を最大限説明し合う互いに直交する成分を順に抽出する変換であり、データを平均から引いて中心に合わせるが、サイズ（スケール）は調整しない。この最後の文句が実務で重要だ。単位が違う変数をそのまま入れると、値の大きい変数が成分を独占してしまう。iris データセットで確認した。

```python
from sklearn.datasets import load_iris
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

X = load_iris().data
print(PCA(2).fit(X).explained_variance_ratio_.round(3))
print(PCA(2).fit(StandardScaler().fit_transform(X)).explained_variance_ratio_.round(3))
```

```
[0.925 0.053]
[0.73  0.229]
```

標準化前には第 1 成分が 92.5% の分散を説明し、標準化後は 73.0% に低下する一方、第 2 成分は 22.9% に上昇する。変数のスケールが結果を変えることをこの 2 行が示している。PCA と変数選択の話は [詳細 → 特徴量選択と次元削減](#/post/bd-feature-select) で続いている。クラスタリングについては [詳細 → 教師なし学習モデル](#/post/bd-unsupervised) に別途ある。

<details>
<summary>PCA と因子分析、混同しやすい点</summary>

どちらも変数を減らすのに使われるが、出発点が異なる。PCA は元の変数の分散を最大限含んだ新しい軸を作ることを目的としており、因子分析は変数が共通して従う潜在因子を仮定し、それを推定することを目的としている。問題文に「潜在因子」「共通因子」と出ていれば因子分析、「分散を最大限保存」「次元削減」と出ていれば PCA と読み取ればよい。

</details>

## 時系列解析

時系列は観測値が時間順に蓄積されたデータである。NIST ハンドブックでは、時間順に集めたデータには「内部構造」が存在する可能性があるとしており、その例として自己相関を挙げている。前後の値が互いに影響し合うため、独立なサンプルを仮定する一般的な検定をそのまま使うことはできない。

試験で頻出の概念は以下の通りだ。

| 概念 | 意味 |
|---|---|
| 平稳性 (stationarity) | 平均・分散が時間とともに変化せず、自己共分散が時差のみによる性質 |
| 差分 | 現在の値から直前の値を引いてトレンドを取り除く変換 |
| 季節差分 | 季節周期だけ離れた値との差 |
| AR(p) | 自身の過去 p 個の値で現在を説明する |
| MA(q) | 過去の衝撃（誤差）q 個で現在を説明する |
| ARIMA(p,d,q) | 非平稳な時系列を d 回差分した後、AR と MA を組み合わせたモデル |

NIST ハンドブックでは Box-Jenkins モデルは平稳な時系列を仮定しており、平稳でない場合は一度以上差分して ARIMA（「I」は integrated）にすると記述されている。モデルを使う順序は識別、推定、検証である。

なぜ差分が有効なのかを実際に回してみた。ランダムウォークのように累積した乱数で作ったトレンド型時系列では、1 歩先の自己相関がほぼ 1 になる。差分を施すとほぼ 0 に落ちる。

```python
import numpy as np, pandas as pd
rng = np.random.default_rng(0)
y = pd.Series(np.cumsum(rng.normal(size=200)))
print(round(y.autocorr(1), 3), round(y.diff().dropna().autocorr(1), 3))
```

```
0.977 0.039
```

AR と MA は自己相関が減衰する様子が異なる。AR(1) で係数 0.7、MA(1) で係数 0.8 を設定してそれぞれ 500 個ずつ生成し、時差ごとの自己相関を見た。

```python
e = rng.normal(size=500)
ar = np.zeros(500)
for t in range(1, 500):
    ar[t] = 0.7 * ar[t-1] + e[t]
s = pd.Series(ar)
print([round(s.autocorr(k), 2) for k in (1, 2, 3, 4)])
m = pd.Series(e[1:] + 0.8 * e[:-1])
print([round(m.autocorr(k), 2) for k in (1, 2, 3)])
```

```
[0.65, 0.41, 0.25, 0.15]
[0.46, -0.07, -0.05]
```

AR は徐々に減衰する形であり、MA(1) は時差 1 以降で途切れる。試験の「ACF が指数関数的に減少すれば AR、時差 q の後に切断されれば MA」はこの様子だ。部分自己相関 (PACF) は逆に AR が切断、MA が減衰と覚える。

<details>
<summary>時系列分解と移動平均</summary>

時系列をトレンド、季節性、循環、不規則成分に分解する手法も定番です。移動平均法は直近のいくつかの値の平均で不規則変動を抑え、トレンドを見る方法であり、指数平滑法は直近の値に大きな重みを与えます。名前と一行の説明をセットにしておけば十分です。

</details>

## 非母数検定

母数検定（t 検定など）は、データが特定の分布（主に正規分布）に従うと仮定し、平均などの母数を比較します。一方、非母数検定は分布の形状を仮定せず、順位や符号を用います。標本サイズが小さい場合、正規性を疑う場合、または順序尺度データの場合に選択します。

| 状況 | 母数検定 | 非母数対応 |
|---|---|---|
| 独立した 2 つの集団 | 独立標本 t 検定 | マン・ホイーニ U (ウィルコクソン順位和) |
| 対応する 2 つの集団 | 対応標本 t 検定 | ウィルコクソン符号順位 |
| 3 つ以上の集団 | 一元分散分析 | クラスカル・ウォリス |
| 相関 | ピアソン | スピアマン順位相関 |

SciPy のドキュメントでは、マン・ホイーニ U を独立標本 t 検定の非母数バージョンとして説明しています。帰無仮説は、2 つの標本の基礎分布が等しいものであり、標本同士が互いに独立である必要があります。対応する標本の場合はウィルコクソンを使用するように案内されています。同じデータに対して t 検定とマン・ホイーニ U を実行してみました。

```python
import numpy as np
from scipy import stats
a = np.array([12,15,14,10,18,20,11,13])
b = np.array([22,19,25,17,30,21,24,16])
print(stats.mannwhitneyu(a, b, alternative='two-sided').pvalue)
print(stats.ttest_ind(a, b).pvalue)
before = np.array([70,65,80,72,68,75,90,66])
after  = np.array([68,60,79,65,66,70,85,67])
print(stats.wilcoxon(before, after).pvalue)
print(stats.kruskal([5,7,6,9,8],[12,14,11,15,13],[20,18,22,19,21]).pvalue)
```

```
0.00295   (만-휘트니)
0.00211   (t검정)
0.0234    (윌콕슨 부호순위)
0.00193   (크러스칼-왈리스)
```

正規性が問題ないデータでは、両方の検定は似たような結論を出します。問題を解く際は、まず検定の名称を選ぶことが重要です。「対応」「3 つの集団」「順位」といった言葉が見えたら、上記の表で該当するセルを探せばよいです。p 値の読み方と帰無仮説については [詳細 → 探索的解析と基礎統計](#/post/bd-eda-stats) を参照してください。

<details>
<summary>その他の非母数検定</summary>

符号検定は、ペアにした値の差が正か負かのみを調べます。ラン検定は、値が +, - に分かれる連続区間 (run) の数を数え、データが無作為に並んでいるかを判定します。コルモゴロフ・スミルノフ検定は、標本が特定の分布に従うか、または 2 つの標本が同じ分布を持つかを確認します。名前と目的だけを結びつけておけば十分です。

</details>

## ベイズ推論

頻度主義は母数を固定された値として扱い、データの確率に基づいて推論を行います。一方、ベイズ派は母数に対する信念を確率分布として置き、データを見るにつれてこれを更新します。

事後確率は、尤度と事前確率の積に比例します。

P(A|B) = P(B|A) × P(A) / P(B)

試験ではこの式を用いて数値計算を行う問題が出題されます。有病率が 1% の疾患において、検査感度が 95%、健康な人が陽性反応を示す割合が 5% の場合、陽性と判定された人が実際に患者である確率を計算してみました。

```python
p, sens, fp = 0.01, 0.95, 0.05
print(sens * p / (sens * p + fp * (1 - p)))
```

```
0.161
```

陽性でありながら患者である確率は約 16% です。検査が 95% と正確に見えても、事前確率（1%）が小さいと事後確率は低くなります。「感度」と「事後確率」を混同させる問題がこの構造にあります。

事前分布として Beta(1,1) から始め、成功 7 回、失敗 3 回を観察すると、事後分布は Beta(1+7, 1+3) = Beta(8,4) となり、平均は 8/12 で約 0.667 です。事前分布と事後分布が同じ系列となるペアを「共役事前分布」と呼び、二項データにはベータ分布がこのペアとなります。

<details>
<summary>ナイーブ・ベイジアンとの関係</summary>

分類モデルであるナイーブ・ベイジアンは、ベイズの定理に「変数がクラスが与えられれば互いに独立」という単純化を適用したものです。教師あり学習に関する説明は [詳細 → 分析モデル設計](#/post/bd-model-design) で続けます。

</details>
