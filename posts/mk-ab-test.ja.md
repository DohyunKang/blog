A/B テストとは、同じものを 2 つの異なる形態に変えてランダムに割り当て、どちらの反応がより良いかを数値で判断する方法です。サムネイルやコピーを選ぶ際に、「感覚的にこっちの方が良さそう」という主観を数値化して客観的なデータに変換します。

## 何をするのか

2 つのバージョンを作成します。A は現在使用しているもの（対照群）、B は変更を加えたものです。訪問者や視聴者をランダムに半々に分け、片方には A、もう片方には B を表示します。その後、同じ期間中にクリック率（CTR）や登録率などの指標を比較します。

ランダムに分割することが核心です。A を月曜日に、B を金요일に上げて比較すると、曜日の違いが混ざって何が原因で結果が変わったのか分かりません。同じ時間帯に同時に表示させて初めて、2 つのグループの差はバージョンの違いによるものだと絞り込めます。

## 実験設計：始める前に決めること

始める前に 4 つの要素を決めておきます。

| 項目 | 例 | 備考 |
|---|---|---|
| 仮説 | 数字を入れたタイトルがクリック率を上げる | 一度に変更するのは一つだけ |
| 主指標 | サムネイルクリック率 | 一つだけ決める |
| 検出したい最小の差 | 3% → 3.6% | これより小さい差は諦める |
| サンプルサイズ | グループあたり約 1 万 4 千回の露出 | 事前に計算する |

「一度に一つだけ変更せよ」というのは、サムネイルの色と文言を同時に変えると何が効果があったのか分からないためです。複数の要素を同時に確認したい場合は、多変量テストという別の方法がありますが、必要なサンプルサイズは大幅に増えます。

## サンプルサイズと指標

サンプルが小さいと、偶然一方が先行しているように見えることがあります。そのため、「どれくらい集めれば信頼できるか」を事前に計算します。Evan Miller の記事にある近似的な式があります。グループあたりのサンプル数 n ≈ 16σ²/δ² で、ここで δ は検出したい最小の差であり、比率指標の場合は σ² = p(1−p) と表します。

私の感覚としては、差が半分になれば必要なサンプル数は 4 倍になります。クリック率 3% で 0.6%p の差を検出するには上記の式でグループあたり約 1 万 3 千人必要となります。同じ基準で 1.5%p の差であれば数千名で済みます。小さな差を検出しようとするテストは、トラフィックが少ない場所では事実上不可能です。

以下の 2 つの値はテスト結果を読む際に付随します。

- 有意水準（α、通常 0.05）：実際には差がないのに「ある」と誤って言う確率の上限。
- 検出力（通常 0.8）：実際に差がある場合、それを検出する確率。

p 値は「2 つのバージョンが実際には同じだと仮定した場合、今のような差が偶然生じる確率」です。B がより良い確率ではありません。この部分が最も混乱しやすいです。

## 自動化する方法

マーケティングオートメーション分野では、通常以下のような順序で実行します。

1. [LLM](#/post/ai-llm) や画像生成モデルを使ってコピーやサムネイルの候補をいくつか抽出する。
2. 候補を露出システムに投稿し、露出をランダムに割り当てる。
3. クリック・コンバージョンログを蓄積する。
4. 事前に決めたサンプル数に達したら検定を実行して勝者を選ぶ。
5. 勝者をデフォルトに変更し、次の仮説へ進む。

候補を作成するのは自動化が容易ですが、難しいのは 4 の「決めたサンプル数まで待つ」というルールをコードでブロックしておくことです。結果を集約して一目で確認できるのは [ダッシュボード](#/post/mk-dashboard) の記事で扱っており、どの素材をテストするかは [コンテンツカレンダー](#/post/mk-content-calendar) や [トレンド収集](#/post/mk-trend-collect) と連携します。

YouTube にはサムネイルやタイトルの A/B テスト機能が別途あると知られていますが、今回は公式ヘルプを開示していませんでした。

## よくある間違い

途中で結果を覗き見て停止すること（peeking）が最も一般的です。Evan Miller は有意水準について、途中で止めてしまうと報告される有意水準が歪むと述べています。10 回確認して 1% と見える値が実際には約 5% であるという例を挙げます。実際に検証しました。2 つのバージョンの実際のコンバージョン率を同じ（3%）にして、それぞれ 5,000 名ずつ集めた偽のテストを 1,500 回実行しました。

| 方式 | 「差がある」と誤って出た割合 |
|---|---|
| 最後に一度だけ検定 | 約 5% |
| 10 回に分けて見て有意なら停止 | 約 21% |

差がないのに、5 回のうち 1 回は「勝者が出現した」ということになります。待ちたくない場合の手法として順次検定やベイズ法があり、Miller の記事では中間確認のタイミングを事前に決めておけば止めてもよいと述べています。

その他によくあるもの。

- 複数回同時比較：5 つの変形をそれぞれ α=0.05 で検定すると、少なくとも 1 つ誤って有意になる確率は 1−0.95⁵ ≈ 23% です。ウィキペディアの多重比較問題の説明に従うと、最も単純な補正は α を回数のまま割るボンフェロニ法（5 つなら 0.01）であり、より保守的で優れた方法としてホルム補正があります。
- 指標をテスト終了後に選ぶ：クリック率が得られない場合は滞在時間を見て、それでも得られない場合は他の指標を見るというものです。これも多重比較です。主たる指標は開始前に一つに固定します。
- 短期間のみ観察する：曜日や時間帯の差があるため、最低でも週単位で回すことが安全だと知られています。これは私が公式出典で確認できなかった点です。
- 新奇性効果：新しいサムネイルは最初は目立って一時的に反応が高まり、その後落ち着く可能性があります。
- 小さな差異を大きな意味と読み取る：有意であることと実用的な大きさがあることは異なります。サンプルサイズが非常に大きければ、0.01%p の差でも有意になります。

## よくある誤解

- p 値が 0.05 より小さければ B が優れていることが確定する：有意水準 5% なら、差がなくても 20 回中 1 回はこのような結果が出ます。一度のテストは単なる証拠の一つに過ぎません。
- サンプルサイズが多いほど常に良い：それだけ時間がかかり、テスト中に悪いバージョンに曝露されるコスト（半分になる）があります。
- 有意でなければ両者は同じだ：違います。検出できなかった差があるかもしれません。まずはサンプルが不足していないか確認します。

<details>
<summary>詳細な解説：グループごとのサンプルサイズ計算式と Python コード</summary>

2 つの比率 p1, p2 を比較する標準的な近似式です。コードを実行して以下の数値を確認しました。

```python
import math
from statistics import NormalDist
N = NormalDist()

def n_per_group(p1, p2, alpha=0.05, power=0.8):
    za = N.inv_cdf(1 - alpha / 2)
    zb = N.inv_cdf(power)
    pb = (p1 + p2) / 2
    n = (za * math.sqrt(2 * pb * (1 - pb))
         + zb * math.sqrt(p1 * (1 - p1) + p2 * (1 - p2))) ** 2 / (p1 - p2) ** 2
    return math.ceil(n)

print(n_per_group(0.03, 0.036))  # 13914
print(n_per_group(0.03, 0.045))  # 2518
```

3% → 3.6% を検出するにはグループあたり 13,914、3% → 4.5% なら 2,518 が得られました。ミラーの近似式 (16σ²/δ²) は同じ条件下で約 12,933 で、正確な式と約 7% の差がありました。近似式は概算感を掴むためのものです。

結果の読み取りは 2 つの比率 z 検定です。

```python
def ztest(c1, n1, c2, n2):
    p = (c1 + c2) / (n1 + n2)
    se = math.sqrt(p * (1 - p) * (1 / n1 + 1 / n2))
    z = (c2 / n2 - c1 / n1) / se
    return 2 * (1 - N.cdf(abs(z)))

print(ztest(150, 5000, 185, 5000))  # 약 0.052
```

5,000 人ずつ表示して A で 150 クリック (3.0%)、B で 185 クリック (3.7%) が得られましたが p は 0.052 で 5% の線をわずかに超えませんでした。このテストは「B が優れている」と断じるには曖昧で、サンプルをさらに集めるなら最初から計画しておくべきでした。

ピーキングシミュレーションでは、同じ 3% の 2 つのグループからそれぞれ 5,000 人を選び、500 人単位で 10 回検定し、一度でも p<0.05 なら「勝者あり」としました。1,500 回繰り返して約 21%、最後に一度だけ検定すると約 5% でした。シードと反復回数によって何%p か揺れます。
