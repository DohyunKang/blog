## 何をしているのか
コーディングエージェントはセッションが終了すると、先に行っていたことを忘れてしまいます。claude-mem はセッション中にツールを使用した記録（observation）を収集し、AI で圧縮して、次のセッションが始まる際に関連する内容を再度投入します。README に記載されている対応エージェントには Claude Code、OpenClaw、Codex、Gemini、Hermes、Copilot、OpenCode があります。

## 動作構造
- フック 6 つ：SessionStart、UserPromptSubmit、PreToolUse、PostToolUse、Stop、SessionEnd。各フックは claude-mem コマンドを 1 つ実行します。
- ワーカー：ローカル HTTP API と Web ビューアを持つサービスであり、Bun で管理します。
- 保存：SQLite にセッション・観察・要約を格納し、FTS5 を用いて全文検索を行います。ベクトル検索には Chroma を使用し、キーワードと組み合わせて検索します。
- 検索：mem-search スキルと MCP ツールの 3 つ（search、timeline、get_observations）を使用します。リストでまずフィルタリングし、必要なものだけを詳細に取得する順序であるため、README はトークンを約 10 倍節約できると主張しています。この数値は著者の主張であり、確認していません。
- モード：デフォルトは code、記録を残す量を減らす code--chill、他の言語で記述する code--[lang] のバリエーションがあります。

## インストール
README に従って `npx claude-mem install` を使用するか、Claude Code 内で `/plugin marketplace add thedotmack/claude-mem` の後、`/plugin install claude-mem` を実行します。Node.js 20 以上が必要で、Bun や uv がなくても自動インストールされるとのことです。npm パッケージはライブラリのみをインストールし、フックやワーカーは登録しないと記載されています。Windows では node と npm が PATH に含まれている必要があり、claude-mem を見つけられないとフックが失敗します。

## 書き込む前に確認すべきこと
README の個人情報に関する内容は、インストール前に読む価値がありました。

- ログインするとホスティングされた "claude-mem observer" の 30 日間無料トライアルが始まります。トライアル終了後、購読しない場合、要約は Anthropic プラン側に切り替わります。OpenRouter や Gemini キーを直接使用するか、`--provider` または `CLAUDE_MEM_ONLINE_OPTIN=false` でログインなしで使用することも可能です。
- `<private>` タグで囲まれた内容は保存から除外されます。
- Cloud Sync をオンにすると、記憶が cmem.ai にバックアップされます。スクリーンショットはデフォルトでオフであり、アップロードされるのは Cloud Sync がオンになっている場合のみです。
- セッション開始時に投入するコンテキストは、デフォルトでは現在使用中のハネス（Harness）のものだけです。拡張には別の環境変数があります。

企業コードを扱う環境であれば、どのような内容が要約ボックスに渡されるかを確認する必要があります。
