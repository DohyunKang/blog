ADSP 2 科目の前半は、どのように標本を抽出するか、値をどのような尺度で読み取るか、1 つの数字でどう要約するか、そしてそれによって母集団をどう推定するかがセットになっている。後半に出てくる仮説検定や回帰分析もすべてここの上に立っている。

## 全体像

| ステップ | 問いかけ | 核心用語 |
|---|---|---|
| サンプル抽出 | 全体が見えないので、どのように一部を選ぶか | 単純・系統・層化・集団 |
| 尺度 | 値の種類は何か | 名目・順序・区間・比率 |
| 記述統計 | データをいくつかの数字にまとめるなら | 平均・中央値・分散・四分位数 |
| 確率分布 | 値がどのような形に散らばるか | 正規分布・標準化 |
| 推定 | 標本から母集団を語るには | 点推定・区間推定・標準誤差 |

## サンプル抽出

母集団全体を調査するのは高価か不可能なため、一部（標本）のみを選ぶ。試験では、4 つの方法の違いを問われることが多い。

| 方法 | どのように選ぶか | 区別のポイント |
|---|---|---|
| 単純無作為抽出 | すべての個体が同じ確率で選ばれる | 並べ替えやグループ化なしで全体から直接 |
| 系統抽出 | 順序立ててランダムな開始点から k 番ごとに選ぶ | 一定の間隔 |
| 層化抽出 | グループ（層）に分けた後、各層から選ぶ | すべての層が標本に含まれる |
| 集団抽出 | グループそのものを丸ごと選び、その中を調査する | 個体ではなく集団を選ぶ |

層化と集団はどちらもグループに分ける点で似ているため混乱しやすい。層化はすべてのグループから一部ずつ選び、集団は一部のグループだけを選んでその内側を調査する。集団調査は調査コストを削減できるが、同じ精度を得るためには標本サイズを大きくする必要がある。

[詳細 → 分析手法論](#/post/adsp-methodology) で扱われるデータ準備段階とつなげて見ると順序が整理される。

## 尺度

値の種類を 4 つの段階に分ける。下に行くほど行える計算が増える。

| 尺度 | 意味 | 例 | 使用可能な統計量 |
|---|---|---|---|
| 名目 | 名前しかない、順序なし | 血液型、性別 | 最頻値 |
| 順序 | 順序はあるが間隔は不明 | ランキング、非常に同意〜非常に反対 | 中央値、最頻値 |
| 区間 | 間隔は等しいが絶対ゼロはない | 摂氏温度、年号 | 平均まで |
| 比率 | 間隔は等しくかつ絶対ゼロがある | 重量、長さ、時間 | 平均まで、比率の解釈が可能 |

区間と比率の違いは「0 の意味」にある。摂氏 20 度が 10 度の 2 倍暖かいとは言えないのは、0 度が「なし」ではないからである。重量では 0 が真に「なし」なので、20kg は 10kg の 2 倍と言える。

試験では例題を示してどの尺度かを選ぶ問題が出ることがある。順序か区間かが曖昧な場合は、「間隔が等しいと言えるか」をまず問えばよい。満足度 5 点尺度の「普通」と「満足」の間隔が、「不満」と「普通」の間隔と等しいという保証はないため、順序尺度である。

## 記述統計

収集したデータを数字で要約する作業である。2 つの種類に分かれる。

- 位置の中心：平均、中央値、最頻値
- ばらつき：分散、標準偏差、範囲、四分位数範囲 (IQR)

平均は外れ値に引っ張られやすく、中央値はそうならない。そのため所得のように右側に長く伸びたデータでは、平均が中央値より大きくなる傾向がある。

標準偏差は分散の平方根なので元の単位に戻る。変動係数（標準偏差 / 平均）は、単位が異なる 2 つのデータのばらつきを比較する際に使用する。

四分位数はデータを大きさ順に並べて 25%、50%、75% の地点をとった値であり、IQR は Q3 − Q1 である。箱ひげ図（ボックスプロット）はこの値を描いた図なので、試験では箱の中央線が中央値であることと、ひげの外側の点が外れ値候補であることを問うことがある。

<details>
<summary>小さなデータで直接計算してみる (Python で実行して確認)</summary>

データ 8 個 `[2, 4, 4, 4, 5, 5, 7, 9]` で計算した。母分散は n で、標本分散は n−1 で割る。

```python
import statistics as st, math
x = [2, 4, 4, 4, 5, 5, 7, 9]
print(st.mean(x), st.median(x), st.mode(x))
print(st.pvariance(x), st.pstdev(x))
print(st.variance(x), round(st.stdev(x), 3))
print(st.quantiles(x, n=4, method='inclusive'))
```

実行結果は以下の通りである。

| 項目 | 値 |
|---|---|
| 平均 / 中央値 / 最頻値 | 5 / 4.5 / 4 |
| 母分散 / 母標準偏差 | 4 / 2.0 |
| 標本分散 / 標本標準偏差 | 4.571 / 2.138 |
| Q1 / Q2 / Q3 | 4.0 / 4.5 / 5.5 |

同じデータだが n で割るか n−1 で割るかによって分散が 4 と 4.571 に分かれる。標本から母集団の分散を推定する場合は、n−1 で割った標本分散を使用する。
</details>

## 確率分布

確率変数がどのような値をどのような確率で持つかを表したものが確率分布である。値が数え上げられる場合は離散、連続的な場合は連続に分ける。

- 離散：二項分布（成功/失敗を n 回試行した成功回数）、ポアソン分布（一定の区間で事象が発生した回数）
- 連続：正規分布、t 分布、カイ二乗分布、F 分布

正規分布は、平均を中心に左右対称な鐘の形をした分布であり、形状は平均と標準偏差の 2 つのパラメータで決まります。平均が 0 で標準偏差が 1 の正規分布を「標準正規分布」と呼び、任意の値 x を z = (x − 平均) / 標準偏差に変換することを「標準化」といいます。

計算してみると、標準正規分布において -1 と 1 の間の確率は 0.6827 で、両側合わせて 5% を残す境界値は 1.96 でした。試験で「±1σ 約 68%、±2σ 約 95%、±3σ 約 99.7%」を暗記する理由はこれらの数字です。区間推定ではそのまま使われるため、95% を正確に捉える値が 2 ではなく 1.96 であることも重要です。

t 分布、カイ二乗分布、F 分布は名称と用途がセットになっています。詳細は [仮説検定](#/post/adsp-hypothesis) で検定方法ごとにまとめて解説します。

## 推定

母集団の値（母数）を標本から当てはめることです。

| 区分 | 内容 | 例 |
|---|---|---|
| 点推定 | 1 つの値で表す | 標本平均 5.2 |
| 区間推定 | 範囲で表す | 母平均は 4.8〜5.6 の間 |

良い推定量の条件として、不偏性（期待値が母数と等しい）、効率性（分散が小さい）、一貫性（標本が大きくなるほど母数に近づく）、充足性が挙げられます。標本分散を n−1 で割る理由は、不偏性を満たすためです。

標本平均がどれだけ揺れるかは標準誤差で測ります。母標準偏差が σ の場合、標本平均の標準誤差は σ / √n です。標準誤差を半分にするには標本サイズを 4 倍にしなければならない点は試験によく出題されます。

中心極限定理は、母集団がどのような分布であっても標本が十分大きければ標本平均の分布が正規分布に近づくことを示しています。これにより、母集団の形状がわからなくても平均については正規分布を用いて推定や検定を行うことができます。

区間推定は 標本平均 ± (臨界値 × 標準誤差) の形です。信頼水準 95% の場合、正規分布基準での臨界値は 1.96 です。信頼水準を上げると区間は広くなり、標本数を増やすと区間は狭くなります。「95% 信頼区間」は、同じ方法で標本を繰り返し抽出した際、その区間の 95% が母数を含むことを意味するため、「今回の区間に母数が含まれる確率が 95% です」と読むと誤答となります。

<details>
<summary>標準誤差と信頼区間の計算例 (Python 確認)</summary>

上記資料の 8 つの標本の標準偏差 2.138 から標準誤差を求めると、2.138 / √8 = 0.756 でした。平均 5 に対して正規分布の臨界値 1.96 を用いると 5 ± 1.96 × 0.756 で、大まかに 3.52〜6.48 です。標本数が 8 と少ない場合は正規分布ではなく t 分布の臨界値を使うのが正しく、その話は [仮説検定](#/post/adsp-hypothesis) で続きます。
</details>

## よく出る問題タイプ

- 尺度の区別（名義/順序/間隔/比率）を見極める例題
- 層化抽出と集団抽出の違いを選ぶ問題
- 平均・中央値・最頻値の中で外れ値に敏感でないものを選ぶ問題
- 標準化値の計算 (z = (x − 平均) / 標準偏差)
- 標準誤差 σ / √n の計算、標本サイズに伴う変化
- 信頼区間の解釈で誤っている文句を選ぶ問題

問題本文は引用していません。過去問は公式サイトや試験機関の資料を直接解くのが適切で、試験日程や受験に関する情報も公式サイトで確認する必要があります。
