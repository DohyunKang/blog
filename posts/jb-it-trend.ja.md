新技術用語の単元は範囲が決まっていないため最も苦戦しやすい。クラウド、ビッグデータ、AI、ブロックチェーン、IoT が一つの問題としてセットで出ることがある。この単元は深く理解するよりも、「この用語は何の問題を解決するために登場したか」を一言でまとめておく方が効率的である。試験日程・受験料は公式サイトで確認し、ここでは概念と解き方の整理のみ行う。

## まず全体像

| 組 | 代表用語 | 解決しようとする問題 |
|---|---|---|
| インフラ | クラウド、仮想化、コンテナ | サーバーを購入・設置にかかる時間・コスト |
| データ | ビッグデータ、NoSQL、データレイク | 既存の DB で扱うのが難しい大量かつ多様なデータ |
| 知能 | 人工知能、機械学習、ディープラーニング | 人間が一つずつルールを組むのが難しい判断 |
| 信頼 | ブロックチェーン | 中央機関なしで記録を信頼させる |
| 接続 | IoT、5G、エッジコンピューティング | 物から発生するデータを近くで素早く処理 |

問題では通常定義文を与えて用語を選ばせるため、用語名よりも定義文のキーワードを一緒に覚える方がよい。

## クラウドコンピューティング

クラウドの定義で最も引用されているのは米国 NIST の定義である。共有された計算資源（ネットワーク、サーバー、ストレージ、アプリケーション、サービス）をどこからでも必要な時にネットワークを通じて利用でき、最小限の管理で借りて返せるモデルという。この定義には特徴 5 つ、サービスモデル 3 つ、デプロイメントモデル 4 つが付け加えられている。

[詳しく → クラウド基礎](#/post/cloud-basics)

### 必須の特徴 5 つ

| 特徴 | 一言で |
|---|---|
| オンデマンドセルフサービス | 人の手を介さずユーザー自身が資源を割り当てられる |
| 広範なネットワークアクセス | 標準的な方法でネットワークを通じて様々な端末からアクセスできる |
| リソースプーリング | プロバイダーの資源を複数の顧客が共有して使う（マルチテナント）ことで、需要に応じて割り当てが変わる |
| 迅速な弾力性 | 需要に合わせて素早く増減させる |
| 計測可能なサービス | 使用量を計測して制御・報告し、通常は使った分だけ支払う |

増減する方についてはオートスケーリングと関連付けて見ると理解が早い。[詳しく → オートスケーリング](#/post/infra-autoscaling)

### サービスモデル 3 つ

3 つのモデルは「顧客がどこまで管理するか」で区別される。

| モデル | 顧客が使っているもの | 顧客が管理しているもの | 例 |
|---|---|---|---|
| IaaS | サーバー・ストレージ・ネットワークなどの基本資源 | OS、ストレージ、デプロイされたアプリ | 仮想サーバーを借りて使う |
| PaaS | アプリを実行する開発・実行環境 | デプロイされたアプリと環境設定 | コードだけアップロードすれば動くプラットフォーム |
| SaaS | プロバイダーが完成させたアプリケーション | ユーザーごとの設定程度 | ウェブメール |

IaaS、PaaS、SaaS の順で顧客が管理する範囲は狭まる。問題で「OS まで直接管理」が出れば IaaS、「アプリケーションだけアップロード」なら PaaS、「ブラウザだけで使う」なら SaaS とほぼ整理できる。

### デプロイメントモデル 4 つ

| モデル | 一言で |
|---|---|
| プライベート | 一つの組織だけが使えるように構成されたクラウド |
| コミュニティ | 共通の関心やセキュリティ要件・規制などがある複数の組織が共有して使う |
| パブリック | 一般大衆が使えるように公開されたクラウド |
| ハイブリッド | 2 つ以上のクラウドを標準技術・固有技術で結び、データやアプリを移動できるようにしたもの |

<details>
<summary>試験で混同しやすいペア</summary>

- プライベートとオンプレミスは同じ意味ではない。NIST の定義上プライベートクラウドは組織内にある場合でも、第三者が運営する外部にある場合でもよい。
- パブリックの核心は「大衆が使っている」であり、ハイブリッドの核心は「2 つ以上を結び合わせた」ことである。
- サーバーレスはサーバーがないという意味ではなく、サーバー管理をプロバイダーが担当するという意味で使う。[詳しく → サーバーレス](#/post/cloud-serverless)

</details>

## 仮想化とコンテナ

仮想化とは物理サーバー一台の上に複数の仮想サーバーを構築する技術である。各仮想サーバーには個別に OS が動作する。コンテナは OS カーネルを共有しながらアプリケーションとその実行に必要なものだけを束ねて隔離する方法であり、仮想サーバーよりも軽量だと説明するのが一般的である。この違いは OS 単元のプロセス・カーネル概念と続く。[詳しく → オペレーティングシステム](#/post/jb-os)

コンテナが増えるとバッチ処理、再起動、置換を自動で行うツールが必要になるが、その役割を果たすのが Kubernetes である。Kubernetes の公式ドキュメントでは、コンテナ化されたワークロードとサービス进行管理するための移植性の高いオープンソースプラットフォームとして紹介している。機能としてはサービスディスカバリーとロードバランシング、レスポンスがないコンテナを蘇らせるセルフヒーリング、宣言した望ましい状態に実際の状態を合わせる自動ロールアウト・ロールバックが含まれる。[詳しく → Docker とコンテナ](#/post/cloud-docker)

## ブロックチェーン

ブロックチェーンは、ビットコインの論文から始まりました。この論文では、銀行のような信頼できる機関なしで当事者同士が直接お金の送金を行うためには二重支払いを防ぐ必要があると指摘し、これを P2P ネットワークで解決することを提案しています。取引をハッシュで結び、プルーフ・オブ・ワーク（Proof-of-Work）が続く連鎖にタイムスタンプを付け、この連鎖はプルーフ・オブ・ワークを行わなければ変更できません。ノードは最も長い連鎖を正解として受け入れます。

試験用に簡略化すると以下のようになります。

| 用語 | 一言で表す |
|---|---|
| ブロック | 取引の束と前ブロックのハッシュを含む単位 |
| プルーフ・オブ・ワーク | 計算作業を行ったことを示し、連鎖にブロックを繋ぐ方式 |
| 分散台帳 | 単一地点ではなく、参加ノードが同じ記録を共有する構造 |
| 二重支払い | 同じお金を 2 回使うこと |

ハッシュと暗号の概念は情報セキュリティ分野と重複します。[詳細 → 情報セキュリティ](#/post/jb-security)

## データと AI の用語

このまとめは、問題で定義を問う形式がほとんどなので表に整理しました。

| 用語 | 一言で表す |
|---|---|
| ビッグデータ | 従来の方法では保存・処理・分析が困難なほど大きく、多様で速やかに発生するデータ |
| NoSQL | 関係型テーブルモデル以外の方式（キー・バリュー、ドキュメントなど）でデータを扱う DB |
| データウェアハウス | 分析用に整理して蓄積した統合ストレージ |
| データレイク | 整理せずに元のデータをそのまま蓄えるストレージ |
| 人工知能 | 人間の知能が行う作業をコンピュータに行わせる技術の総称 |
| マシンラーニング | ルールを直接書かずにデータからパターンを学習させる方式 |
| ディープラーニング | 複数の層を持つニューラルネットワークで学習するマシンのラーニングの一分野 |
| 生成 AI | テキストや画像など新しい結果物を生成する AI |

包含関係は、人工知能の中にマシンのラーニングがあり、その中にディープラーニングがあります。この順序を逆にした出題がよく見られます。最近では LLM の話は AI 用語辞典の項目に別途整理しました。[詳細 → LLM](#/post/ai-llm)、[詳細 → 生成 AI](#/post/ai-generative)、[詳細 → NoSQL](#/post/db-nosql)

## 接続技術

| 用語 | 一言で表す |
|---|---|
| IoT | 物にセンサーと通信機能を付与してインターネットで繋ぎ、データをやり取りすること |
| エッジコンピューティング | データが発生する場所の近くで処理し、遠くのデータセンターへの流量と遅延を減らす方式 |
| 5G | 移動通信世代の一つで、多数の機器を接続し、遅延を減らすことに重点を置いています |

ネットワークに関する基礎知識は別の単元にあります。[詳細 → ネットワーク](#/post/jb-network)

## 問題の解き方

1. 選択肢に用語の英語略語がある場合は、フルネームから連想します。IaaS は Infrastructure as a Service のようにです。
2. 定義文からキーワードを見つけます。「管理範囲」「中央機関なし」「元データのまま」などの言葉が答えを絞り込みます。
3. 似たようなペアは違いを一行で整理しておきます。ウェアハウスとレイク、プライベートとパブリック、マシンのラーニングとディープラーニングなどが代表的です。
4. 新しい用語は毎年変わる可能性があるため、過去問よりも最新の公式出題基準と教科書の用語リストを併せて確認します。過去問の原文をそのまま写すのではなく、概念として再整理しておく方が長く役立ちます。

<details>
<summary>暗記用のペア作り</summary>

- IaaS は「敷地」、PaaS は「家を建てる工房」、SaaS は「完成した家」と捉えると管理範囲が視覚的に理解できます。
- ブロックチェーンは「共有台帳、1 ページを破れば次のページもすべて狂う台帳」とイメージするとハッシュの繋がりが記憶に残ります。
- コンテナは「OS を一緒に使う引越しボックス」、仮想サーバーは「家をまるごと分割したもの」です。

</details>
