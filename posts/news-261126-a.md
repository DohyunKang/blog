오늘 아침 GitHub 트렌딩 일간 목록에 cathrynlavery/diagram-design이 있었다. 오늘 하루 별 1,133개, 레포 전체 별은 73,004개다(11월 26일 오전 확인). 코딩 에이전트에게 다이어그램 그리는 법을 가르치는 스킬이다. "프론트엔드, 백엔드, DB, Redis 캐시로 구성도 그려 줘"라고 말하면 에이전트가 종류를 고르고 계획을 한 줄로 말한 뒤 HTML 파일 하나를 쓴다. 더블클릭하면 열린다. 나는 README, SKILL.md, CHANGELOG, PRIVACY.md, 검사 스크립트 두 개의 앞부분을 읽었다. 직접 설치해서 그려 보지는 않았다.

## 뭘 하는 건지
스킬은 에이전트가 특정 일을 할 때 꺼내 읽는 지침 묶음이다. SKILL.md 한 장과 참고 문서, 스크립트가 같이 들어 있다. 이 레포는 그 형식을 따르고 있어서 Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI 같은 곳에 `npx skills add cathrynlavery/diagram-design` 한 줄로 들어간다.

결과물은 SVG를 품은 HTML 파일 한 장이다. SVG는 점·선·글자를 좌표로 적는 벡터 그림 형식이라 확대해도 안 깨진다. 외부 파일을 따로 안 불러서 메일에 붙이거나 문서에 넣기 편하다. 구성도, 시퀀스, 상태도, ER, 간트, 사분면, 퍼널 같은 52가지 종류를 다룬다. PNG, 단독 SVG, 인쇄용 PDF로 내보내는 스크립트도 들어 있다. draw.io, Mermaid, Excalidraw, PlantUML 파일을 읽어서 이 스타일로 다시 그리는 기능도 있다.

README 부제가 "No shadows. No Mermaid slop."이다. 에이전트한테 그림을 시키면 그림자 넣고 색 다 칠하고 화살표가 대각선으로 엉키는 흔한 결과가 나오는데, 그걸 안 나오게 하겠다는 얘기다.

## 취향을 규칙으로 적었다
SKILL.md를 읽어 보면 디자인 감각을 꽤 구체적인 숫자로 바꿔 놨다.

- 강조색은 한 그림에 1~2곳만. 다섯 곳에 칠하면 강조가 사라진다고 적혀 있다.
- 밀도 목표는 10점 만점에 4. 노드가 9개를 넘으면 그림 두 장으로 나누라고 한다.
- 화살표는 직각으로만 꺾고 모서리는 반지름 8px로 둥글린다. 대각선은 실패로 친다.
- 화살표 라벨은 14자 이하, 대문자, 선에서 6~10px 띄운다.
- 노드 위치와 크기, 간격은 전부 4의 배수.

그리기 전에 먼저 물어보는 것도 있다. "표나 문단으로 써도 되는 거면 그리지 마라." 철학 항목 첫 줄이 "제일 좋은 수는 보통 지우는 것"이다. 다 그린 뒤에는 노드를 하나 빼도 이해되는지, 두 노드를 합칠 수 있는지, 화살표를 빼도 되는지 체크리스트로 다시 본다.

처음 쓰는 프로젝트에서는 바로 안 그린다. 색과 글꼴이 아직 기본값이면 웹사이트 주소, 디자인 시스템 폴더, 직접 붙여 넣은 토큰 중 뭘로 맞출지 사용자에게 묻고 멈춘다. 사이트 주소를 주면 그 사이트 색과 글꼴을 가져와 이후 그림에 계속 쓴다.

## 마지막 확인은 스크립트가 한다
읽으면서 제일 눈에 띈 건 이 부분이었다. 규칙을 문서에만 적어 두지 않고, 결과 파일을 검사하는 파이썬 스크립트를 스킬 안에 같이 넣었다.

`self_check.py`는 외부 라이브러리 없이 돈다. 접근성 규칙(`<svg>`에 `role="img"`, 제목과 설명 태그), 허용한 글꼴 말고는 외부 파일을 안 부르는지, 스크립트 실행 속성이 없는지, 그림이 화면 밖으로 안 나가는지, 파일이 중간에 끊기거나 글자가 깨지지 않았는지를 본다. 접근성은 화면 읽기 프로그램을 쓰는 사람도 내용을 알 수 있게 하는 것이다.

`verify_geometry.py`는 화살표 라벨 뒤에 깔린 바탕 사각형이 나중에 그려진 노드에 가려지지 않는지, 화살표가 직각 규칙을 지키는지 본다. 에이전트가 그린 뒤 이걸 돌리고, 통과 못 하면 고치는 흐름이다. 사람이 그림을 보고 "선이 겹쳤네"라고 말하기 전에 기계가 먼저 걸러 주는 셈이다.

레포 자체도 비슷하게 돌아간다. CHANGELOG를 보면 명도 대비 검사(WCAG)가 CI에 들어가 있고, 모든 예시 그림을 Chromium에서 렌더링해 보는 검사도 있다. 버전 번호는 사람이 안 올리고 main에 합쳐질 때마다 워크플로가 올린다. 그래서 11월 25일 기준 2.6.179까지 와 있다.
