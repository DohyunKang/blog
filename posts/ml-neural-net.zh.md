神经网络是一个由层层堆叠的“乘加后弯曲”计算构成的函数，而反向传播则是一种从输出端开始，逆向计算出内部数字（权重）应如何调整的方法。

## 单个神经元

神经元听起来名字很宏大，但其计算过程其实很简单。它将输入数字与权重相乘并求和，再加上偏置（bias），最后通过激活函数。

```
출력 = 활성화( w1*x1 + w2*x2 + ... + b )
```

权重和偏置是随学习而改变的数值。关于什么是学习、损失函数以及梯度下降法，已在 [详细 → 机器学习·深度学习基础](#/post/ml-basics) 中单独介绍，此处仅关注将其应用于神经网络的部分。

## 层与激活函数

将神经元排成一行即为层（layer）。依次连接输入层 → 隐藏层 → 输出层便构成了神经网络。每一层通过一次矩阵乘法进行计算。例如，若有 2 个输入和 4 个神经元，则权重为 2×4 的矩阵。

然而，如果没有激活函数，无论堆叠多少层都毫无用处。因为连续两次进行矩阵乘法等同于合并为一个矩阵进行一次乘法，最终只能表达线性关系。只有在中间插入非线性函数，堆叠多层才有意义。

| 函数 | 形状 | 用途 |
|---|---|---|
| Sigmoid | 压缩至 0~1 之间 | 用于输出概率类结果 |
| tanh | 压缩至 -1~1 之间 | 小型神经网络的隐藏层常用 |
| ReLU | 负数置零，正数保持不变 | 深层神经网络默认选择 |

ReLU 成为默认值的原因在于其计算成本低，且在正数区域斜率为 1，即使网络很深，信号衰减也较少。

## 前向传播

将输入送入网络并逐层传递以获得输出的过程称为前向传播（forward）。通过损失函数比较输出与正确答案，生成一个数值（即损失）。学习的目标就是朝着减小该损失的方向微调权重。

问题在于权重数量可能高达数千万甚至数千亿。如果逐一尝试“稍微增加一点权重，损失会如何变化”，则需对每个权重重复前向传播。反向传播正是通过一次逆向计算来解决这一问题。

## 反向传播：逆向乘法

反向传播（backpropagation）的本质是链式法则（chain rule）。若函数形式为 f(g(x))，则 x 对 f 的影响等于"x 对 g 的影响 × g 对 f 的影响”。神经网络是由多个嵌套函数组成的结构，因此可以从损失出发，逐层回溯并累积影响（梯度），从而求得所有权重的梯度。

CS231n 笔记用串联的电路来解释这一过程：每个门仅知晓其输入对应的局部梯度。将后方传来的梯度乘以该局部梯度后向前传递即可完成。由此可归纳出几条规则：

- 加法门将梯度原样传递给两侧；
- 乘法门将相对输入值相乘后传递（即交换两个输入值）；
- 若某变量被多处使用，则需将各分支的梯度相加；
- 前向传播时保存中间结果，以便在反向传播时复用。

正因最后一项规则，学习过程中会占用大量内存。推理时可以丢弃中间值，但学习时必须保留用于反向传播。

根据维基百科的总结，严格来说，“反向传播”仅指计算梯度的部分，而利用所求梯度更新权重则是 SGD 或 Adam 等优化器的工作。在日常对话中，人们常将两者合并称为“通过反向传播进行学习”。

其高效性也正源于此：只需为每一层计算一次梯度并在前一层复用，相比逐个重新计算每个权重的梯度，效率高出许多。1986 年 Rumelhart、Hinton 和 Williams 的论文引用为首次广泛推广该方法用于训练隐藏层，但维基百科指出类似思想曾多次被独立发现，背后有着复杂的交织历史。

## 亲手实现的 XOR

XOR（仅当两个输入不同时输出 1）无法用单一直线分割，因此若无隐藏层则无法解决。此处使用纯 NumPy 构建了一个含 4 个神经元的神经网络并运行测试，代码为手写反向传播版本。

```python
import numpy as np
rng = np.random.default_rng(1)
X = np.array([[0,0],[0,1],[1,0],[1,1]], dtype=float)
y = np.array([[0],[1],[1],[0]], dtype=float)
W1 = rng.normal(0, 1, (2, 4)); b1 = np.zeros((1, 4))
W2 = rng.normal(0, 1, (4, 1)); b2 = np.zeros((1, 1))
sigmoid = lambda z: 1 / (1 + np.exp(-z))
lr = 1.0
for step in range(5001):
    # 순전파
    h = np.tanh(X @ W1 + b1)
    p = sigmoid(h @ W2 + b2)
    loss = np.mean((p - y) ** 2)
    # 역전파: 출력 쪽에서 거꾸로
    dp = 2 * (p - y) / len(X)
    dz2 = dp * p * (1 - p)            # 시그모이드 미분
    dW2 = h.T @ dz2; db2 = dz2.sum(0, keepdims=True)
    dh = dz2 @ W2.T
    dz1 = dh * (1 - h ** 2)           # tanh 미분
    dW1 = X.T @ dz1; db1 = dz1.sum(0, keepdims=True)
    # 경사하강법
    W1 -= lr * dW1; b1 -= lr * db1; W2 -= lr * dW2; b2 -= lr * db2
    if step % 1000 == 0:
        print(step, round(float(loss), 4))
print(np.round(p, 2).ravel())
```

运行结果（NumPy 2.5.4, Python 3）：

```
0 0.24
1000 0.0008
2000 0.0003
3000 0.0002
4000 0.0002
5000 0.0001
[0.   0.99 0.99 0.01]
```

损失从 0.24 下降至 0.0001，输出收敛至 [0, 1, 1, 0]。此外，还通过数值微分验证了反向传播的正确性：将单个权重极小量扰动后重新计算损失变化为 -1.2166e-05，而反向传播求得的梯度为 -1.2169e-05，两者几乎一致。因此，亲手编写的反向传播代码值得如此对照验证。

有趣的是当随机种子设为 0 时的情况：相同代码在损失约 0.125 处停滞，输出固定为 [0.01, 0.5, 0.99, 0.5]。这证明了若初始权重不佳，模型可能陷入局部极小值。种子 1~4 均成功求解。

<details>
<summary>逐行解析反向传播代码</summary>

损失函数为 $L = \text{mean}((p - y)^2)$，其中 $p = \sigma(z_2)$，$z_2 = h \cdot W_2 + b_2$，$h = \tanh(z_1)$，$z_1 = X \cdot W_1 + b_1$。我们沿损失函数反向逐层计算梯度。

1. $dp = \partial L / \partial p = 2(p - y) / N$。这是平方误差的导数。
2. $dz_2 = dp \cdot p(1 - p)$。这里利用了 Sigmoid 函数的导数为 $\sigma(1 - \sigma)$。
3. $dW_2 = h^\top \cdot dz_2$。由于 $z_2 = h \cdot W_2$，因此关于 $W_2$ 的梯度是 $h$ 与 $dz_2$ 的乘积形式。这完全符合“乘法门”将相对输入相乘并传递的规则。
4. $dh = dz_2 \cdot W_2^\top$。这是同一乘法运算中流向 $h$ 的梯度。
5. $dz_1 = dh \cdot (1 - h^2)$。$\tanh$ 的导数为 $1 - \tanh^2$。
6. $dW_1 = X^\top \cdot dz_1$。第一层的结构也相同。

偏置项的梯度直接接收加法门的输出，并对 4 个样本求和（`sum(0)`）。每一行都是“来自后方的梯度 × 该门函数的局部梯度”。
</details>

## 常见误区

- “神经网络模仿大脑”的说法仅源于其名称由来，实际计算基于上述矩阵乘法与非线性函数。
- 反向传播并非整个学习算法，它仅用于计算梯度；参数更新由优化器完成。
- 单纯增加层数并不总是有益的。若激活函数选择不当，梯度在穿过多层时会变得过小或过大，导致无法学习。因此出现了 ReLU、残差连接等机制。
- “神经网络是万能逼近器”这一说法在理论上意味着只要网络足够大，就能逼近任意函数，但这并不意味着一定能学好。例如像种子 0 这样的案例，训练也可能失败。
