仮説検定とは、「帰無仮説が正しいと仮定したときに、現在得られた結果がどれほど珍しいか」を計算し、十分に稀であれば帰無仮説を棄却する手順のことです。ADsP では用語の区別、誤りの種類、状況ごとの検定の選択が繰り返し出題されます。

## まず用語について

- 帰無仮説 (H0): 「差がない」「効果がない」など、「デフォルト」としての主張。検定はこの仮説を基準に進められます。
- 対立仮説 (H1): 研究者が見たい主張。差がある、効果がある。
- 検定統計量: サンプルから計算された値。t 値、F 値、カイ二乗値などがこれに該当します。
- 有意水準 (α): 帰無仮説が真であるにもかかわらず棄却してしまう確率の上限。通常は 0.05 を使い、0.1 や 0.01 も使います。検定を行う前に設定しておきます。
- p 値: 帰無仮説が正しいと仮定したとき、観測された値と同じかそれより極端な値が出る確率です。
- 棄却域: 検定統計量がこの区間に含まれると帰無仮説を棄却する区間。境界値が臨界値です。

NIST ハンドブックの説明によれば、α = 0.05 は「帰無仮説が真である場合、約 5% の確率で棄却してしまう」という意味であり、臨界値を超えることと p < 0.05 は同じ決定となります。試験ではこの二つを結びつけて問われることがあります。

## 判断ルール

| 状況 | 決定 |
|---|---|
| p 値 < α | 帰無仮説の棄却、対立仮説の採用 |
| p 値 ≥ α | 帰無仮説の棄却はできない |
| 検定統計量が棄却域外 | 帰無仮説の棄却（＝棄却できない） |

「棄却できない」と「帰無仮説が正しいと証明された」は異なります。「証拠が不足している」という意味に過ぎず、選択肢に「帰無仮説を採用する」があれば問題文をもう一度よく読む必要があります。

p 値に関する一般的な誤解も試験に出題されます。p 値は「帰無仮説が真である確率」ではありません。帰無仮説が真であるという仮定の下で、データがこのほど極端になる確率です。効果の大きさを示す値でもなく、サンプルサイズが非常に大きい場合、差が小さくても p 値は小さくなる可能性があります。

## 第 1 種誤りと第 2 種誤り

| | 実際には帰無仮説が真 | 実際には帰無仮説が偽 |
|---|---|---|
| 棄却する | 第 1 種誤り (α) | 正しい決定（検出力） |
| 棄却できない | 正しい決定 | 第 2 種誤り (β) |

- 第 1 種誤り: 真である帰無仮説を棄却する。確率は有意水準 α です。
- 第 2 種誤り: 偽である帰無仮説を棄却できない。確率は β です。
- 検出力: 1 − β。実際に差がある場合、それを捉える確率です。

暗記のポイントは「第 1 種 = ないのにあるとみなす（虚報）、第 2 種 = あるのにないとみなす（漏報）」です。サンプルサイズをそのままにして α を下げると β は大きくなります。両方を同時に下げたい場合はサンプルサイズを増やす必要があります。この関係は選択肢で頻繁に変化して出題されます。

## 片側検定と両側検定

対立仮説が「異なる」場合は両側、「大きい」や「小さい」といった方向性がある場合は片側です。両側検定では α を左右の裾に半分ずつ配分します。例えば α = 0.05 の両側の場合、一方の裾は 0.025 です。同じデータにおいて、両側 p 値が片側 p 値の 2 倍になる対称分布（t 分布など）を仮定します。

## 状況ごとの検定の選び方

問題で最も多く問われるのは「この状況ならどの検定か」です。変数の種類と集団の数で判断できます。

| 状況 | 検定 |
|---|---|
| 一つの集団の平均が基準値と異なるか | 単標本 t 検定 |
| 異なる二つの集団の平均比較 | 独立標本 t 検定 |
| 同じ対象の前後比較（ペアデータ） | 対応標本 t 検定 |
| 三集団以上の平均比較 | 分散分析 (ANOVA, F 検定) |
| カテゴリ変数の二つが関連しているか | カイ二乗独立性検定 |
| 観測頻度が期待分布と合致するか | カイ二乗適合度検定 |

核心は、平均の比較には t と F、カテゴリ頻度にはカイ二乗を使うことです。集団が二つなら t 検定、三つ以上なら分散分析です。集団が三つで t 検정을をペアごとに複数回繰り返すと第 1 種誤りが蓄積するため、分散分析を使います。

[詳細 → 統計分析の基礎](#/post/adsp-stat-basic) では確率分布と推定を先に読むことで、t 分布、カイ二乗分布、F 分布がどこから導かれるかが続きます。

## t 検定

t 検定は母集団の分散が分からない場合、サンプルの標準偏差を用いて平均を比較します。独立標本の場合には、二つの集団の分散が等しいとみなす方式（等分散仮定）と、等しいと仮定しない Welch の方式があります。SciPy ドキュメントでは `ttest_ind` のデフォルトは `equal_var=True`(等分散仮定) であり、`equal_var=False` にすると Welch t 検定になり自由度が小数になることが説明されています。

試験では通常、以下のような内容を問います。

- 独立標本 t 検定は異なる二つの集団、対応標本は同じ対象の前後という区別。
- 正規性仮定。サンプルサイズが小さい場合は正規分布を仮定し、正規性が疑われる場合は非母数検定を使う程度。
- 帰無仮説を確認。「二つの集団の平均は等しい (μ1 = μ2)」。

## 分散分析

分散分析の名前は「分散」ですが、目的は平均の比較です。集団間の変動が集団内の変動よりもどれだけ大きいかが F 値で判断されます。

- 귀무가설: 모든 집단의 평균이 동일하다.
- 대립가설: 적어도 한 집단의 평균은 다르다.
- F 값이 크고 p 값이 작으면 귀무가설을 기각한다.

주의할 점은 분산분석에서 귀무가설을 기각해도 "어느 집단이 다른지"는 알 수 없다는 것이다. 이는 사후검정으로 별도로 확인해야 한다. 또한 대립가설을 "모든 집단의 평균이 서로 다르다"로 표현하면 틀리다.

## 카이제곱 검정

관측된 빈도와 귀무가설 하의 기대빈도를 비교한다. 통계량은 (관측 − 기대)² / 기대를 모두 더한 값이다. 독립성 검정의 자유도는 (행 수 − 1) × (열 수 − 1) 이다. 귀무가설은 "두 변수는 독립적이다"이며, 기각하면 두 변수 간에 관련성이 있다고 본다.

<details>
<summary>카이제곱 손으로 계산해 보기</summary>

성별과 제품 선호처럼 2×2 표가 다음과 같이 나왔다고 가정하자.

| | 선호 A | 선호 B | 합 |
|---|---|---|---|
| 집단 1 | 30 | 20 | 50 |
| 집단 2 | 20 | 30 | 50 |
| 합 | 50 | 50 | 100 |

기대빈도는 (행 합 × 열 합) / 전체이므로 각 칸마다 50 × 50 / 100 = 25 가 된다.

통계량 = (30−25)²/25 + (20−25)²/25 + (20−25)²/25 + (30−25)²/25 = 1 + 1 + 1 + 1 = 4.0

자유도는 (2−1)(2−1) = 1 이다. SciPy `chi2_contingency` 를 연속성 보정 없이 (`correction=False`) 실행하면 통계량 4.0, p 값 약 0.0455 가 나오며 손계산 결과와 일치했다. α = 0.05 라면 기각이다.

## 직접 돌려 보기

개념이 잘 와닿지 않아 작은 데이터로 파이썬에서 실행해 보았다. 값은 설명을 위해 임의로 생성한 것이다.

```python
import numpy as np
from scipy import stats

a = np.array([23, 25, 28, 30, 26, 24, 27, 29])
b = np.array([30, 32, 29, 35, 33, 31, 34, 36])

r = stats.ttest_ind(a, b)                    # 독립표본, 등분산 가정
print(r.statistic, r.pvalue)                 # -4.899, 0.000235

w = stats.ttest_ind(a, b, equal_var=False)   # Welch
print(w.statistic, w.pvalue)                 # -4.899, 0.000235

g1 = [20, 22, 19, 24, 25]
g2 = [28, 30, 27, 26, 29]
g3 = [33, 31, 35, 30, 32]
f = stats.f_oneway(g1, g2, g3)               # 분산분석
print(f.statistic, f.pvalue)                 # 31.04, 1.8e-05
```

두 집단 크기와 분산이 비슷하여 등분산 가정과 Welch 의 결과가 거의 동일하게 나왔다. p 값이 0.05 보다 훨씬 작아 귀무가설을 기각하는 사례다. 위 코드는 실제로 실행하여 확인한 값이다.

## 자주 나오는 유형과 풀이 순서

1. 문장에서 귀무가설과 대립가설을 구분하는 문제. "차이가 없다"는 귀무가설이다.
2. 결과 표를 주고 p 값과 유의수준을 비교해 결론을 고르는 문제. p 값 < α 라면 기각이다.
3. 오류 종류. 참인 것을 기각 = 1 종, 거짓인 것을 기각하지 못함 = 2 종.
4. 상황 → 검정 이름 연결. 집단 수와 변수 종류부터 확인한다.
5. 보기 중 틀린 설명 고르기. "p 값은 귀무가설이 참일 확률", "기각하지 못하면 귀무가설이 증명됨", "분산분석 기각 = 모든 집단이 다름"이 흔한 함정이다.

풀이는 이 순서로 진행한다. 먼저 검정 대상이 평균인지 비율·빈도인지 확인하고, 집단 수를 센다. 그다음 p 값과 α 를 비교해 결론을 도출한다. 용어 문제는 1 종/2 종 오류 표를 머릿속에 그려서 해결한다.
