非教師あり学習は、正解（ラベル）なしでデータそのものの構造を見つける手法である。試験ではクラスタリング分析、関連分析、次元削減の 3 つの分野に分けられ、それぞれ「どのような状況に使うか」と「主要な指標やパラメータは何か」を問われることが多い。正解がある側は [教師あり学習モデル](#/post/bd-supervised) に別途まとめた。

## まず 3 つの分野について

| 種類 | 行うこと | 代表的な手法 | 主要キーワード |
|---|---|---|---|
| クラスタリング分析 | 似たものを束ねる | K-means, 階層的クラスタリング, DBSCAN | 距離、クラスター数、シルエット |
| 関連分析 | 同時に発生する項目を見つける | Apriori | サポート、信頼度、リフト |
| 次元削減 | 変数を減らす | PCA | 分散説明率 |

クラスタリングは「顧客をいくつかのグループに分けるか」、関連分析は「A を購入した人は B も購入するか」、次元削減は「変数が多すぎるが削減できないか」といった状況である。問題文の状況を読み、3 つのうちどれに該当するかを選ぶ問題が多い。

## クラスタリング分析

距離が近い観測値同士を同じクラスターに束ねる。距離を使用するため、変数の単位が異なる場合、大きな単位の変数が距離を支配してしまう。そのため、クラスタリングの前には標準化がほぼ必須である。スケーリングの手法は [データ前処理](#/post/bd-preprocessing) で扱った。

### K-means

クラスター数 K を最初に定め、クラスター内の平方和（慣性、中心までの距離の 2 乗の和）を小さくするように中心を移動させながら束ねる手法である。scikit-learn のドキュメントでまとめられた特徴は以下の通りだ。

- クラスターが凸形で丸い形状であると仮定しており、細長いまたは不規則な形状には弱い。
- クラスター数を事前に指定する必要がある。
- 局所最小値に収束するため、初期中心によって結果が変わる。これを軽減する方法としてデフォルトの初期化である k-means++ が挙げられる。
- サンプル数が多くなっても比較的うまく動作する。

順序は覚えやすい。初期中心 K 個を定める、各点を最も近い中心に割り当てる、中心をクラスターの平均で更新する、変化がなくなるまで繰り返すという流れだ。平均を使用するため異常値に敏感である。異常値が心配な場合は、中心を実際の観測値として取る K-medoids を使うとまとめられている。

### K の選び方

試験によく出題されるのは以下の 2 つだ。

- エルボー法：K を増やしながら慣性を描き、曲がる点を選ぶ。慣性は K が大きくなると常に減少するため、この値だけでは選べない。
- シルエット係数：一点の (b - a) / max(a, b)。a は同じクラスター内の平均距離、b は最も近い別のクラスターまでの平均距離である。-1 から 1 の範囲で、1 に近いほどクラスターがうまく分かれている、0 付近ならクラスターが重なっている、負値なら誤った割り当てかもしれない。

<details>
<summary>実際に動かした結果 (K = 2~6)</summary>

3 つの分野で作った仮想データ (make_blobs, 300 件) を標準化し、K を変えて回した。

| K | inertia | シルエット |
|---|---|---|
| 2 | 187.8 | 0.688 |
| 3 | 18.3 | 0.848 |
| 4 | 15.5 | 0.679 |
| 5 | 12.7 | 0.522 |
| 6 | 10.7 | 0.357 |

inertia は K=2 から 3 に変える際に大きく曲がり、その後は緩やかになっている（エルボー）。シルエットも K=3 で最も高い。データを 3 つのグループで作ったため、正しく出たことになる。実際のデータではこの 2 つの指標が常にこれほどきれいに一致するわけではない。
</details>

### 階層的クラスタリング

クラスター数を事前に定めず、一点ずつ始めて近いクラスター同士を順次結合していく（凝集型）手法である。結合のプロセスを木のように描いたものがデンドログラムであり、どこで切るかでクラスター数が決まる。クラスター間の距離を測る方式（連結法）にはいくつかある。

| 連結法 | クラスター間の距離 |
|---|---|
| 単連結 | 2 つのクラスターで最も近い 2 点 |
| 全連結 | 2 つのクラスターで最も遠い 2 点 |
| 平均連結 | すべてのペアの距離の平均 |
| ワード連結 | 結合した際にクラスター内の平方和が最も少なくなるペア |

ワード連結は目的が K-means と似ており、ドキュメントの説明ではクラスターのサイズが最も均等になる傾向にある。単連結は鎖のように繋がってしまう傾向があると知られている。階層的クラスタリングは点ごとに距離をすべて計算するため、大きなデータには重い。上記の仮想データでワード連結、3 クラスターで回したところ、シルエットが 0.848 と K-means と同じだった。

### DBSCAN

密度に基づく手法である。半径 eps の中に min_samples 個以上の点があれば核点であり、核点同士を繋いでクラスターを作る。どの核点にも触れない点はノイズとしてラベル -1 が付与される。

- クラスター数を指定しない。
- 形状が自由である。
- 異常値をノイズとして別途除外する。
- eps が小さすぎるとほとんどが -1 になり、大きすぎるとクラスターが結合してしまう。

上記のデータで `eps=0.3`, `min_samples=5` を設定して実行したところ、3 つのクラスターと 1 つのノイズが出力されました。

## 関連分析

バスケット分析が代表的な例です。「A を買えば B も買う」というルールをアイテム集合から探します。ルールの強さは 3 つの値で測定します。

| 指標 | 式 | 意味 |
|---|---|---|
| サポート (Support) | P(A and B) | 全取引の中で A と B が同時に出現した割合 |
| 信頼度 (Confidence) | P(A and B) / P(A) | A が含まれる取引のうち、B も含まれる割合 |
| リフト (Lift) | 信頼度 / P(B) | B を単独で購入する確率に対する、A が存在する場合の B の購入確率の倍数 |

リフトが 1 より大きければ A と B は正の相関関係、1 なら独立、1 より小さければ負の相関関係です。信頼度が高くても、B が元々誰でも買う商品であればリフトは 1 に近くなります。この区別を問う問題があったため、一緒に暗記しました。

Apriori アルゴリズムは、「頻出集合の部分集合も必ず頻出である」という性質を利用して候補を絞り込みます。逆に言えば、ある集合が頻出でなければ、その集合を含むより大きな集合を検討する必要はありません。最小サポート以上の集合のみを広げて探索し、その上で最小信頼度を上回るルールを選定します。

<details>
<summary>5 件の取引を用いて手計算した値をコードで確認</summary>

取引 5 件: {牛乳, パン}, {牛乳, おむつ, ビール, パン}, {パン, ビール}, {牛乳, おむつ, パン}, {牛乳, おむつ, ビール}

```python
tx = [{'우유','빵'},{'우유','기저귀','맥주','빵'},{'빵','맥주'},
      {'우유','기저귀','빵'},{'우유','기저귀','맥주'}]
n = len(tx)
def sup(s): return sum(s <= t for t in tx) / n
for a, b in [({'기저귀'},{'맥주'}), ({'우유'},{'빵'})]:
    s = sup(a | b); c = s / sup(a)
    print(a, b, s, round(c, 3), round(c / sup(b), 3))
```

| ルール | サポート | 信頼度 | リフト |
|---|---|---|---|
| おむつ → ビール | 0.4 | 0.667 | 1.111 |
| 牛乳 → パン | 0.6 | 0.75 | 0.937 |

「牛乳 → パン」はサポートと信頼度がより高いものの、リフトは 1 より小さいです。パンは元々 5 件中 4 件に含まれているため、牛乳があるからといってパンをさらに買うわけではないことを示しています。「おむつ → ビール」は値が小さくてもリフトが 1 を超えています。
</details>

## 次元削減: PCA

変数間の相関が高い場合、情報（分散）を最大限に維持しつつ、互いに直交する新しい軸（主成分）に変換して変数の数を減らす手法です。最初の主成分が最も多くの分散を説明し、その後に続く成分が続きます。

- scikit-learn の PCA は平均引き算（中心化）は自動で行いますが、スケーリングは行いません。単位が異なる変数は事前に標準化しないと、大きな値を持つ変数が主成分を支配してしまいます。
- 何個を残すかは、説明分散比率の累積値を見て決定します。
- 主成分は元の変数の組み合わせであるため、解釈が難しくなるという代償があります。
- 変数選択（元の変数を選ぶこと）とは異なります。後者は [変数選択と次元削減](#/post/bd-feature-select) でまとめています。

<details>
<summary>iris データを用いて確認した説明分散比率</summary>

```python
from sklearn.datasets import load_iris
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
X = StandardScaler().fit_transform(load_iris().data)
p = PCA().fit(X)
print(p.explained_variance_ratio_.round(3))
print(p.explained_variance_ratio_.cumsum().round(3))
```

比率は 0.730, 0.229, 0.037, 0.005、累積は 0.730, 0.958, 0.995, 1.0 となりました。4 つの変数が 2 つの主成分によって分散の約 96% が説明されます。
</details>

## クラスタリング結果の確認とよくある落とし穴

- クラスタリングには正解がないため、精度で評価しません。シルエット係数などの内部指標や、集められた結果が業務的に解釈できるかを検討します。評価指標全般は [モデル評価](#/post/bd-evaluation) にあります。
- K-means は標準化を行わないと、単位が大きい変数が結果を左右してしまいます。
- エルボー法において慣性 (inertia) が K が増えるにつれて減少するのは当然であり、「K が大きいほど良いクラスタリング」というのは誤りです。
- DBSCAN の -1 はクラスター番号ではなくノイズを示します。
- 関連分析は信頼度だけでなくリフトも併せて見る必要があります。
- PCA 前に標準化を行わないと、単位が大きい変数が最初の主成分を占めてしまいます。
- データを学習用・テスト用に分割する概念は教師あり学習の話であり、クラスタリングにはそのまま適用できません。データ分割については [分析モデル設計](#/post/bd-model-design) でまとめています。
