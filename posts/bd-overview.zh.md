大数据分析师笔试从“大数据概述”开始。该章节没有计算题，绝大多数题目是要求准确区分术语，只要掌握每个词属于哪个范畴即可得分。内容主要分为四大部分：大数据的特征、数据类型、价值创造以及个人信息保护。

## 什么是大数据

IT 维基将大数据定义为：超过传统数据处理能力的海量数据，或者利用这些数据进行分析以创造价值的技术。拥有大量数据并不等同于就是大数据，还必须包含对其进行分析并加以利用的部分。在考试中，比起定义本身，更多时候会考察以 V 开头的特征。

## 按 V 来记忆特征

盖特纳（Gartner）提出的 3V 是基础。

| V | 含义 |
|---|---|
| Volume(规模) | 处理的数据量远超传统数据库 |
| Velocity(速度) | 数据的流入和流出速度极快 |
| Variety(多样性) | 种类繁多，包括非结构化数据和暗数据等 |

此外，IBM 等机构还补充了其他项目。

| V | 含义 |
|---|---|
| Veracity(可信度) | 在快速处理海量数据的同时保持其质量 |
| Value(价值) | 通过收集并快速处理来创造新价值 |
| Validity(有效性) | 能够准确分析此前无法处理的超大规模数据并进行预测 |
| Volatility(易变性) | 在处理结果具有意义的时间内完成处理 |

在 3V 基础上增加价值可归纳为 4V，再加上可信度则为 5V。不过，不同教材和机构对 V 的数量及构成有所不同。有的地方将 4V 中的第四个定义为可信度。因此，如果题目问“有几个 V"，请以教材为准；对于选项中出现的词汇，将其对应到具体的 V 并仔细辨析更为稳妥。

<details>
<summary>V 名称与含义的逆向练习</summary>

当选项给出的是解释而非名称时，可以这样解题：

1. 出现“量、大小、容量”等词，即为规模（Volume）。
2. 出现“实时、输入输出快”等词，即为速度（Velocity）。
3. 出现“文本、视频、日志”等混合种类的描述，即为多样性（Variety）。
4. 提到“保持质量”，对应可信度（Veracity）；提到“创造新价值”，对应价值（Value）。
5. 提到“准确的分析/预测”，对应有效性（Validity）；提到“在结果有效的期限内处理”，对应易变性（Volatility）。

可信度和有效性都带有“值得相信”的含义，容易混淆。建议将可信度归为数据质量方面，将有效性归为分析与预测的准确度方面，这样更容易区分。
</details>

## 数据类型

根据数据的结构是否固定进行分类。以 IT 维基为标准整理如下：

| 类型 | 说明 |
|---|---|
| 结构化数据 | 具有固定的格式和规则的值，支持机器读取和自动运算。例如 RDBMS 表、电子表格。 |
| 半结构化数据 | 拥有模式（Schema/结构定义），但无法直接进行运算。 |
| 非结构化数据 | 既没有模式，也无法直接进行运算。 |

可以理解为依据“是否有模式”和“是否可运算”两个标准划分：结构化数据两者皆具备；半结构化数据仅有模式；非结构化数据两者皆无。

大数据增长的核心因素并非结构化数据的增加，而是非结构化数据的激增。这是因为社交媒体（SNS）、智能手机、物联网传感器中不断涌现出文字、图片、视频和日志等数据。海量的半结构化数据通常使用 NoSQL 进行灵活查询和更新。关于存储方面的内容将在 [详见 → 数据采集与存储](#/post/bd-collection-storage) 中继续介绍。

通过 pandas 可以直观地看到半结构化数据实际上是如何转换为表格的。例如，使用 `json_normalize` 展开像 JSON 这样内部结构嵌套的数据。对于没有项目的单元格，则填充为 NaN。

```python
import pandas as pd

raw = [
    {"user": "u1", "tags": ["x", "y"], "geo": {"city": "서울"}},
    {"user": "u2", "geo": {"city": "부산", "dist": "해운대"}},
]
print(pd.json_normalize(raw))
```

执行后会出现 `user`、`tags`、`geo.city`、`geo.dist` 四个列，其中 u1 在 `geo.dist` 列为空，u2 在 `tags` 列为空。半结构化数据的特性在于每条记录拥有的项目可以不同，若要进行分析，则需先进行此类展开为表格的预处理。该步骤将在 [详见 → 数据预处理](#/post/bd-preprocessing) 中详细讨论。

## 价值创造

即使是相同的数据，其价值也会因使用者、使用时机及目的的不同而有所差异。因此，大数据的价值难以一次性定价。原因包括：利用方式的多样化、新价值的创造以及分析技术的发展。

按主体分类，可以这样记忆：

| 主体 | 变化/应用 |
|---|---|
| 企业 | 通过分析客户行为预测市场变化、降低成本、实现产品差异化 |
| 政府 | 利用气象、交通、人口数据制定政策、应对灾害 |
| 个人 | 以低廉价格享受服务，并根据自身目的利用数据 |

随着大数据的到来，数据处理方式在以下四个方面发生了改变。

| 之前 | 之后 | 变化原因 |
|---|---|---|
| 预处理 | 后处理 | 不预先设定格式，先收集数据再组合以发现隐藏信息 |
| 抽样调查 | 全面调查 | 处理成本降低，可对整体进行分析 |
| 质 | 量 | 收集的数据越多，即使存在部分错误，整体趋势也能显现 |
| 因果关系 | 相关关系 | 即使不了解原因，也可利用同时发生的现象 |

最后一行容易误解。使用相关关系并不意味着相关即因果。在需要追究因果的问题上（如政策效果或医学领域），仍然需要进行因果分析。这四组内容在 [详细 → 数据的价值与未来](#/post/adsp-data-value) 中关于 ADsP 的部分有单独整理，结合查看可厘清重复部分。

<details>
<summary>当选项颠倒方向时</summary>

本表以“之前 → 之后”的方向为核心，因此选项中只需改变方向即可构造错误句子。例如，“从全面调查变为抽样调查”、“从质变为量”等。只要记住“之后”对应的是后处理、全面调查、量、相关关系，就能迅速排除错误选项。
</details>

## 对个人信息进行脱敏使用

大数据大量涉及人员数据，因此必须采用个人信息脱敏方法，且具体方法随考试要求而定。2016 年 6 月由相关部门联合发布的《个人信息非标识化措施指南》指导了五种技术可单独或组合使用。金融委员会新闻稿中列出的技术名称如下：

| 技术 | 从名称推测的方向 |
|---|---|
| 假名处理 | 将标识值替换为其他值 |
| 汇总处理 | 使用合计、平均等聚合值代替单个值 |
| 数据删除 | 删除标识要素的全部或部分 |
| 范畴化 | 将值归并为区间或类别 |
| 数据掩码 | 遮盖部分内容使其不可见 |

新闻稿仅列出技术名称，未给出定义。建议对照教材掌握具体定义与示例。假名处理与掩码、汇总处理与范畴化名称相似，容易混淆，需从“是替换还是遮盖”、“保留单个值还是进行聚合”等角度加以区分记忆。

脱敏流程分为四个阶段：

1. 事前审查：判断是否属于个人信息。若不属于，可在无需额外措施的情况下使用。
2. 非标识化措施：利用上述技术消除标识要素。
3. 适当性评估：由外部评估团队审查措施是否适当。此时采用 k-匿名性等量化手段进行评估。
4. 事后管理：采取保护措施以确保安全使用和防止滥用。目的达成后予以销毁，管理访问权限；若发生再识别，则停止处理并销毁数据。

k-匿名性是指将具有相同值的记录数量提升至至少 k 条，从而使得难以推断特定个人的概念。当 k=5 时，意味着相同记录至少有 5 条。

曾使用 pandas 直接实现范畴化、掩码及 k 值验证：

```python
import pandas as pd

df = pd.DataFrame({
    "id":   [1, 2, 3, 4, 5, 6],
    "age":  [23, 27, 24, 41, 45, 43],
    "city": ["서울"] * 3 + ["부산"] * 3,
})

# 범주화: 나이를 구간으로 묶는다
df["age_grp"] = pd.cut(df["age"], bins=[20, 30, 40, 50],
                       labels=["20대", "30대", "40대"], right=False)

# k 확인: 같은 (나이대, 도시) 조합이 몇 건씩인지
sizes = df.groupby(["age_grp", "city"], observed=True).size()
print(sizes)
print("k =", sizes.min())

# 마스킹: 전화번호 뒷자리 가리기
phone = pd.Series(["010-1234-5678", "010-9876-5432"])
print(phone.str.replace(r"-\d{4}$", "-****", regex=True))
```

执行后显示“20 多岁·首尔”3 条、“40 多岁·釜山”3 条，k=3；电话号码变为 `010-1234-****`、`010-9876-****`。由此可见，通过范畴化将值归并后，相同组合数量增加，k 值也随之增大。本示例仅为展示结构而构建的小表，与实际适当性评估标准并不一致。

<details>
<summary>假名信息与假名处理的五个阶段</summary>

除指南外，《个人信息保护法》中另有“假名信息”的概念。个人信息保护委员会将假名信息定义为：经假名处理后，在不使用或结合额外信息进行还原的情况下，无法识别特定个人的信息。法律依据为《法》第 2 条第 1 款和第 28 条之 2。

适用于统计编制、科学研究及公益记录保存目的。其中，统计编制指生成关于特定群体的量化信息；科学研究指应用科学方法进行技术开发、基础研究或应用研究；公益记录保存指为公共利益而保留具有查阅价值的记录。

假名处理流程共五个阶段：事前准备（如设定目的）、风险评估、假名处理、适当性审查、安全管理。这与《非标识化措施指南》的四个阶段（事前审查、非标识化措施、适当性评估、事后管理）属于不同文件的流程。需根据题目出现的是哪一方的术语加以区分。
</details>

关于个人信息保护的总体框架，可参考 [详细 → 个人信息与隐私](#/post/sec-privacy) 部分另行了解。

## 本单元高频题型

原题原文未移至此处，仅整理题型：

- 特征选择：阅读描述后匹配 V 名称，或选出非特定 V 项。可靠性、有效性与价值常被混淆作为干扰项。
- 类型分类：将日志、JSON、表格、视频等示例划分为结构化、半结构化和非结构化数据。可通过是否存在 schema 以及是否支持运算来判断。
- 变化方向：判断是否朝向后处理、全面调查、量、相关关系等方向发展。
- 脱敏：匹配技术名称与说明，排列流程顺序，理解 k-匿名性的含义。

## 总结

- 3V 指规模（Volume）、速度（Velocity）和多样性（Variety），4V 增加价值（Value），5V 再增加可靠性（Veracity）。不同教材的构成有所不同，请以标准教材为准。
- 结构化数据同时具备 Schema（模式）和运算；半结构化数据仅有 Schema；非结构化数据则两者皆无。
- 大数据的变化体现在事后处理、全量调查、数据量以及相关关系的方向。
- 五种匿名化技术包括：假名化处理、汇总处理、数据删除、分类化和数据掩码。
- 匿名化流程为：事前审查 → 实施匿名措施 → 适当性评估（k-匿名性）→ 事后管理
