오늘 아침 GitHub 트렌딩(daily)에 mvanhorn/last30days-skill이 올라와 있었다. 오늘 별 952개, 레포 전체 별은 70,777개다(11월 20일 오전 확인). 주제 하나를 주면 Reddit, X, YouTube, Hacker News, GitHub 같은 데서 최근 30일 치 글을 한꺼번에 찾아, 사람들이 실제로 반응한 순서로 묶어 요약해 주는 에이전트 스킬이다. 나는 README, CONCEPTS.md, CONFIGURATION.md 일부, CHANGELOG를 읽었고 직접 돌려 보지는 않았다.

## 뭐 하는 물건인지
스킬은 에이전트가 필요할 때 꺼내 읽는 설명서 폴더다. [자세히 → 스킬](#/post/ai-skills) Claude Code에선 `/last30days 주제`로 부르고, Codex나 Cursor 같은 다른 에이전트에도 `npx skills add`로 깔린다. 만든 사람은 AI 쪽 소식을 따라가려고 만들었다고 적어 놨다. 모델의 학습 데이터는 늘 몇 달 늦고, 새로운 요령은 Reddit과 X에서 먼저 돈다는 이유다.

README의 주장은 한 줄로 이렇다. 검색 엔진은 편집된 글을 모으고, 이건 사람들의 반응을 모은다. 그래서 순위를 매길 때 Reddit 추천 수, X 좋아요, YouTube 자막 내용, Polymarket 배당 같은 참여 신호를 쓴다. Polymarket은 사건 결과에 돈을 거는 예측 시장이라, 배당이 곧 사람들이 매긴 확률이다.

## 안에서 어떻게 도는지
구조는 둘로 나뉜다. SKILL.md는 모델에게 어떤 플래그로 엔진을 부를지 알려 주는 설명서고, 실제 검색은 `scripts/last30days.py`라는 파이썬 엔진이 한다. 엔진이 정해진 모양으로 결과를 내면 모델은 그걸 그대로 넘겨 받아 요약한다.

1. 주제에서 핵심 대상을 뽑는다. "OOO 가격" 같은 주제면 "가격"을 떼고 OOO만 남긴다. 그 대상의 X 계정, GitHub 레포, 서브레딧, YouTube 채널을 먼저 찾아 둔다.
2. 질문을 여러 개로 쪼개 소스마다 따로 동시에 검색한다.
3. 같은 글이 여러 검색에 걸리면 정리된 URL 기준으로 하나로 합친다. 다른 플랫폼에서 같은 얘기를 하면 한 묶음(클러스터)으로 묶는다.
4. 대상 이름이 안 들어간 글은 반응이 아무리 커도 크게 깎는다. 남은 것만 참여도, 관련도, 최신성으로 줄 세운다.
5. 모델이 묶음별로 출처를 달아 브리핑 하나로 쓴다.

4번이 재밌었다. 문서에선 Entity grounding이라고 부르는데, 대상 이름의 첫 단어만 본다. 뒤쪽 단어는 대개 검색어 꾸밈말이라 다 요구하면 맞는 글까지 떨어뜨린다는 이유다. 반대로 대상이 "ai"나 "new"처럼 흔한 단어면 기준을 올려서, 주제와 상관없이 뜬 글이 자리를 못 차지하게 한다.

관련도 판단에 LLM을 쓸지는 고를 수 있다. OpenAI나 xAI, Gemini 같은 키를 넣으면 주제와 찾은 글 조각을 그 모델에 보내 다시 순위를 매기는 리랭킹을 한다. 키가 없으면 로컬 점수로 돌아간다. 키 없이도 Reddit, HN, Polymarket, GitHub는 바로 된다고 적혀 있다. 찾아온 글을 근거로 답을 쓰는 점에선 RAG와 비슷한 흐름이다. [자세히 → RAG](#/post/ai-rag)

주제 없이 돌리는 Discovery 모드도 있다. 요즘 뜨는 걸 알아서 찾아 주는 건데, 여러 소스에서 같이 보이거나 한 곳에서 아주 강하게 뜬 것만 보여 준다. 기준을 못 넘으면 억지로 채우지 않고 "확실한 게 없다"고 답하게 되어 있다. 이 부분은 문서에 원칙으로 박혀 있어서 좋았다.

## 입문자 입장에서
PM 입장에선 "요즘 사람들이 이걸 어떻게 말하냐"를 손으로 탭 열어 가며 찾던 일을 한 번에 묶어 보는 도구다. 미팅 전 상대 조사, 기능 만들기 전 사람들이 겪는 문제 찾기를 예로 든다. 다만 순위의 기준이 반응 수라서, 시끄러운 글이 맞는 글이라는 보장은 없다. 브리핑은 출발점으로 쓰고 원문은 따로 열어 보는 게 맞을 것 같다.

개발 입문자라면 소스마다 인증 방식이 다 다르다는 점을 먼저 보면 좋다. X는 기본적으로 브라우저에 로그인된 세션 쿠키를 읽는 경로가 앞에 있고, API 키를 쓰는 경로가 그 뒤에 있다. 쿠키를 읽기 전엔 동의를 묻고 `--no-browser-cookies`로 끌 수도 있다. Reddit 로그인 세션을 쓰는 옵션은 문서 스스로 Reddit 약관에 어긋날 수 있다고 적어 놨다. 돌리기 전에 `--preflight`로 무엇을 읽고 쓸지 먼저 확인할 수 있게 해 둔 것도 참고할 만하다. 다른 스킬 모음 얘기는 예전 글과 같이 보면 좋다.
