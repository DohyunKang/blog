Triple 是一个由主谓宾三个部分组成的句子，用来表达"A 与 B 存在某种关系”。收集大量这样的句子就构成了图，而预先定义用于该图的词汇含义和规则的就是本体（Ontology）。要理解知识图谱，首先需要了解这两者（[详情 → 知识图谱](#/post/ai-knowledge-graph)）。

## Triple

W3C 的 RDF 1.1 Primer 将 RDF 的句子描述为 `<subject> <predicate> <object>` 的形式。一个句子表示两个资源之间的关系，由三个部分组成，因此被称为三元组（Triple）。谓词也称为属性（property）。

| 主语 | 谓语 | 宾语 |
|---|---|---|
| 首尔 | 是首都 | 大韩民国 |
| 大韩民国 | 名称 | "대한민국" |
| 首尔 | 类型 | 城市 |

如果三元组之间共享相同的资源，它们就会连接起来。主语和宾语成为节点，谓语成为节点之间的箭头，从而构成图。在上表中，“首尔”出现在两行中，因此被归为一个节点。

如果用表格书写，看起来就像是一个只有三列的表，但区别在于单元格中的值不是字符串，而是全球通用的标识符。

## IRI 与字面量

根据 Primer，在 RDF 中指代资源的是 IRI（Internationalized Resource Identifier），它是 URI 的国际化版本，URL 也是 IRI 的一种形式。由于 IRI 是全局标识符，当其他人指代同一对象时可以直接复用。三元组的三个位置都可以填入 IRI。

例如，如果将“首尔”直接写成 `서울`，在不同文档中可能含义不同；而写成如 `http://example.org/city/Seoul` 这样的 IRI，则固定指向该地址所代表的单一对象（此地址仅为说明用途，由我自行创建）。

值（字面量）是非 IRI 的基本值，如字符串、日期、数字等，具有数据类型，且字符串可以附加语言标签。字面量只能出现在三元组的宾语位置。上表中用引号括起来的“대한민국”名称即为字面量。

没有标识符的资源用空白节点（Blank Node）表示。Primer 将空白节点比作代数中的简单变量。

## Schema 与本体所做的工作

仅有三元组的话，没有人会定义“是首都”这一谓词的含义。因此需要定义词汇的词汇表，在 RDF 中，RDF Schema (RDFS) 负责此项工作。Primer 介绍的组件如下：

| 元素 | 作用 |
|---|---|
| 类（Class） | 对资源进行分类的类别。个体通过 type 属性与类连接 |
| subClassOf | 声明一个类是另一个类的子类（层级关系） |
| subPropertyOf | 声明一个属性是另一个属性的子属性 |
| domain | 该属性的主语所属的类 |
| range | 该属性的宾语所属的类 |

通过定义这些类和关系类型，就构成了本体。OWL 2 Overview 文档将本体描述为“针对特定领域、由用户群体共享的结构化词汇”，并指出术语是通过与其他术语的关系来定义的。OWL 2 是一种形式上具有明确语义的本体语言，提供类、属性、个体和数据值。可以将其视为比 RDFS 表达能力更丰富的表达方式。OWL 2 本体主要通过 RDF 文档进行交换，任何 OWL 2 本体都可以被视为 RDF 图。

### 推理

由于语义被形式化定义，机器可以从现有三元组中推导出新的三元组。Primer 中的例子很简单：

- 事实：`ex:bob foaf:knows ex:alice`
- 声明：`foaf:knows` 的 domain 是 `foaf:Person`
- 推导：`ex:bob` 是 `foaf:Person`

尽管任何地方都没有说明 Bob 是人，但由于谓词的 domain 声明，这一结论自然得出。Primer 指出，当一个三元组集合蕴含另一个三元组时，称为 entailment（蕴含），推理机（reasoner）还能发现矛盾。例如，当声明为整数的值中出现了非整数字面量时，即为矛盾。

OWL 2 相关文档列举了推理机回答的查询类型：“类一致性、子集关系（subsumption）、实例检索”。此外，OWL 2 RL 推理被描述为“健全但通常不完全”，即推导出的结论可以信赖，但是否能找到所有可推导的结论则取决于具体的配置文件。

## 与属性图的区别

处理图的方式并非只有一种。属性图方式直接在节点和关系上附加属性进行存储，这在 [图数据库](#/post/ai-graph-db) 中应用广泛。RDF 的特点在于将所有内容以三元组形式展开，通过 IRI 共享实体与词汇，并且其模式（Schema）与推理规则均已标准化。与其说哪种更好，不如说两者的使用目的不同，这一点只需了解即可。本文未对两者进行直接对比，因此暂且搁置。

## 常见误解

- 本体论（Ontology）是哲学术语，难以理解：本文所讨论的内容，只需理解为定义了概念与关系的共享词汇即可。
- RDF 是一种数据库类型：RDF 是数据表达模型，而存储与查询需另行处理。
- 有了模式就能检查数据并防止错误：RDFS 的 domain/range 本质上是推导规则。如上文 Bob 示例所示，并非用于标记“错误”，而是表示“那么这也成立”。
- 进行推理就能得出所有结论：如上所述，OWL 2 RL 并不保证完备性（Completeness）。
- IRI 必须是可打开的网页地址：URL 仅是 IRI 的一种形式，IRI 的核心在于其作为全局标识符的特性。
