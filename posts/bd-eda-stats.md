탐색적 분석(EDA)은 모형을 만들기 전에 데이터가 어떻게 생겼는지 숫자와 그림으로 훑는 단계고, 시험에서는 그 밑바탕인 기초 통계 개념이 계산·해석 문제로 나온다. 시험 일정과 응시료는 공식 사이트에서 확인하면 된다.

## EDA가 하는 일

데이터를 받으면 바로 모형부터 돌리지 않고 먼저 본다. 변수가 몇 개고 어떤 타입인지, 값이 어디에 몰려 있는지, 튀는 값이 있는지, 변수끼리 같이 움직이는지. 이걸 보고 나서 결측치를 어떻게 할지, 변환이 필요한지 정한다. 전처리는 [자세히 → 데이터 전처리](#/post/bd-preprocessing)에서 따로 정리했다.

EDA에서 쓰는 도구는 크게 두 가지다.

| 도구 | 보는 것 | 대표 |
|---|---|---|
| 기술통계 | 한 변수의 중심·퍼짐·모양 | 평균, 중앙값, 표준편차, 사분위수 |
| 상관분석 | 두 변수가 같이 움직이는 정도 | 피어슨, 스피어만 상관계수 |

그림은 히스토그램, 상자그림, 산점도가 기본이다. 어떤 그림을 언제 쓰는지는 [자세히 → 시각화와 결과 해석](#/post/bd-visualization)에 있다.

## 기술통계

중심 경향은 평균, 중앙값, 최빈값이다. 이상값이 있으면 평균은 끌려가고 중앙값은 잘 안 움직인다. 이 차이가 시험에서 자주 나온다. 값이 `[2, 4, 4, 4, 5, 5, 7, 9, 30]`일 때 직접 계산해 보면 이렇다.

```python
import pandas as pd
s = pd.Series([2, 4, 4, 4, 5, 5, 7, 9, 30])
print(s.mean(), s.median(), s.mode().tolist())
# 7.777777777777778 5.0 [4]
```

30 하나 때문에 평균은 7.78이 되고 중앙값은 5다. 평균이 중앙값보다 크면 오른쪽으로 꼬리가 긴 분포(양의 왜도)고, pandas의 `skew()`는 이 데이터에서 약 2.70이 나왔다.

퍼짐은 분산, 표준편차, 범위, 사분위범위(IQR)다. 여기서 헷갈리는 부분이 하나 있다. 표본분산은 n이 아니라 n-1로 나눈다. pandas의 `var()`와 `std()`는 기본이 n-1이고, numpy는 기본이 n이다.

```python
print(s.var(), s.var(ddof=0))
# 73.44444444444444 65.28395061728395
```

같은 데이터에서 73.44와 65.28이 나온다. 시험 문제가 표본분산을 묻는지 모분산을 묻는지 먼저 봐야 한다.

상자그림의 이상값 기준은 Q1 - 1.5×IQR 아래, Q3 + 1.5×IQR 위다. 위 데이터는 Q1=4, Q3=7, IQR=3이라 울타리가 -0.5와 11.5고, 30만 밖에 있다.

```python
q1, q3 = s.quantile([.25, .75]); iqr = q3 - q1
print(s[(s < q1 - 1.5*iqr) | (s > q3 + 1.5*iqr)].tolist())
# [30]
```

<details>
<summary>왜도·첨도, 변동계수 짧게</summary>

- 왜도: 0이면 대칭, 양수면 오른쪽 꼬리가 길다, 음수면 왼쪽 꼬리가 길다.
- 첨도: 분포가 뾰족한 정도. 정규분포 기준으로 비교하는 값이라 쓰는 도구에 따라 3을 빼서 주기도 해서, 문제에서 기준이 뭔지 확인해야 한다.
- 변동계수: 표준편차 ÷ 평균. 단위가 다른 두 변수의 퍼짐을 비교할 때 쓴다.
- 산술평균과 달리 기하평균은 증가율처럼 곱으로 변하는 값에 쓴다.
</details>

## 상관분석

상관계수는 -1에서 1 사이고, 부호는 방향, 절댓값은 세기다. 피어슨은 선형 관계를 보고 이상값에 민감하다. 스피어만은 값을 순위로 바꿔서 계산해서 단조 관계를 보고, 순서형 자료나 이상값이 있을 때 쓴다.

```python
import numpy as np
from scipy import stats
x = np.array([1,2,3,4,5,6,7,8]); y = np.array([2,1,4,3,7,8,6,9])
print(stats.pearsonr(x, y))   # 상관계수 약 0.896, p 약 0.0026
print(stats.spearmanr(x, y))  # 상관계수 약 0.881, p 약 0.0039
```

pandas에서는 `df.corr(method="pearson")`이 기본이고 `"spearman"`, `"kendall"`을 고를 수 있다. 결측치가 있으면 두 열 모두 값이 있는 행만 써서 쌍마다 계산한다.

상관이 높다고 원인이라는 뜻은 아니다. 제3의 변수가 둘을 같이 움직이는 경우(가짜 상관)가 시험 단골 오답 선지다. 상관이 0에 가까워도 곡선 관계는 있을 수 있다. 상관 높은 변수를 다루는 방법은 [자세히 → 변수 선택과 차원 축소](#/post/bd-feature-select)에서 이어진다.

## 확률분포

시험에서 외워 둘 분포는 정해져 있다.

| 분포 | 쓰임 | 기억할 점 |
|---|---|---|
| 정규분포 | 연속형, 종 모양 | 평균±1σ 약 68%, ±1.96σ 95% |
| 이항분포 | n번 중 성공 횟수 | 시행이 독립, 성공확률 일정 |
| 포아송분포 | 단위 시간·공간의 사건 횟수 | 평균=분산 |
| t분포 | 모분산을 모를 때 평균 추정·검정 | 자유도가 커지면 정규분포에 가까워짐 |
| 카이제곱분포 | 분산 검정, 범주형 독립성·적합도 | 0 이상, 오른쪽 꼬리 |
| F분포 | 분산 비교, 분산분석 | 두 개의 자유도 |

표준정규분포 값은 외워 두면 편하다. scipy로 확인하면 이렇다.

```python
print(stats.norm.cdf(1.96), stats.norm.ppf(.975))
# 0.9750021048517795 1.959963984540054
print(stats.t.ppf(.975, 9), stats.chi2.ppf(.95, 3))
# 2.262157162798205 7.814727903251179
```

자유도 9의 t분포에서 양쪽 5% 임계값이 2.262고, 정규분포의 1.96보다 크다. 표본이 작을수록 꼬리가 두꺼워서 그렇다.

중심극한정리도 자주 나온다. 모집단이 정규분포가 아니어도 표본 크기가 충분히 크면 표본평균의 분포는 정규분포에 가까워진다는 내용이다. 표본평균의 표준오차는 σ/√n이라 표본이 4배 늘면 절반으로 줄어든다.

## 추정

점추정은 값 하나로, 구간추정은 범위로 모수를 말한다. 모분산을 모르는 정규 모집단의 평균 95% 신뢰구간은 표본평균 ± t(0.975, n-1) × s/√n이다.

```python
a = np.array([12.1,11.8,12.5,12.9,11.5,12.2,12.7,12.0,11.9,12.4])
m, se = a.mean(), stats.sem(a)
print(m, se, stats.t.interval(.95, len(a)-1, loc=m, scale=se))
# 12.2 0.1358... (11.8928, 12.5072)
```

신뢰수준 95%의 해석에서 많이 틀린다. "모평균이 이 구간에 있을 확률이 95%"가 아니라, 같은 방식으로 표본을 반복해 구간을 만들면 그중 약 95%가 모평균을 포함한다는 뜻이다. 신뢰수준을 올리면 구간은 넓어지고, 표본을 늘리면 좁아진다.

## 가설검정

순서는 늘 같다. 귀무가설(H0)과 대립가설(H1)을 세우고, 유의수준(보통 0.05)을 정하고, 검정통계량과 p-값을 구해서, p-값이 유의수준보다 작으면 H0를 기각한다.

- 제1종 오류: H0가 참인데 기각. 확률이 유의수준 α.
- 제2종 오류: H0가 거짓인데 기각하지 못함. 확률이 β, 검정력은 1-β.
- p-값은 H0가 참이라고 했을 때 지금 같거나 더 극단적인 결과가 나올 확률이다. H0가 참일 확률이 아니다.

검정은 자료 형태로 고른다.

| 상황 | 검정 |
|---|---|
| 한 집단 평균을 기준값과 비교 | 단일표본 t검정 |
| 두 독립 집단 평균 비교 | 독립표본 t검정 |
| 같은 대상의 전후 비교 | 대응표본 t검정 |
| 세 집단 이상 평균 비교 | 분산분석(ANOVA, F검정) |
| 범주형 두 변수의 독립성 | 카이제곱 검정 |
| 정규성 확인 | 샤피로-윌크 등 |

```python
print(stats.ttest_1samp(a, 12.0))
# 통계량 1.4726, p 0.1749, df 9  -> 평균이 12라는 H0를 기각 못 함

b = np.array([12.8,13.1,12.6,13.4,12.9,13.0,12.7,13.3,12.5,13.2])
print(stats.ttest_ind(a, b, equal_var=False))
# 통계량 -4.5136, p 0.000345, df 약 16.17  -> 두 평균이 같다는 H0 기각
```

scipy 문서에서 `ttest_ind`는 두 독립 표본의 평균이 같다는 귀무가설을 검정하고, `equal_var=True`가 기본이라 등분산을 가정한다. `False`로 두면 등분산을 가정하지 않는 Welch 검정이 된다. 위 결과의 자유도가 소수(16.17)로 나온 것이 Welch 검정의 특징이다.

카이제곱 독립성 검정은 관측도수와 기대도수를 비교한다.

```python
table = np.array([[30,20],[20,30]])
chi2, p, dof = stats.chi2_contingency(table, correction=False)[:3]
print(chi2, p, dof)
# 4.0 0.0455... 1
```

기대도수는 (행합 × 열합) ÷ 전체인데, 이 표에서는 모든 칸이 25다. 자유도는 (행 수-1)×(열 수-1)이라 1이다. 통계량이 4.0, p가 약 0.0455라 5% 수준에서는 독립이라는 H0를 기각한다. `correction=False`를 준 이유는 2×2 표에서 scipy가 기본으로 연속성 보정을 걸기 때문이고, 손으로 푸는 시험 풀이와 맞추려고 껐다.

<details>
<summary>정규성이 안 맞을 때</summary>

t검정과 ANOVA는 정규성을 가정한다. 표본이 작고 정규성이 의심되면 순위 기반의 비모수 검정(윌콕슨 순위합, 크루스칼-왈리스 등)을 쓴다. 비모수 검정은 [자세히 → 고급 분석 기법](#/post/bd-advanced-analysis)에서 이어서 본다.

```python
print(stats.shapiro(a))
# 통계량 0.9885, p 0.9947 -> 정규성을 기각할 근거 없음
```

샤피로-윌크의 H0는 "정규분포를 따른다"라서, p가 크면 정규성을 기각하지 못한다는 뜻이다. 정규라고 증명했다는 뜻은 아니다.
</details>

## 문제 유형과 풀이 방식

- 평균·중앙값·최빈값 위치 비교: 꼬리 방향부터 그리면 대소 관계가 바로 나온다.
- 표본분산 계산: n-1로 나눴는지 확인한다.
- 상자그림 해석: Q1, Q3, IQR로 울타리를 계산해서 이상값 개수를 센다.
- 상관계수 해석: 부호와 크기, 인과 여부 선지를 거른다.
- 검정 선택: 자료가 연속형인지 범주형인지, 집단이 몇 개인지, 독립인지 대응인지 순서로 묻는다.
- p-값과 유의수준 비교: 기각이면 "차이가 있다", 기각 못 하면 "차이가 있다고 할 근거가 부족하다".
