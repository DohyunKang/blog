## What it does
Coding agents forget what they've done once a session ends. `claude-mem` collects tool usage records (observations) made during a session, compresses them with AI, and re-injects relevant content when the next session starts. The README lists supported agents as Claude Code, OpenClaw, Codex, Gemini, Hermes, Copilot, and OpenCode.

## Architecture
- Six hooks: SessionStart, UserPromptSubmit, PreToolUse, PostToolUse, Stop, and SessionEnd. Each hook executes one `claude-mem` command.
- Worker: A service with a local HTTP API and web viewer, managed via Bun.
- Storage: Sessions, observations, and summaries are stored in SQLite, with full-text search enabled using FTS5. Vector search uses Chroma, combining both keyword and vector-based retrieval.
- Search: Includes the `mem-search` skill and three MCP tools (`search`, `timeline`, `get_observations`). The README claims this two-step filtering process saves about 10x on tokens by first listing results and then fetching details only for necessary items. This figure is the author's claim, which I have not verified.
- Modes: The default mode is `code`. Variants include `code--chill` (which leaves fewer traces) and `code--[lang]` for writing in other languages.

## Installation
According to the README, you can use `npx claude-mem install`, or within Claude Code, run `/plugin marketplace add thedotmack/claude-mem` followed by `/plugin install claude-mem`. Node.js 20 or higher is required; Bun and uv will be installed automatically if missing. The npm package installs only the library and does not register hooks or workers. On Windows, `node` and `npm` must be in your PATH, or hooks will fail if `claude-mem` cannot be found.

## Things to check before writing
The privacy-related content in the README is worth reading before installation.

- Logging in starts a 30-day free trial of the hosted "claude-mem observer." After the trial ends, summaries revert to Anthropic's billing tier unless you subscribe. You can also use your own OpenRouter or Gemini keys, or run without logging in using `--provider` or setting `CLAUDE_MEM_ONLINE_OPTIN=false`.
- Content wrapped in `<private>` tags is excluded from storage.
- Enabling Cloud Sync backs up memories to cmem.ai. Screenshots are disabled by default and only upload when Cloud Sync is enabled.
- Context added at session start defaults to the current harness context; separate environment variables exist to expand this.

In environments handling company code, you should verify what content gets passed to the summary before proceeding.
