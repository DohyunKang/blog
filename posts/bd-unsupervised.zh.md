无监督学习是一种在没有任何正确答案（标签）的情况下，寻找数据自身结构的方法。考试中通常分为聚类分析、关联分析和降维三个部分，经常考察“适用于什么场景”以及“核心指标或参数是什么”。有答案的部分已在 [监督学习模型](#/post/bd-supervised) 中单独整理。

## 先了解三大块

| 类型 | 作用 | 代表算法 | 核心关键词 |
|---|---|---|---|
| 聚类分析 | 将相似的事物归为一类 | K-means, 层次聚类，DBSCAN | 距离、簇数、轮廓系数 |
| 关联分析 | 寻找共同发生的项 | Apriori | 支持度、置信度、提升度 |
| 降维 | 减少变量数量 | PCA | 方差解释比例 |

聚类用于“将客户分成几个组”，关联分析用于“购买 A 的人是否也会购买 B"，降维则用于“变量太多能否进行缩减”。考试中经常只给出问题描述的情境，要求判断属于上述三种中的哪一种。

## 聚类分析

将距离相近的观测值归为同一簇。由于使用了距离度量，如果变量单位不同，大单位的变量会主导距离计算。因此，在聚类之前几乎必须进行标准化。缩放方法已在 [数据预处理](#/post/bd-preprocessing) 中讨论过。

### K-means

首先确定簇的数量 K，然后移动中心点以最小化簇内平方和（inertia，即各点到中心的距离平方和）。scikit-learn 文档总结的特征如下：

- 假设簇呈凸形且圆润，对于细长或弯曲的形状效果不佳。
- 必须预先指定簇的数量。
- 会收敛到局部最小值，因此结果取决于初始中心点。k-means++ 是减少该问题的基本初始化方法。
- 即使样本量很大，也能相对较好地运行。

顺序容易记忆：确定 K 个初始中心、将每个点分配给最近的中心、用簇的平均值更新中心、重复直到不再变化。由于使用平均值，因此对异常值敏感。如果担心异常值，可以使用以实际观测值为中心的 K-medoids。

### 如何选择 K

以下两种方法在考试中经常出现：

- **肘部法则**：绘制随 K 增加而变化的 inertia，选择曲线发生转折的点。inertia 会随着 K 的增加而始终减小，因此仅凭该值无法确定 K。
- **轮廓系数**：公式为 (b - a) / max(a, b)。其中 a 是同一簇内的平均距离，b 是到最近的其他簇的平均距离。取值范围在 -1 到 1 之间，越接近 1 表示聚类效果越好，接近 0 表示簇有重叠，负值可能表示分配错误。

<details>
<summary>实际运行结果 (K = 2~6)</summary>

使用三大块生成的虚拟数据（make_blobs, 300 个样本）进行标准化后，改变了 K 值进行测试。

| K | inertia | 轮廓系数 |
|---|---|---|
| 2 | 187.8 | 0.688 |
| 3 | 18.3 | 0.848 |
| 4 | 15.5 | 0.679 |
| 5 | 12.7 | 0.522 |
| 6 | 10.7 | 0.357 |

inertia 在 K 从 2 变为 3 时大幅下降，之后变化平缓（肘部）。轮廓系数在 K=3 时最高。由于数据本身由三个簇生成，因此结果符合预期。在实际数据中，这两个指标并不总是如此清晰地达成一致。
</details>

### 层次聚类

不需要预先指定簇的数量，从单个点开始，依次合并距离相近的簇（凝聚型）。将合并过程绘制成树状图称为树状图（dendrogram），切割的高度决定了簇的数量。测量簇之间距离的方法（连接法）有多种。

| 连接法 | 簇间距离定义 |
|---|---|
| 单一 | 两个簇中最近的两个点之间的距离 |
| 完全 | 两个簇中最远的两个点之间的距离 |
| 平均 | 所有点对距离的平均值 |
| 瓦德 (Ward) | 合并后使簇内平方和增加最少的点对 |

瓦德法的目的与 K-means 相似，根据文档描述，它倾向于产生大小最均匀的簇。单一连接法已知容易产生链式结构。层次聚类需要计算每对点之间的距离，因此在大数据集上计算负担较重。在上述虚拟数据上使用瓦德连接法并设定为 3 个簇时，轮廓系数为 0.848，与 K-means 相同。

### DBSCAN

基于密度的方法。如果半径 eps 内包含 min_samples 个以上的点，则该点为核心点；通过连接核心点形成簇。无法连接到任何核心点的点被视为噪声（noise），标签为 -1。

- 不需要指定簇的数量。
- 形状自由。
- 将异常值单独标记为噪声。
- eps 过小会导致大部分点被标记为 -1，过大则会导致簇合并。

运行上述数据，设置 `eps=0.3` 和 `min_samples=5` 后，得到了 3 个簇和 1 个噪声点。

## 关联分析

购物篮分析是典型代表。从项集中寻找"A 购买则 B 也购买”的规则。规则的强度由三个值衡量。

| 指标 | 公式 | 含义 |
|---|---|---|
| 支持度 | P(A and B) | 所有交易中 A 和 B 同时出现的比例 |
| 置信度 | P(A and B) / P(A) | 在包含 A 的交易中，也包含 B 的比例 |
| 提升度 | 置信度 / P(B) | 购买 B 的概率相对于仅购买 B 的基线概率的倍数 |

若提升度大于 1，则 A 与 B 呈正相关；等于 1 表示相互独立；小于 1 表示负相关。即使置信度高，如果 B 本身是人人必买的商品，提升度也会接近 1。因此需要区分这两种情况，这也是常考的问题点。

Apriori 算法利用“频繁项集的子集也必然是频繁的”这一性质来剪枝候选项。反过来说，如果一个集合不频繁，那么包含该集合的更大集合也没有必要考虑。算法仅从支持度不低于最小阈值的集合开始扩展搜索，并在此基础上筛选出置信度超过最小阈值的规则。

<details>
<summary>通过 5 笔交易计算得出的代码验证</summary>

5 笔交易：{牛奶, 面包}, {牛奶, 尿布, 啤酒, 面包}, {面包, 啤酒}, {牛奶, 尿布, 面包}, {牛奶, 尿布, 啤酒}

```python
tx = [{'우유','빵'},{'우유','기저귀','맥주','빵'},{'빵','맥주'},
      {'우유','기저귀','빵'},{'우유','기저귀','맥주'}]
n = len(tx)
def sup(s): return sum(s <= t for t in tx) / n
for a, b in [({'기저귀'},{'맥주'}), ({'우유'},{'빵'})]:
    s = sup(a | b); c = s / sup(a)
    print(a, b, s, round(c, 3), round(c / sup(b), 3))
```

| 规则 | 支持度 | 置信度 | 提升度 |
|---|---|---|---|
| 尿布 → 啤酒 | 0.4 | 0.667 | 1.111 |
| 牛奶 → 面包 | 0.6 | 0.75 | 0.937 |

“牛奶 → 面包”的支持度和置信度更高，但提升度小于 1。这是因为面包原本就出现在 5 笔交易中的 4 笔里，说明有牛奶并不会额外增加购买面包的概率。“尿布 → 啤酒”的数值虽小，但提升度超过了 1。
</details>

## 降维：PCA

当变量间相关性较高时，该方法旨在尽可能保留信息（方差），将数据转换到一组相互正交的新轴（主成分）上，从而减少变量数量。第一个主成分解释的方差最大，后续成分依次递减。

- scikit-learn 中的 PCA 会自动进行去均值（中心化），但不会进行缩放。对于单位不同的变量，必须先进行标准化，否则大数值的变量会主导主成分。
- 保留多少个主成分需根据累计解释方差比例来决定。
- 主成分是原始变量的组合，因此解释起来较为困难，这是其代价。
- 这与特征选择（从原始变量中挑选）不同。相关内容已在 [特征选择与降维](#/post/bd-feature-select) 中一并整理。

<details>
<summary>使用 iris 数据集查看的解释方差比例</summary>

```python
from sklearn.datasets import load_iris
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
X = StandardScaler().fit_transform(load_iris().data)
p = PCA().fit(X)
print(p.explained_variance_ratio_.round(3))
print(p.explained_variance_ratio_.cumsum().round(3))
```

比例为 0.730, 0.229, 0.037, 0.005；累计值为 0.730, 0.958, 0.995, 1.0。4 个变量被压缩为 2 个主成分后，解释了约 96% 的方差。
</details>

## 聚类结果检查与常见陷阱

- 聚类没有标准答案，因此不使用准确率进行评估。需关注内部指标（如轮廓系数）以及聚类结果在业务上的可解释性。各类评估指标详见 [模型评估](#/post/bd-evaluation)。
- K-means 若不进行标准化，单位较大的变量会左右结果。
- 肘部法则中惯性（inertia）随 K 增大而减小是理所当然的，因此"K 越大聚类越好”的说法是错误的。
- DBSCAN 中的 -1 不是簇编号，而是表示噪声点。
- 关联分析不能只看置信度，必须结合提升度一起观察。
- PCA 前若不进行标准化，单位大的变量会占据第一个主成分。
- 将数据划分为训练集和测试集的概念属于监督学习范畴，并不直接适用于聚类。数据划分相关内容已在 [分析模型设计](#/post/bd-model-design) 中整理。
