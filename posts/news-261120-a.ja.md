今朝の GitHub トレンド(daily)に mvanhorn/last30days-skill が載っていた。今日のスター 952、合計 70,777(11月20日朝に確認)。トピックを一つ渡すと、Reddit、X、YouTube、Hacker News、GitHub などから直近30日分の投稿をまとめて探し、人が実際に反応した順に束ねて要約してくれるエージェント用スキルだ。README、CONCEPTS.md、CONFIGURATION.md の一部、CHANGELOG を読んだ。自分では動かしていない。

## 何をするものか
スキルはエージェントが必要なときに取り出して読む説明書フォルダだ。[詳しく → スキル](#/post/ai-skills) Claude Code では `/last30days トピック` で呼び出し、Codex や Cursor など他のエージェントにも `npx skills add` で入る。作者は AI まわりのニュースについていくために作ったと書いている。モデルの学習データはいつも数か月遅れで、新しいコツは Reddit と X で先に回る、という理由だ。

README の主張は一行でいうとこうなる。検索エンジンは編集された記事を集め、これは人の反応を集める。だから順位づけに Reddit の upvote、X のいいね、YouTube の字幕の中身、Polymarket のオッズといった反応のシグナルを使う。Polymarket は出来事の結果にお金を賭ける予測市場なので、オッズがそのまま人がつけた確率になる。

## 中でどう動くか
構成は二つに分かれる。SKILL.md はモデルにどのフラグでエンジンを呼ぶかを教える説明書で、実際の検索は `scripts/last30days.py` という Python のエンジンがやる。エンジンが決まった形で結果を返し、モデルはそれをそのまま受け取って要約する。

1. トピックから中心の対象を取り出す。「〇〇 料金」なら「料金」を外して〇〇だけ残す。その対象の X アカウント、GitHub リポジトリ、サブレディット、YouTube チャンネルを先に探しておく。
2. 質問をいくつかに分け、ソースごとに別々に同時に検索する。
3. 同じ投稿が複数の検索に引っかかったら、正規化した URL で一つにまとめる。別のプラットフォームで同じ話をしていれば一つの塊(クラスタ)にする。
4. 対象の名前が入っていない投稿は、反応がどれだけ大きくても大きく下げる。残ったものだけを反応、関連度、新しさで並べる。
5. モデルが塊ごとに出典をつけて一つのブリーフにまとめる。

4 が面白かった。ドキュメントでは Entity grounding と呼んでいて、対象名の最初の単語だけを見る。後ろの単語はたいてい検索の飾りなので、全部を求めると合っている投稿まで落としてしまうから、という理由だ。逆に対象が "ai" や "new" のようなありふれた単語なら基準を上げて、関係なくバズった投稿が枠を取らないようにする。

関連度の判断に LLM を使うかは選べる。OpenAI、xAI、Gemini などのキーを入れると、トピックと見つけた投稿の断片をそのモデルに送って並べ直すリランキングをする。キーがなければローカルの採点に戻る。キーなしでも Reddit、HN、Polymarket、GitHub はすぐ使えると書いてある。集めた投稿を根拠に答えを書くところは RAG に近い流れだ。[詳しく → RAG](#/post/ai-rag)

トピックなしで動かす Discovery モードもある。いま伸びているものを自分で探すモードで、複数のソースで同時に見えるか、一か所でとても強く伸びたものだけを見せる。基準を超えるものがなければ無理に埋めず「確かなものはない」と答えるようになっている。ここがドキュメントに原則として書かれていてよかった。

## 入門者の立場から
PM の立場では、「いま人がこれをどう話しているか」をタブを開きながら手で探していた作業を一度にまとめて見る道具だ。会議前の相手の下調べや、機能を作る前に人がぶつかっている問題を探すことが例に挙がっている。ただ順位の基準は反応の数なので、うるさい投稿が正しい投稿とは限らない。ブリーフは出発点にして、原文は別に開いて見るのがよさそうだ。

開発の入門者なら、ソースごとに認証のやり方が違うところを先に見るといい。X は、ブラウザにログインしたセッションの Cookie を読む経路がデフォルトで先にあり、API キーを使う経路がその後ろにある。Cookie を読む前に同意を聞き、`--no-browser-cookies` で切ることもできる。Reddit のログインセッションを使うオプションについては、ドキュメント自身が Reddit の規約に反するかもしれないと書いている。動かす前に `--preflight` で何を読み書きするかを先に確かめられるのも参考になる。他のスキル集の話は前の記事と合わせて読むといい。[詳しく → よく使われる Claude スキル集](#/post/claude-popular-skills)
