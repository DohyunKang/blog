## 一览流程概览

```
학습 기초(손실·경사하강법)
  → 신경망과 역전파
    → 트랜스포머(어텐션)
      → 사전학습 → 지시 튜닝(SFT) → 선호 학습(RLHF·DPO)
        → 파인튜닝(LoRA/QLoRA)
        → 로컬에서 돌리기(양자화·VRAM)
        → 추론 최적화(KV 캐시·배치)
(별도 계열) 이미지 생성 = 확산 모델
```

## 1. 什么是学习

**机器学习·深度学习基础**：学习是通过数值衡量错误程度（损失），并逐步调整权重的过程。仅仅在训练数据上表现良好并非终点，因此也会涉及过拟合以及验证集与测试集的划分。
[详情 → 机器学习·深度学习基础](#/post/ml-basics)

**神经网络与反向传播**：由层层叠加的乘法、加法和弯曲计算构成的函数即为神经网络；而反向传播则是一种从输出端逆向计算权重应如何调整的方法。
[详情 → 神经网络与反向传播](#/post/ml-neural-net)

## 2. LLM 的骨架

**Transformer 与注意力机制**：这是一种为每个单词计算其在句子中参考其他单词程度的分数结构。它无需按顺序读取即可捕捉上下文，如今绝大多数 LLM 均采用此架构。
[详情 → Transformer 与注意力机制](#/post/ml-transformer)

## 3. 聊天机器人的构建过程

**从预训练到 RLHF**：包括通过阅读文本预测下一个词的预训练、展示回答提问方法的监督微调（SFT），以及将模型导向人类偏好的奖励学习（RLHF·DPO）。必须经过这三个阶段，才能生成能够对话的模型。
[详情 → 从预训练到 RLHF](#/post/ml-pretraining)

## 4. 本地操作指南

**微调：全量 vs LoRA/QLoRA**：对已完成预训练的模型使用自身数据进行再次教学的过程。若采用 LoRA，则无需修改整个模型，因此所需 GPU 资源大幅减少。
[详情 → 微调：全量 vs LoRA/QLoRA](#/post/ml-finetuning)

## 5. 运行方面

**本地模型运行**：模型能否放入本地 PC 的显卡，大致取决于参数量、量化位数和上下文长度。其中量化与显存（VRAM）计算是核心。
[详情 → 本地模型运行](#/post/ml-local-models)

**推理优化**：这并非关于构建，而是关于运行的话题。KV 缓存、批处理、流式处理及投机解码最终都归结为如何分配 GPU 内存的问题。
[详情 → 推理优化](#/post/ml-inference)

## 6. 不仅是文本

**图像生成模型（扩散）**：这类模型并非直接绘制图像，而是学习逐步去除噪声的方法。理解这一原理后，便能读懂 ComfyUI 的节点配置。
[详情 → 图像生成模型（扩散）](#/post/ml-diffusion)
