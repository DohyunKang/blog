이 단원은 두 덩어리다. 변수가 여러 개일 때 정보를 줄여 보는 다변량 분석(주성분분석, 다차원척도법)과, 시간 순서대로 쌓인 값을 다루는 시계열(구성요소, 정상성, ARIMA)이다. 시험 일정과 응시료는 공식 사이트에서 확인한다.

## 다변량 분석: 변수가 많을 때

변수가 열 개, 스무 개씩 되면 표를 보는 것만으로는 구조가 안 보인다. 다변량 분석은 변수를 줄이거나 점들의 위치 관계를 그림으로 옮겨서 그걸 해결한다. 이 단원에서 알아 둘 건 주성분분석(PCA)과 다차원척도법(MDS) 둘이다. 상관·회귀의 바탕은 [자세히 → 회귀 분석](#/post/adsp-regression)에 있다.

### 주성분분석(PCA)

scikit-learn 문서 표현으로 PCA는 데이터를 서로 직교하는 성분들로 나누되, 앞 성분일수록 분산을 최대한 많이 설명하게 만든다. 정리하면 이렇다.

| 항목 | 내용 |
|---|---|
| 목적 | 상관 있는 여러 변수를 적은 수의 새 변수(주성분)로 요약 |
| 주성분끼리 | 서로 직교, 즉 상관이 없다 |
| 순서 | 제1주성분이 분산을 가장 많이 설명, 그다음이 제2주성분 |
| 쓰임 | 차원 축소, 시각화, 다중공선성 줄이기 |

여기서 시험에서 잘 갈리는 포인트가 하나 있다. 문서에 따르면 PCA는 각 변수의 평균을 빼서 중심을 맞추기만 하고 크기(스케일)는 맞추지 않는다. 그래서 분산이 큰 변수가 성분을 끌고 간다. 단위가 다른 변수를 섞어 쓸 땐 표준화를 먼저 하는 게 맞다(문서가 이 부분은 일반 지침으로 따로 적는다).

직접 돌려 본 예가 있다. 변수 세 개를 만들었는데, 앞의 둘은 같은 신호에 잡음을 얹어 서로 강하게 닮게 했고 셋째는 독립으로 뒀다(numpy로 공분산 행렬의 고유값 분해).

| 성분 | 고유값 | 설명 분산 비율 | 누적 |
|---|---|---|---|
| PC1 | 4.771 | 0.933 | 0.933 |
| PC2 | 0.258 | 0.050 | 0.983 |
| PC3 | 0.087 | 0.017 | 1.000 |

닮은 변수가 있으면 첫 성분 하나가 대부분을 가져간다. 그래서 "성분을 몇 개 남길까"는 설명 분산 비율의 누적을 보고 정한다. 고유값은 그 성분이 설명하는 분산의 크기이고, 비율은 고유값을 전체 합으로 나눈 값이다.

<details>
<summary>자세한 풀이: PCA를 numpy로 계산하는 순서</summary>

```python
import numpy as np
rng = np.random.default_rng(0)
n = 200
a = rng.normal(size=n)
X = np.c_[a + 0.3*rng.normal(size=n), 2*a + 0.3*rng.normal(size=n), 0.5*rng.normal(size=n)]
Xc = X - X.mean(0)                # 1) 평균을 빼서 중심 맞추기
cov = np.cov(Xc, rowvar=False)    # 2) 공분산 행렬
w, v = np.linalg.eigh(cov)        # 3) 고유값·고유벡터
w = np.sort(w)[::-1]
print((w / w.sum()).round(3))     # [0.933 0.05  0.017]
```

고유벡터가 성분의 방향이고, 고유값이 그 방향의 분산이다. 데이터에 고유벡터를 곱하면 성분 점수가 나온다.

</details>

### 다차원척도법(MDS)

MDS는 개체 사이의 비유사성(거리) 행렬을 받아서, 낮은 차원(보통 2차원)에 점을 놓되 점 사이 거리가 원래 거리를 최대한 닮게 만든다. 지도 위에 도시를 놓는 것과 같다. 원래 거리를 얼마나 못 맞췄는지가 스트레스(stress)다. 작을수록 잘 맞춘 것이다.

- 계량적(metric) MDS: 거리의 실제 값을 재현하려 한다.
- 비계량적(non-metric) MDS: 거리의 순서만 맞추면 된다. 가까운 쌍이 먼 쌍보다 가깝게 놓이면 된다.

문서에는 유클리드 거리를 입력으로 쓰는 고전적 MDS가 PCA와 같은 결과를 낸다고도 나온다. 둘 다 "높은 차원을 낮은 차원으로"지만 PCA는 변수 값에서, MDS는 거리 행렬에서 출발한다는 점이 다르다.

| | PCA | MDS |
|---|---|---|
| 입력 | 변수 값 표 | 개체 간 거리 행렬 |
| 기준 | 분산을 최대한 보존 | 거리를 최대한 보존(스트레스 최소화) |
| 결과 | 주성분(변수의 조합) | 개체의 좌표 |

## 시계열: 시간 순서가 있는 데이터

시계열은 같은 대상을 시간 순서대로 관측한 값이다. 일반 회귀는 관측이 서로 독립이라고 보는데, 시계열은 오늘 값이 어제 값과 이어져 있다는 게 출발점이다.

### 구성요소

시계열은 보통 네 가지가 섞인 걸로 본다.

| 구성요소 | 뜻 |
|---|---|
| 추세 | 장기간 오르거나 내리는 방향 |
| 계절 | 주기가 고정된 반복(월별, 요일별 등) |
| 순환 | 주기가 일정하지 않은 오르내림 |
| 불규칙 | 위 셋으로 설명 안 되는 나머지 |

계절과 순환의 구분이 헷갈린다. Hyndman 교재 기준으로 계절은 주기가 고정되고 알려져 있고, 순환은 길이가 고정되지 않아서 고점·저점이 언제 올지 예측하기 어렵다.

### 정상성

정상 시계열은 통계적 성질이 관측 시점에 따라 달라지지 않는 시계열이다. 그림으로는 대체로 수평이고 변동 폭이 일정하다. 추세나 계절성이 있으면 정상이 아니다. 백색잡음은 정상이다. 순환이 있어도 주기가 정해져 있지 않으면 정상으로 본다는 점이 의외였다.

정상성을 보는 방법은 두 가지다.

- 그림과 ACF: 정상이면 자기상관(ACF)이 금방 0 근처로 떨어지고, 비정상이면 천천히 줄어든다.
- 단위근 검정: Hyndman 교재가 쓰는 KPSS 검정은 귀무가설이 "정상"이다. p값이 작으면(예: 0.05 미만) 차분이 필요하다는 뜻이다. 검정마다 귀무가설이 정반대일 수 있어서, 시험에서는 귀무가설이 뭔지 같이 외워 두는 게 안전하다. 가설검정의 구조는 [자세히 → 가설 검정](#/post/adsp-hypothesis)에서 다뤘다.

직접 확인한 예다. 랜덤워크(매 시점 잡음을 누적한 값)를 만들어 ACF를 구해 봤다.

| 시차 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 랜덤워크 ACF | 0.98 | 0.97 | 0.95 | 0.93 | 0.91 |
| 한 번 차분한 ACF | 0.03 | -0.02 | 0.20 | 0.04 | 0.03 |

원본은 천천히 줄고, 차분하면 거의 0이다. 이게 비정상에서 정상으로 바뀐 모습이다.

### 변환: 차분

차분은 이웃한 두 관측의 차이를 취하는 것이다(y_t − y_(t−1)). 수준의 변화를 없애서 평균을 안정시키고 추세와 계절성을 줄인다. 계절 차분은 한 주기 전 값과의 차이를 쓴다(y_t − y_(t−m)). 월별 자료라면 m=12다. 한 주기가 12인 사인 파형에 계절 차분을 걸었더니 표준편차가 3.59에서 0.41로 줄었다.

주의할 점은 필요한 만큼만 해야 한다는 것이다. 과하게 차분하면 없던 자기상관이 생긴다. 로그 변환은 분산을 안정시키지만 추세를 없애진 못한다.

## ARIMA

ARIMA(p, d, q)는 AutoRegressive Integrated Moving Average의 약자고, 세 숫자가 구조를 정한다.

| 기호 | 뜻 |
|---|---|
| p | 자기회귀(AR) 차수: 과거 값을 몇 개 쓰나 |
| d | 차분 횟수: 정상으로 만들려고 몇 번 차분하나 |
| q | 이동평균(MA) 차수: 과거 예측 오차를 몇 개 쓰나 |

- AR(p): 자기 자신의 과거 값으로 회귀한다. y_t = c + φ1·y_(t−1) + … + ε_t
- MA(q): 과거 오차들의 조합이다. y_t = c + ε_t + θ1·ε_(t−1) + …. 추세를 뽑는 이동평균 평활과는 다른 개념이라 이름이 겹쳐 헷갈린다.
- I(차분): 차분의 반대 연산(적분)이 들어 있다는 뜻이다. d는 실제로는 2를 넘는 일이 드물다고 교재에 나온다.

자주 쓰는 특수한 경우는 이렇다.

| 모델 | 표기 |
|---|---|
| 백색잡음 | ARIMA(0,0,0) |
| 랜덤워크 | ARIMA(0,1,0) |
| 표류 있는 랜덤워크 | ARIMA(0,1,0) + 상수 |
| 자기회귀 | ARIMA(p,0,0) |
| 이동평균 | ARIMA(0,0,q) |

p와 q를 고를 때 ACF가 단서가 된다. 직접 시뮬레이션해서 이론과 맞는지 봤다.

- AR(1), φ=0.7: ACF가 0.69, 0.48, 0.32, 0.21, 0.15로 서서히 줄었다. 이론값 0.7^k(0.70, 0.49, 0.34, 0.24, 0.17)와 비슷하다.
- MA(1), θ=0.8: 시차 1에서 0.49, 이후는 0 근처(0.00, −0.02, …)였다. 이론값 θ/(1+θ²)=0.49와 같다.

그래서 AR은 ACF가 서서히 감소하고, MA는 시차 q 뒤에서 뚝 끊긴다는 식으로 정리된다. 시험에서 이 둘의 구분을 묻는 유형이 나오기 쉬운 자리다.

<details>
<summary>자세한 풀이: 후방이동 연산자로 쓴 ARIMA 식</summary>

후방이동 연산자 B는 값을 한 시점 뒤로 옮긴다(B·y_t = y_(t−1)). 1차 차분은 (1 − B)y_t이고, d차 차분은 (1 − B)^d·y_t다. 그래서 d는 (1 − B)의 지수다. 전체 식은 다음과 같다.

(1 − φ1·B − … − φp·B^p)(1 − B)^d·y_t = c + (1 + θ1·B + … + θq·B^q)·ε_t

왼쪽에 AR 다항식과 차분이, 오른쪽에 MA 다항식이 있다.

</details>

## 흔한 오해

- 주성분은 원래 변수 중 일부를 고른 것이다: 아니다. 원래 변수들의 조합으로 새로 만든 변수다.
- PCA는 단위를 신경 쓸 필요 없다: 스케일을 맞추지 않으므로 단위가 다르면 큰 변수가 지배한다.
- MDS는 항상 원래 거리를 그대로 재현한다: 낮은 차원에 옮기는 과정에서 오차가 생기고, 그 크기가 스트레스다.
- 순환과 계절은 같다: 계절은 주기가 고정, 순환은 고정되지 않는다.
- ARIMA의 d가 클수록 좋다: 필요한 만큼만 차분해야 하고, 과하면 가짜 자기상관이 생긴다.
