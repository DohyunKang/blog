신경망은 "곱하고 더한 다음 한 번 휘는" 계산을 층층이 쌓은 함수이고, 역전파는 그 안의 숫자(가중치)를 어느 쪽으로 얼마나 고칠지 출력 쪽에서 거꾸로 계산해 주는 방법이다.

## 뉴런 하나

뉴런은 이름만 거창하고 계산은 단순하다. 입력 숫자들에 가중치를 곱해 더하고, 편향(bias)을 더한 다음, 활성화 함수에 통과시킨다.

```
출력 = 활성화( w1*x1 + w2*x2 + ... + b )
```

가중치와 편향이 학습으로 바뀌는 숫자다. 학습이 뭔지, 손실과 경사하강법이 뭔지는 [자세히 → 머신러닝·딥러닝 기초](#/post/ml-basics)에 따로 적었고, 여기서는 그걸 신경망에 붙이는 부분만 본다.

## 층과 활성화 함수

뉴런을 한 줄로 늘어놓은 게 층(layer)이다. 입력층 → 은닉층 → 출력층으로 이어 붙이면 신경망이 된다. 층 하나는 행렬 곱 한 번으로 계산된다. 입력이 2개, 뉴런이 4개면 가중치는 2×4 행렬이다.

그런데 활성화 함수가 없으면 층을 몇 개 쌓아도 소용이 없다. 행렬 곱을 두 번 하는 건 합친 행렬 하나로 한 번 곱하는 것과 같아서, 결국 직선(선형) 관계밖에 못 표현한다. 중간에 비선형 함수를 끼워야 층을 쌓은 보람이 생긴다.

| 함수 | 모양 | 어디에 쓰이나 |
|---|---|---|
| 시그모이드 | 0~1로 눌러 담음 | 확률처럼 읽는 출력 |
| tanh | -1~1로 눌러 담음 | 작은 신경망의 은닉층 |
| ReLU | 음수는 0, 양수는 그대로 | 깊은 신경망의 기본값 |

ReLU가 기본값이 된 이유는 계산이 싸고, 양수 쪽에서는 기울기가 1이라 층이 깊어도 신호가 덜 죽어서라고 알려져 있다.

## 순전파

입력을 넣고 층을 차례로 지나 출력을 얻는 과정이 순전파(forward)다. 출력과 정답을 손실 함수로 비교해 숫자 하나(손실)로 만든다. 학습은 이 손실을 줄이는 방향으로 가중치를 조금씩 고치는 일이다.

문제는 가중치가 수천만~수천억 개일 수 있다는 점이다. 각각을 "조금 올리면 손실이 어떻게 변하나"로 하나씩 재면 순전파를 가중치 개수만큼 돌려야 한다. 이걸 한 번의 거꾸로 계산으로 끝내는 게 역전파다.

## 역전파: 거꾸로 곱해 오기

역전파(backpropagation)의 정체는 연쇄 법칙(chain rule)이다. 함수가 f(g(x))처럼 겹쳐 있으면 x가 f에 주는 영향은 "x가 g에 주는 영향 × g가 f에 주는 영향"이다. 신경망은 겹친 함수 덩어리이니, 손실에서 출발해 한 층씩 거슬러 오며 영향(기울기)을 곱해 나가면 모든 가중치의 기울기를 구할 수 있다.

CS231n 노트는 이걸 게이트가 이어진 회로로 설명한다. 각 게이트는 자기 입력에 대한 국소 기울기만 알고 있다. 뒤에서 내려온 기울기에 그 국소 기울기를 곱해서 앞으로 넘기면 끝이다. 몇 가지 규칙이 나온다.

- 덧셈 게이트는 기울기를 그대로 양쪽에 넘긴다.
- 곱셈 게이트는 상대 입력값을 곱해서 넘긴다(입력값이 서로 맞바뀐다).
- 한 변수가 여러 갈래로 쓰였으면 갈래마다 온 기울기를 더한다.
- 순전파 때 나온 중간값을 저장해 뒀다가 거꾸로 올 때 다시 쓴다.

마지막 항목 때문에 학습 중에는 메모리를 많이 쓴다. 추론은 중간값을 버려도 되지만 학습은 역전파용으로 들고 있어야 해서다.

위키백과의 정리로는 역전파는 엄밀히 기울기를 구하는 부분만 가리키고, 구한 기울기로 가중치를 고치는 건 SGD나 Adam 같은 옵티마이저의 일이다. 일상 대화에서는 둘을 합쳐 "역전파로 학습한다"고 퉁쳐서 말한다.

빠른 이유도 거기 있다. 각 층의 기울기를 한 번만 계산해서 앞 층에서 재사용하니, 가중치마다 따로 재는 것보다 훨씬 싸다. 1986년 Rumelhart, Hinton, Williams의 논문이 이 방법으로 은닉층을 학습시키는 걸 널리 알린 걸로 인용되는데, 위키백과는 비슷한 아이디어가 여러 번 따로 발견된 얽힌 역사가 있다고 적는다.

## 직접 돌려 본 XOR

XOR(두 입력이 다를 때만 1)은 직선 하나로 나눌 수 없어서 은닉층이 없으면 못 푼다. 은닉층 4개짜리 신경망을 numpy로만 짜서 돌렸다. 역전파를 손으로 쓴 코드다.

```python
import numpy as np
rng = np.random.default_rng(1)
X = np.array([[0,0],[0,1],[1,0],[1,1]], dtype=float)
y = np.array([[0],[1],[1],[0]], dtype=float)
W1 = rng.normal(0, 1, (2, 4)); b1 = np.zeros((1, 4))
W2 = rng.normal(0, 1, (4, 1)); b2 = np.zeros((1, 1))
sigmoid = lambda z: 1 / (1 + np.exp(-z))
lr = 1.0
for step in range(5001):
    # 순전파
    h = np.tanh(X @ W1 + b1)
    p = sigmoid(h @ W2 + b2)
    loss = np.mean((p - y) ** 2)
    # 역전파: 출력 쪽에서 거꾸로
    dp = 2 * (p - y) / len(X)
    dz2 = dp * p * (1 - p)            # 시그모이드 미분
    dW2 = h.T @ dz2; db2 = dz2.sum(0, keepdims=True)
    dh = dz2 @ W2.T
    dz1 = dh * (1 - h ** 2)           # tanh 미분
    dW1 = X.T @ dz1; db1 = dz1.sum(0, keepdims=True)
    # 경사하강법
    W1 -= lr * dW1; b1 -= lr * db1; W2 -= lr * dW2; b2 -= lr * db2
    if step % 1000 == 0:
        print(step, round(float(loss), 4))
print(np.round(p, 2).ravel())
```

실행 결과(numpy 2.5.4, Python 3):

```
0 0.24
1000 0.0008
2000 0.0003
3000 0.0002
4000 0.0002
5000 0.0001
[0.   0.99 0.99 0.01]
```

손실이 0.24에서 0.0001까지 내려갔고 출력이 [0, 1, 1, 0]에 붙었다. 역전파가 맞게 짜였는지는 수치 미분으로도 확인했다. 가중치 하나를 아주 조금 바꿔 손실 변화를 재면 -1.2166e-05, 역전파로 구한 기울기는 -1.2169e-05로 거의 같았다. 직접 짠 역전파 코드는 이렇게 한 번 대조해 보는 게 안전하다.

재미있었던 건 시드를 0으로 했을 때다. 같은 코드가 손실 0.125 근처에서 멈추고 출력이 [0.01, 0.5, 0.99, 0.5]로 굳었다. 초기 가중치가 나쁘면 얕은 골짜기에 갇힐 수 있다는 걸 보여 준 셈이다. 시드 1~4는 전부 풀었다.

<details>
<summary>역전파 코드를 한 줄씩 풀면</summary>

손실은 L = mean((p − y)²)이고, p = σ(z2), z2 = h·W2 + b2, h = tanh(z1), z1 = X·W1 + b1이다. 손실에서 거꾸로 한 칸씩 간다.

1. dp = ∂L/∂p = 2(p − y)/N. 제곱 오차의 미분이다.
2. dz2 = dp · p(1 − p). 시그모이드의 미분이 σ(1 − σ)라는 점을 쓴다.
3. dW2 = hᵀ · dz2. z2가 h·W2이므로 W2에 대한 기울기는 h를 곱한 형태가 된다. 곱셈 게이트가 상대 입력을 곱해 넘긴다는 규칙 그대로다.
4. dh = dz2 · W2ᵀ. 같은 곱셈에서 h 쪽으로 넘어가는 기울기다.
5. dz1 = dh · (1 − h²). tanh의 미분이 1 − tanh²다.
6. dW1 = Xᵀ · dz1. 첫 층도 같은 모양이다.

편향의 기울기는 덧셈 게이트라 기울기를 그대로 받고, 샘플 4개에 걸친 합이 된다(`sum(0)`). 한 줄 한 줄이 "뒤에서 온 기울기 × 이 게이트의 국소 기울기"다.
</details>

## 흔한 오해

- 신경망은 뇌를 흉내 낸 것이라는 말은 이름의 유래일 뿐이고, 실제 계산은 위의 행렬 곱과 비선형 함수다.
- 역전파는 학습 알고리즘 전체가 아니다. 기울기를 구하는 부분이고, 고치는 건 옵티마이저가 한다.
- 층을 많이 쌓으면 무조건 좋아지지도 않는다. 활성화 함수를 잘못 고르면 기울기가 층을 거치며 작아지거나 커져서 학습이 안 된다. 그래서 ReLU, 잔차 연결 같은 장치가 생겼다.
- 신경망이 만능 근사기라는 말은 이론상 충분히 크면 임의의 함수를 흉내 낼 수 있다는 뜻이지, 학습이 잘 된다는 보장은 아니다. 위 시드 0 예처럼 학습이 걸릴 수도 있다.
