この単元は 2 つのパートに分かれています。変数が複数ある場合、情報を圧縮して見る多変量分析（主成分分析、多次元尺度法）と、時間順に積み上がった値を扱う時系列（構成要素、平稳性、ARIMA）です。試験日程と受験料は公式ウェブサイトでご確認ください。

## 多変量分析：変数が多数ある場合

変数が 10 個、20 個になると、表を見るだけでは構造が見えません。多変量分析は変数を減らしたり、点の位置関係を図に描いて解決します。この単元で覚えておくべきのは主成分分析 (PCA) と多次元尺度法 (MDS) の 2 つです。相関・回帰の基礎は [詳しく → 回帰分析](#/post/adsp-regression)にあります。

### 主成分分析 (PCA)

scikit-learn のドキュメントの表現では、PCA はデータを互いに直交する成分に分割し、最初の成分ほど分散を最大限に説明するようにします。まとめると以下のようになります。

| 項目 | 内容 |
|---|---|
| 目的 | 相関のある複数の変数を少数の新しい変数（主成分）で要約 |
| 主成分同士 | 互いに直交しており、つまり相関がない |
| 順序 | 第 1 主成分が最も多くの分散を説明し、次に第 2 主成分 |
| 用途 | 次元削減、可視化、多重共線性の低減 |

ここで試験でよく出るポイントは一つあります。ドキュメントによると、PCA は各変数の平均を引き算して中心を整えるだけで、サイズ（スケール）は調整しません。そのため、分散の大きい変数が成分を引っ張ってしまいます。単位が異なる変数を混ぜて使う場合は、まず標準化を行うのが正しいです（ドキュメントはこの部分を一般的な指針として別に記載しています）。

実際に動かしてみた例があります。3 つの変数を作成し、最初の 2 つは同じ信号にノイズを重ねて互いに強く似せ、3 つ目は独立に置きました (numpy を用いた共分散行列の固有値分解)。

| 成分 | 固有値 | 説明分散比率 | 累積 |
|---|---|---|---|
| PC1 | 4.771 | 0.933 | 0.933 |
| PC2 | 0.258 | 0.050 | 0.983 |
| PC3 | 0.087 | 0.017 | 1.000 |

似た変数がある場合、最初の成分一つで大部分を担います。そのため「何個の成分を残すべきか」は説明分散比率の累積を見て決めます。固有値はその成分が説明する分散の大きさであり、比率は固有値を全体の合計で割った値です。

<details>
<summary>詳しい解説：numpy で PCA を計算する手順</summary>

```python
import numpy as np
rng = np.random.default_rng(0)
n = 200
a = rng.normal(size=n)
X = np.c_[a + 0.3*rng.normal(size=n), 2*a + 0.3*rng.normal(size=n), 0.5*rng.normal(size=n)]
Xc = X - X.mean(0)                # 1) 평균을 빼서 중심 맞추기
cov = np.cov(Xc, rowvar=False)    # 2) 공분산 행렬
w, v = np.linalg.eigh(cov)        # 3) 고유값·고유벡터
w = np.sort(w)[::-1]
print((w / w.sum()).round(3))     # [0.933 0.05  0.017]
```

固有ベクトルが成分の方向であり、固有値はその方向の分散です。データに固有ベクトルを掛けることで成分スコアが得られます。

</details>

### 多次元尺度法 (MDS)

MDS は個体間の非類似性（距離）行列を受け取り、低い次元（通常は 2 次元）に点を配置し、点同士の距離が元の距離とできるだけ似るようにします。地図上に都市を置くのと同じです。元の距離をどれだけ合わせられなかったかがストレス (stress) です。小さいほどよく合っていることを意味します。

- 計量 (metric) MDS: 距離の実際の値を再現しようとします。
- 非計量 (non-metric) MDS: 距離の順序だけ合わせればよいです。近いペアが遠いペアより近くなるように配置すればよいです。

ドキュメントには、ユークリッド距離を入力とする古典的 MDS が PCA と同様の結果を与えるともあります。どちらも「高い次元を低い次元へ」ですが、PCA は変数の値から出発し、MDS は距離行列から出発する点が異なります。

| | PCA | MDS |
|---|---|---|
| 入力 | 変数値の表 | 個体間の距離行列 |
| 基準 | 分散を最大限に保持 | 距離を最大限に保持（ストレス最小化） |
| 結果 | 主成分（変数の組み合わせ） | 個体の座標 |

## 時系列：時間順序があるデータ

時系列とは、同じ対象を時間順に観測した値です。通常の回帰は観測が互いに独立であるとみなしますが、時系列では今日の値が昨日の値と繋がっていることが出発点です。

### 構成要素

時系列は通常、4 つの要素が混ざったものとして見られます。

| 構成要素 | 意味 |
|---|---|
| トレンド | 長期的に上昇または下降する方向 |
| 季節 | 周期が固定された反復（月別、曜日別など） |
| 循環 | 周期が一定しない上下動 |
| 不規則 | 上記 3 つで説明できない残りの部分 |

季節と循環の区別が分かりにくいものです。Hyndman の教科書によると、季節は周期が固定されており知られており、循環は長さが固定されていないため高値・低値がいつ来るか予測するのが難しいとしています。

### 平稳性

平稳時系列とは、統計的性質が観測時点によって変わらない時系列です。図では概ね水平で変動幅が一定です。トレンドや季節性があれば平稳ではありません。白色雑音は平稳です。循環があっても周期が決まっていない場合は平稳とみなす点が意外でした。

平稳性を確認する方法は 2 つあります。

- 그림과 ACF: 正規であれば自己相関 (ACF) はすぐに 0 の近傍に収束し、非正規であればゆっくりと減少する。
- 単位根検定：Hyndman の教科書で用いられる KPSS 検定の帰無仮説は「正規」である。p 値が小さい場合（例：0.05 未満）は差分が必要であることを意味する。各検定では帰無仮説が正反対になる可能性があるため、試験では帰無仮説の内容も一緒に暗記しておくのが安全だ。仮説検定の構造については [詳細 → 仮説検定](#/post/adsp-hypothesis) で扱った。

直接確認した例である。ランダムウォーク（各時点でのノイズの累積値）を作成して ACF を求めた。

| 時差 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| ランダムウォーク ACF | 0.98 | 0.97 | 0.95 | 0.93 | 0.91 |
| 一度差分した ACF | 0.03 | -0.02 | 0.20 | 0.04 | 0.03 |

元データはゆっくり減少し、差分を取るとほぼ 0 になる。これが非正規から正規への変化の様子である。

### 変換：差分

差分とは隣接する 2 つの観測値の差を取る操作のことである (y_t − y_(t−1))。レベル変化を除去して平均を安定させ、トレンドや季節性を減らす。季節差分は 1 周期前の値との差を用いる (y_t − y_(t−m))。月次データの場合 m=12 となる。1 周期が 12 のサイン波に季節差分を適用したところ、標準偏差は 3.59 から 0.41 に減少した。

注意すべき点は必要な分だけ行う必要があることだ。過剰な差分を行うと本来ない自己相関が生じる。対数変換は分散を安定させるがトレンドを除去することはできない。

## ARIMA

ARIMA(p, d, q) は AutoRegressive Integrated Moving Average の略称であり、3 つの数字が構造を決定する。

| 記号 | 意味 |
|---|---|
| p | 自己回帰 (AR) の次数：過去何個の値を用いるか |
| d | 差分回数：正規にするために何回差分するか |
| q | 移動平均 (MA) の次数：過去何個の予測誤差を用いるか |

- AR(p): 自身の過去の値に対して回帰する。y_t = c + φ1·y_(t−1) + … + ε_t
- MA(q): 過去の誤差の組み合わせである。y_t = c + ε_t + θ1·ε_(t−1) + …. トレンドを抽出する移動平均平滑化とは異なる概念であり、名称が重複して混同しやすい。
- I(差分): 差分の逆演算（積分）が含まれていることを意味する。教科書によると d は実際には 2 を超えることは稀とある。

よく使われる特殊なケースは以下の通りである。

| モデル | 表記 |
|---|---|
| 白色雑音 | ARIMA(0,0,0) |
| ランダムウォーク | ARIMA(0,1,0) |
| ドリフトのあるランダムウォーク | ARIMA(0,1,0) + 定数 |
| 自己回帰 | ARIMA(p,0,0) |
| 移動平均 | ARIMA(0,0,q) |

p と q を選ぶ際の手がかりとなるのが ACF である。直接シミュレーションして理論値と一致するか確認した。

- AR(1), φ=0.7: ACF が 0.69, 0.48, 0.32, 0.21, 0.15 と徐々に減少した。理論値 0.7^k (0.70, 0.49, 0.34, 0.24, 0.17) と似ている。
- MA(1), θ=0.8: 時差 1 で 0.49、以降は 0 の近傍 (0.00, −0.02, …) だった。理論値 θ/(1+θ²)=0.49 と一致する。

したがって AR では ACF がゆっくり減少し、MA では時差 q を過ぎると急激に切れるというように整理できる。試験ではこの 2 つの区別を問う問題が出やすい。

<details>
<summary>詳しい解説：後方移動演算子を用いた ARIMA 式</summary>

後方移動演算子 B は値を 1 時点分後ろにずらす (B·y_t = y_(t−1))。1 次差分は (1 − B)y_t であり、d 次差分は (1 − B)^d·y_t となる。したがって d は (1 − B) の指数である。全体の式は以下の通りである。

(1 − φ1·B − … − φp·B^p)(1 − B)^d·y_t = c + (1 + θ1·B + … + θq·B^q)·ε_t

左側に AR 多項式と差分があり、右側に MA 多項式がある。

</details>

## よくある誤解

- 主成分は元の変数の一部を選んだものである：違う。元の変数の組み合わせによって新たに作成された変数である。
- PCA は単位を気にする必要がない：スケールを合わせないため、単位が異なると大きな値の変数が支配する。
- MDS は常に元の距離をそのまま再現する：低次元へ移す過程で誤差が生じ、その大きさがストレスとなる。
- 循環と季節は同じ：季節は周期が固定されているが、循環は固定されていない。
- ARIMA の d が大きいほど良い：必要な分だけ差分を行うべきであり、過剰に行うと偽の自己相関が生じる。
