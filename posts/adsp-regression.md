회귀 분석은 입력 변수(독립변수)로 결과 변수(종속변수)를 설명하는 식을 세우고, 그 식이 얼마나 쓸 만한지 확인하는 단원이다. ADsP 3과목에서 가설 검정 다음에 이어지고, 용어가 많아 보여도 물어보는 축은 몇 개로 정해져 있다. 시험 일정과 응시료는 공식 사이트에서 확인한다.

## 단순 회귀와 다중 회귀

단순 회귀는 독립변수가 하나다. 직선 y = b0 + b1x를 긋고, 점들이 선에서 벗어난 거리(잔차)의 제곱합이 가장 작아지도록 b0, b1을 정한다. 이게 최소제곱법이다. 다중 회귀는 독립변수가 둘 이상이라 y = b0 + b1x1 + b2x2 + ... 꼴이 된다.

| | 단순 회귀 | 다중 회귀 |
|---|---|---|
| 독립변수 | 1개 | 2개 이상 |
| 식 | y = b0 + b1x | y = b0 + b1x1 + b2x2 ... |
| 추가로 신경 쓸 것 | 없음 | 변수끼리 얽힘(다중공선성), 변수 선택 |

회귀계수 b1은 "다른 변수가 그대로일 때 x가 1 늘면 y가 평균 b1만큼 변한다"로 읽는다. 문제에서 계수 해석을 시키면 이 문장 틀에 숫자만 넣으면 된다. 계수가 0인지 아닌지는 t검정으로, 모형 전체가 의미 있는지는 F검정으로 본다. p값 읽는 법은 [자세히 → 가설 검정](#/post/adsp-hypothesis)에 정리했다.

## 회귀의 기본 가정

오차(잔차)에 대한 가정이 네 가지로 나온다. 외울 때는 이름 그대로 쓰면 된다.

| 가정 | 뜻 | 어긋나면 |
|---|---|---|
| 선형성 | 독립변수와 종속변수가 직선 관계 | 곡선 관계면 변환하거나 항 추가 |
| 독립성 | 오차끼리 서로 관계없음 | 시계열처럼 앞뒤가 붙은 자료에서 자주 깨짐 |
| 등분산성 | 오차의 퍼짐이 어디서나 같음 | 잔차 그림이 깔때기 모양 |
| 정규성 | 오차가 정규분포 | Q-Q 도표가 선에서 벗어남 |

statsmodels 문서도 OLS는 오차가 서로 독립이고 분산이 같은 경우로 정의하고, 분산이 다르면 WLS, 임의의 공분산이면 GLS로 따로 둔다. 시험에서는 "잔차 그림을 보고 어느 가정이 깨졌나"를 묻는 유형이 많다. 잔차가 무늬 없이 0 근처에 고르게 흩어져 있으면 가정이 대체로 맞는 상태다.

## 결정계수 R²

R²는 모형이 y의 변동 중 얼마를 설명하는지를 0과 1 사이 숫자로 보여 준다. 식은 이렇다.

- SST(총변동) = Σ(y − 평균)²
- SSE(잔차 변동) = Σ(y − 예측값)²
- SSR(회귀 변동) = SST − SSE
- R² = SSR / SST = 1 − SSE / SST

단순 회귀에서는 R²가 상관계수의 제곱과 같다. 여기서 시험이 자주 건드리는 점이 두 가지다.

- 변수를 추가하면 R²는 줄어들지 않는다. 쓸모없는 변수를 넣어도 마찬가지다.
- 그래서 다중 회귀에서는 변수 개수로 벌점을 준 수정된 결정계수(adjusted R²)를 같이 본다. 수정된 R²는 R²보다 클 수 없고, 새 변수가 우연 이상으로 설명력을 올릴 때만 오른다.

<details>
<summary>손으로 계산해 보기 (x = 1~5, y = 2, 4, 5, 4, 5)</summary>

숫자 5개짜리 예제를 python으로 돌려 확인한 값이다.

- 최소제곱 결과: b1 = 0.6, b0 = 2.2, 식은 y = 2.2 + 0.6x
- SST = 6.0, SSE = 2.4, SSR = 3.6
- R² = 3.6 / 6.0 = 0.6 (상관계수 제곱도 0.6으로 같음)
- 수정된 R² = 1 − (1 − 0.6) × (5 − 1) / (5 − 1 − 1) ≈ 0.467
- F = (SSR / 1) / (SSE / 3) = 4.5

```python
import numpy as np
x = np.array([1, 2, 3, 4, 5.]); y = np.array([2, 4, 5, 4, 5.])
n, p = len(x), 1
b1 = ((x - x.mean()) * (y - y.mean())).sum() / ((x - x.mean())**2).sum()
b0 = y.mean() - b1 * x.mean()
sse = ((y - (b0 + b1 * x))**2).sum()
sst = ((y - y.mean())**2).sum()
r2 = 1 - sse / sst
adj = 1 - (1 - r2) * (n - 1) / (n - p - 1)
F = ((sst - sse) / p) / (sse / (n - p - 1))
```

시험에서 이 정도 계산은 SST, SSE 중 둘이 주어지고 R²나 F를 구하는 식으로 나온다.
</details>

## 다중공선성

독립변수끼리 강하게 상관돼 있으면 어느 변수가 y에 영향을 줬는지 가를 수 없고, 계수 추정이 불안정해진다. 이 현상이 다중공선성이다. 흔한 신호는 R²는 높은데 개별 계수의 t검정은 유의하지 않은 경우다.

진단은 분산팽창계수(VIF)로 한다. 변수 하나를 나머지 독립변수들로 회귀해서 얻은 R²를 Ri²라 하면 VIF = 1 / (1 − Ri²)이다. 기준은 보통 10 이상이면 심각하다고 보고, 5를 기준으로 쓰기도 한다. 시험에서는 10이 정답으로 나오는 쪽이다. 소프트웨어에 따라 VIF의 역수인 공차(tolerance)로 보여 주기도 한다.

해결은 상관 높은 변수 중 하나를 빼거나, 변수를 합치거나, 주성분분석으로 변수를 줄이는 방식이다. 주성분분석은 [자세히 → 다변량 분석과 시계열](#/post/adsp-multivariate-ts)에서 이어진다.

<details>
<summary>VIF 직접 계산해 보기</summary>

x1 = 1~6, x2 = 2.1, 3.9, 6.2, 8.1, 9.8, 12.1처럼 거의 두 배 관계인 두 변수를 만들어 x1을 x2로 회귀했더니 R²가 약 0.998, VIF는 약 624가 나왔다. 두 변수가 사실상 같은 정보라는 뜻이고, 기준 10을 훌쩍 넘는다.
</details>

## 변수 선택

후보 변수가 많을 때 어떤 걸 넣을지 정하는 방법이 세 가지다.

| 방법 | 시작 | 진행 |
|---|---|---|
| 전진 선택 | 변수 없음 | 가장 유의하게 개선시키는 변수를 하나씩 추가, 더 개선이 없으면 중단 |
| 후진 제거 | 변수 전부 | 빼도 손실이 가장 작은 변수를 하나씩 제거, 빼면 손실이 클 때 중단 |
| 단계적 선택 | 어느 쪽이든 | 추가와 제거를 매 단계 번갈아 검토 |

Wikipedia의 stepwise regression 항목도 같은 순서로 설명하고, 판단 기준으로 F검정이나 t검정의 연속을 든다. 전진 선택은 한번 넣은 변수를 못 빼고, 후진 제거는 한번 뺀 변수를 못 되살린다는 점이 비교 문제의 단골이다. 단계적 선택은 그 둘을 보완한다.

## 자주 나오는 유형과 푸는 방식

- 계수 해석: "x1이 1 증가하면 y는 b1 변한다(다른 변수 고정)"로 쓴다. 단위를 같이 본다.
- R² vs 수정된 R²: 변수가 늘었는데 R²만 오르고 수정된 R²가 내려가면 불필요한 변수가 들어간 것이다.
- p값 판단: 계수의 p값이 유의수준보다 작으면 그 변수는 유의하다. F검정 p값이 작으면 모형 전체가 유의하다.
- 가정 점검: 잔차 그림 모양을 가정 이름과 연결한다. 깔때기는 등분산성, 곡선 패턴은 선형성이다.
- 다중공선성: R²는 높은데 t검정이 대부분 비유의하면 의심하고, VIF 10을 기준으로 답한다.
- 변수 선택: 전진, 후진, 단계적의 시작점과 진행 방향을 표로 외운다.

기출문제는 원문을 여기 옮기지 않았다. 문제를 풀 때 위 여섯 줄 중 어느 유형인지 먼저 분류하는 것부터 하면 된다.

## 흔한 오해

- R²가 높으면 좋은 모형이다: 변수를 늘리면 R²는 무조건 오른다. 수정된 R²와 잔차를 같이 본다.
- 회귀계수가 크면 영향이 크다: 변수 단위가 다르면 계수 크기를 그냥 비교할 수 없다.
- 상관이 있으면 인과다: 회귀는 관계를 식으로 쓸 뿐 원인을 증명하지 않는다.
