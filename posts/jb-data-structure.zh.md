信息处理技术员考试的数据结构部分，与其死记硬背概念，不如动手练习，这样更容易转化为分数。考试中常考的类型包括：栈中剩余什么、遍历树时的顺序、以及从图的何处开始访问等，都需要在纸上画图理解。本文按此逻辑整理。关于考试日程和报考相关信息，请查阅官方网站。

## 一览分类

| 类别 | 类型 | 核心问题 |
|---|---|---|
| 线性 | 数组、链表、栈、队列、双端队列 | 从哪一端插入或删除？ |
| 非线性 | 树、图 | 访问顺序是什么？ |

线性结构是指数据呈单行排列的结构，而非线性结构是指从一个节点分叉出多个分支的结构。考试中会出现如“下列哪项不是线性结构”的分类确认题，以及要求按顺序执行运算后得出结果的题目。

## 线性结构

数组可通过索引直接访问，但在中间插入元素时需要移动后续元素。链表通过节点指向下一个节点的方式实现，插入操作只需修改指针；但若要查找第 i 个元素，则必须从头开始遍历。

| | 访问 | 中间插入/删除 |
|---|---|---|
| 数组 | 快（索引） | 慢（需移动） |
| 链表 | 慢（需遍历） | 快（修改指针） |

栈是后进先出（LIFO），仅在一端进行插入和删除；队列是先进先出（FIFO），从后端插入、前端删除；双端队列两端均可操作。栈用于函数调用、回溯、括号匹配等场景；队列用于按顺序处理的任务等待队列。在 Python 中创建队列时，由于列表的 `pop(0)` 时间复杂度为 O(n)，因此推荐使用 `deque`。官方文档也指出：`deque` 两端的添加和删除操作约为 O(1)，而列表的 `pop(0)` 为 O(n)。关于编码题目的详细内容，请参见 [详细说明 → 栈·队列·双端队列](#/post/algo-stack-queue)。

考试中，栈几乎总是以“中缀表达式转后缀表达式”的形式出现。

### 表达式表示法

根据运算符位置不同，有三种表示法：

| 名称 | 运算符位置 | 示例 (A+B) |
|---|---|---|
| 前缀 (prefix) | 操作数之前 | +AB |
| 中缀 (infix) | 中间 | A+B |
| 后缀 (postfix) | 之后 | AB+ |

将中缀转换为后缀的规则如下：直接输出操作数；运算符压入栈，但若栈顶运算符优先级相同或更高，则先弹出并输出。遇到左括号时压入栈，遇到右括号时弹出直至匹配左括号。最后将栈中剩余元素全部弹出。按此规则编写的代码运行结果如下：

| 中缀表达式 | 后缀表达式 |
|---|---|
| A+B*C | ABC*+ |
| (A+B)*C | AB+C* |
| A-B-C | AB-C- |

当优先级相同时（如第三例），遵循左结合性，左侧先处理。后缀表达式的计算更简单：从左到右读取，数字压入栈，遇到运算符时弹出两个数进行运算后再压回。注意 `3 4 2 * +` 的计算过程是：先计算 4*2=8，再计算 3+8=11。只需小心弹出顺序——第一个弹出的值是右侧操作数（在减法或除法中顺序会颠倒）。

<details>
<summary>转换与计算代码（可直接运行验证上述结果）</summary>

```python
def topost(s):
    pr = {'+': 1, '-': 1, '*': 2, '/': 2}
    st, out = [], []
    for c in s:
        if c.isalnum():
            out.append(c)
        elif c == '(':
            st.append(c)
        elif c == ')':
            while st[-1] != '(':
                out.append(st.pop())
            st.pop()
        else:
            while st and st[-1] != '(' and pr[st[-1]] >= pr[c]:
                out.append(st.pop())
            st.append(c)
    while st:
        out.append(st.pop())
    return ''.join(out)

print(topost('A+B*C'), topost('(A+B)*C'), topost('A-B-C'))
# ABC*+ AB+C* AB-C-

def ev(s):
    st = []
    for c in s.split():
        if c in '+-*/':
            b = st.pop(); a = st.pop()
            st.append({'+': a+b, '-': a-b, '*': a*b, '/': a/b}[c])
        else:
            st.append(float(c))
    return st[0]

print(ev('3 4 2 * +'))  # 11.0
```

</details>

## 树

树是无环连通结构，相关术语在考试中直接出现。

| 术语 | 含义 |
|---|---|
| 根 (Root) | 没有父节点的顶层节点 |
| 叶/终端 (Leaf) | 没有子节点的节点 |
| 度数 (Degree) | 一个节点的子节点数量（树的度数为所有节点度数中的最大值） |
| 深度/高度 | 从根到该节点的距离 / 到最深层的长度 |

具有 n 个节点的树有 n-1 条边。二叉树中每个节点最多有两个子节点。在二叉树中，第 i 层（根为第 1 层）最多有 2^(i-1) 个节点；高度为 h 的二叉树最多有 2^h - 1 个节点。题目中若将根视为第 0 层或第 1 层，公式会不同，因此需先阅读条件。

### 遍历（最常考部分）

三种深度优先遍历的区别仅在于“何时访问自身”。三者均优先访问左子树再访问右子树。

| 名称 | 顺序 | 记忆方法 |
|---|---|---|
| 前序 (Preorder) | 自身 → 左 → 右 | 自身在前 (Pre) |
| 中序 (Inorder) | 左 → 自身 → 右 | 自身在中 |
| 后序 (Postorder) | 左 → 右 → 自身 | 自身在后 |

层序遍历按从上到下逐层访问，通常用队列实现。以下为对示例树的实际运行结果：

```
        A
       / \
      B   C
     / \   \
    D   E   F
```

| 遍历方式 | 结果 |
|---|---|
| 前序 | A B D E C F |
| 中序 | D B E A C F |
| 后序 | D E B F C A |
| 层序 | A B C D E F |

前序、中序和后序遍历只是观察同一节点的时机不同，因此如果在每个节点经过时分别记录“左侧”、“下方”和“右侧”，可以减少错误。具体而言：经过节点瞬间向左看是前序，向下看是中序，向右看是后序。

由此还会引出通过两次遍历结果还原树的问题。对于值不重复的树，前序和中序的组合可以唯一确定树的形状；而这一点与前序和后序的组合并不总是成立。还原方法如下：前序序列的第一个值是根节点，在中序序列中找到该值，其左侧为左子树，右侧为右子树。然后递归地重复此过程。

<details>
<summary>遍历与还原代码（运行验证）</summary>

```python
from collections import deque

class N:
    def __init__(s, v, l=None, r=None):
        s.v, s.l, s.r = v, l, r

def pre(n):  return [] if not n else [n.v] + pre(n.l) + pre(n.r)
def ino(n):  return [] if not n else ino(n.l) + [n.v] + ino(n.r)
def post(n): return [] if not n else post(n.l) + post(n.r) + [n.v]

def level(n):
    q, out = deque([n]), []
    while q:
        x = q.popleft(); out.append(x.v)
        if x.l: q.append(x.l)
        if x.r: q.append(x.r)
    return out

t = N('A', N('B', N('D'), N('E')), N('C', None, N('F')))
print(pre(t), ino(t), post(t), level(t))

def build(p, i):                      # 전위 + 중위 -> 트리
    if not p: return None
    k = i.index(p[0])
    return N(p[0], build(p[1:k+1], i[:k]), build(p[k+1:], i[k+1:]))

print(post(build(list('ABDECF'), list('DBEACF'))))
# ['D', 'E', 'B', 'F', 'C', 'A']
```

</details>

### 二叉搜索树与堆

二叉搜索树（BST）遵循“左子节点小于父节点，右子节点大于父节点”的规则。对该树进行中序遍历会得到升序序列。依次插入 50, 30, 70, 20, 40, 60, 80 后进行中序遍历，结果为 20 30 40 50 60 70 80。

搜索、插入和删除操作的平均时间复杂度为 O(log n)。但由于树的形状受输入顺序影响，若按 10, 20, 30, 40 这样的有序序列插入，树会退化为单侧倾斜的链表，最坏情况时间复杂度变为 O(n)。上述树的高度为 3，而四个有序节点构成的树高度为 4。为防止此类问题，存在保持平衡的树（如 AVL 树）。AVL 树是最早的自平衡二叉搜索树，每次插入或删除后都会检查并调整高度。

堆是一种完全二叉树，其中每个父节点始终大于或等于（最大堆）或小于或等于（最小堆）其子节点。它常用于需要快速取出最大值或最小值的优先级队列。使用 Python 的 `heapq` 模块依次插入 5, 3, 8, 1, 2 后逐个弹出，结果为 1, 2, 3, 5, 8。与 BST 不同，堆中兄弟节点之间没有大小顺序限制。关于编码问题中的相关视角，可参考 [详细说明 → 树·堆·优先级队列](#/post/algo-tree-heap)。

## 图

图是由顶点和边组成的集合。若存在方向则为有向图，否则为无向图。对于包含 n 个顶点的无向图，其边的最大数量为 n(n-1)/2。可以将树视为一种无环且连通的图。

图的表示方法主要有两种。以下通过示例图（边包括 1-2, 1-3, 2-4, 3-4, 4-5）进行说明：

| 方式 | 形状 | 空间复杂度 | 特点 |
|---|---|---|---|
| 邻接矩阵 | n×n 表中，若存在边则标记为 1 | O(n²) | 可直接判断两个顶点是否相连 |
| 邻接表 | 每个顶点对应一个邻居列表 | O(n + 边数) | 当边较少时占用空间更少 |

无向图的邻接矩阵关于对角线对称。将矩阵中所有 1 相加并除以 2，即可得到边数 5。顶点 4 的邻居为 2, 3, 5，因此其度数为 3。

### 图遍历

深度优先搜索（DFS）使用栈（或递归），广度优先搜索（BFS）使用队列。从顶点 1 开始，并按编号较小的邻居优先访问，结果如下：

| 方式 | 访问顺序 |
|---|---|
| DFS | 1 2 4 3 5 |
| BFS | 1 2 3 4 5 |

考试中题目会明确“选择邻居的顺序”条件，应严格按照题目要求执行。与树遍历类似，只需记住"BFS = 队列，DFS = 栈”这一对应关系即可确定解题方向。具体实现可参考 [详细说明 → BFS·DFS 与图](#/post/algo-graph-search)。

<details>
<summary>图代码（运行验证）</summary>

```python
from collections import deque

E = [(1, 2), (1, 3), (2, 4), (3, 4), (4, 5)]
adj = {i: [] for i in range(1, 6)}
for a, b in E:
    adj[a].append(b); adj[b].append(a)

def dfs(g, s):
    seen, st = [], [s]
    while st:
        x = st.pop()
        if x in seen: continue
        seen.append(x)
        for y in sorted(g[x], reverse=True):   # 작은 번호가 먼저 나오도록
            st.append(y)
    return seen

def bfs(g, s):
    seen, q = [s], deque([s])
    while q:
        x = q.popleft()
        for y in sorted(g[x]):
            if y not in seen:
                seen.append(y); q.append(y)
    return seen

print(dfs(adj, 1), bfs(adj, 1))
# [1, 2, 4, 3, 5] [1, 2, 3, 4, 5]
```

</details>

## 常见题型与解决步骤

| 类型 | 解决步骤 |
|---|---|
| 栈/队列操作结果 | 逐步应用操作，并在纸上记录当前状态 |
| 表达式转换与计算 | 依据优先级和括号规则，按栈逻辑处理 |
| 树遍历结果 | 确认访问节点的时机，并从左子节点向下遍历 |
| 通过两次遍历还原树 | 前序首元素为根节点，利用中序区分左右子树 |
| 节点与边数量计算 | n 个节点的树有 n-1 条边；高度为 h 的二叉树最多有 2^h - 1 个节点 |
| 图遍历 | 确认起始顶点及邻居选择条件，DFS=栈，BFS=队列 |
| 时间复杂度比较 | 区分 BST 平均 O(log n) 与最坏 O(n) 的情况 |

## 常见错误

- 混淆栈和队列的弹出端并错误应用。
- 在后缀表达式计算中颠倒减法或除法的操作数顺序。
- 未确认是从 0 还是从 1 开始计数层级，就直接使用 2^h 公式。
- 混淆中序与后序遍历结果：可通过“节点为根时，后序出现在最后，前序出现在最前”来区分。
- 误记 BST“总是 O(log n)"：若树形状倾斜，则退化为 O(n)。
