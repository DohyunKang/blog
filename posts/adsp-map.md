ADsP 공부 노트 열두 편을 한자리에 모았다. 1과목은 개념, 2과목은 기획, 3과목은 통계와 분석이다. 시험 일정·응시료는 바뀌니 공식 사이트에서 확인한다.

## 한눈에 보는 순서

```
1과목 데이터 이해
 데이터의 이해 → 데이터의 가치와 미래 → 데이터 사이언스와 인재
2과목 데이터 분석 기획
 분석 기획 → 분석 방법론 → 분석 과제와 마스터플랜
3과목 데이터 분석
 R·데이터 마트 → 통계 기초 → 가설 검정 → 회귀 → 다변량·시계열 → 데이터 마이닝
```
