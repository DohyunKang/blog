机器学习是一种不让人类编写规则，而是展示数据，让模型自行拟合出符合规则的数值（权重）的方法。深度学习则是其中使用深层堆叠神经网络的一种。

## 从简单的话说起

假设我们要编写一个过滤垃圾邮件的程序。以前的方法是让人类逐条编写规则，例如“如果标题中包含‘中奖’二字就是垃圾邮件”。机器学习则恰恰相反：提供大量标记为垃圾邮件和非垃圾邮件的样本，让模型从数据中自行找出区分两者的规则。

这些规则的实质是数字。它接收输入，将几个数字（权重）相乘并相加来得出答案。起初这些数字乱七八糟，导致答案也很糟糕。学习的过程就是逐步修正这些数字，使错误减少。“学习”这个词听起来很宏大，但实际上做的事情只是调整数字而已。

深度学习也是同样的框架。不同之处在于参与运算的数字从几十个增加到数百万甚至数千亿，并且将相乘和相加的步骤堆叠成多层。关于层结构，详见 [深入讲解 → 神经网络与反向传播](#/post/ml-neural-net)。LLM 也建立在这个框架之上。[深入讲解 → LLM](#/post/ai-llm)

## 学习的三个部件

拆解一次学习过程，会发现它由三部分组成。

| 部件 | 作用 | 示例 |
|---|---|---|
| 模型 | 一种从输入得出答案的机制，内部包含可调节的数字（参数） | `预测 = w × 输入 + b` |
| 损失函数 | 用一个数字衡量答案偏离了多少 | 均方误差 (MSE)，即对误差平方后取平均 |
| 优化器 | 调整参数以使损失减小 | 梯度下降法 |

这三者的运行顺序始终一致：先用当前数字进行预测，计算损失，然后朝着使损失减小的方向微调数字，并重复此过程。

## 损失函数

损失函数是一个将“偏离程度”压缩为一个数字的函数。数字越小表示拟合得越好。之所以要压缩成一个数字，是因为只有这样我们才能确定“损失减小”的方向。

在回归（预测数值）任务中，常见的是计算均方误差 (MSE)，即对误差进行平方后取平均。平方操作使得负向和正向误差不会相互抵消，并且对较大错误的惩罚更重。在分类（是垃圾邮件还是非垃圾邮件）任务中，通常使用另一种称为交叉熵的损失函数。这种损失函数的特点是：预测的概率越偏离正确答案，损失值就越大。具体的公式此处不再展开。

选择何种损失函数，实际上决定了“希望模型擅长什么”。因为模型只会致力于减小损失。

## 梯度下降法

梯度下降法 (gradient descent) 是一种寻找损失最低点并沿该方向下降的方法。Google 的机器学习课程是这样解释的：从权重和偏置接近 0 的地方开始，计算损失，找到使损失减小的方向，然后朝该方向移动一小步，并重复此过程。如果损失不再减小，则停止。

将其想象为在雾中下山会更容易理解。你看不到山顶，只能感受到脚下的坡度。朝着下坡的方向走一步，再感受脚下，如此循环。脚下的坡度即为梯度 (gradient)，每一步的大小即为学习率 (learning rate)。更新公式如下：

`新值 = 旧值 − 学习率 × 梯度`

如果学习率太小，下山会非常缓慢；如果太大，则可能跳过谷底，反而导致损失增大。因此，学习率是人工设定的超参数中最早需要确定的一个。

我亲自运行了代码。这是一个拟合五个点（在 `y ≈ 2x + 1` 附近略有波动）的直线方程的代码。

```python
import numpy as np
x = np.array([1,2,3,4,5], dtype=float)
y = np.array([3.1,4.9,7.2,8.8,11.1])
w, b, lr = 0.0, 0.0, 0.01
for step in range(1, 1001):
    pred = w*x + b
    err = pred - y
    loss = (err**2).mean()
    gw = 2*(err*x).mean()   # 손실을 w로 미분한 값
    gb = 2*err.mean()       # 손실을 b로 미분한 값
    w -= lr*gw; b -= lr*gb
    if step in (1,10,100,1000):
        print(step, round(loss,4), round(w,3), round(b,3))
```

执行结果如下：

| 迭代次数 | 损失 | w | b |
|---|---|---|---|
| 1 | 57.222 | 0.501 | 0.14 |
| 10 | 0.5012 | 1.972 | 0.563 |
| 100 | 0.0414 | 2.081 | 0.72 |
| 1000 | 0.0214 | 1.994 | 1.034 |

损失从 57 降至 0.02，w 收敛至 2 附近，b 收敛至 1 附近。大部分下降发生在前几次迭代中，之后则是缓慢微调的过程。神经网络也完全沿用此框架。当参数数量变得极其庞大时，高效计算梯度的方法就是反向传播。

## 过拟合

学习的目标不是拟合训练数据，而是能够拟合从未见过的新数据。用 Google 课程的话来说，这种能力称为泛化 (generalization)，其反面状态即为过拟合 (overfitting)。即模型在训练数据上表现极好，却无法应对新数据。

打个比方，就像只死记硬背了历年考题的答案。虽然历年真题能拿满分，但只要题目稍有变化就会出错。当模型的参数过多而数据过少时，这种“死记硬背”现象更容易发生。这是因为模型连数据中混杂的噪声（偶然的波动）也当作规则给记住了。

我也运行了相关实验。在 `sin(2x)` 函数上添加了噪声生成了 60 个点，使用其中 30 个进行训练（学习），另外 15 个用于验证，并改变了多项式的阶数。阶数越高，模型越复杂。

```python
import numpy as np
rng = np.random.default_rng(0)
x = rng.uniform(-1,1,60)
y = np.sin(2*x) + rng.normal(0,0.2,60)
idx = rng.permutation(60)
tr, va, te = idx[:30], idx[30:45], idx[45:]
def mse(p,i): return float(((np.polyval(p,x[i])-y[i])**2).mean())
for d in (1,3,9,15):
    p = np.polyfit(x[tr], y[tr], d)
    print(d, round(mse(p,tr),3), round(mse(p,va),3))
```

| 迭代次数 | 训练损失 | 验证损失 |
|---|---|---|
| 1 | 0.075 | 0.07 |
| 3 | 0.032 | 0.044 |
| 9 | 0.024 | 0.048 |
| 15 | 0.021 | 0.936 |

训练损失随着迭代次数增加持续下降。验证损失在迭代次数为 3 附近最低，但在迭代次数为 15 时突然飙升至 0.936。如果只看训练数据，迭代次数为 15 的模型似乎是最好的。然而，迭代次数为 1 的模型则过于简单，导致两者损失都很高，这种情况被称为欠拟合。

Google 的课程也传达了同样的信号：当训练损失持续下降或趋于平稳，而验证损失从某个时间点开始上升时，就意味着发生了过拟合。

## 学习·验证·测试

在上述实验中，如果没有验证数据，我们就无法察觉过拟合现象。因此，通常将数据分为三部分。

| 数据 | 用途 |
|---|---|
| 训练 (training) | 用于调整参数 |
| 验证 (validation) | 用于监测训练过程中是否发生过拟合，以及选择模型类型、学习率等超参数 |
| 测试 (test) | 仅在最后使用一次，用于评估模型在实际环境中的表现 |

单独保留测试集的原因是，验证数据在模型选择过程中已经被“查看”过了。如果在观察验证分数的基础上反复调整，模型可能会无意中适应验证集。测试集则不应参与任何选择过程，以确保其评估结果的公正性。上述代码中的 `te` 即为该位置，在本次实验中未使用并留空。

减少过拟合的方法包括增加数据量、简化模型、施加正则化（对参数过大进行惩罚）或在验证损失开始上升时停止训练（早停）等。

## 常见误区

- **训练准确率高就是好模型**：如上表所示，训练损失随着模型复杂度增加而持续下降。真正需要关注的是在未见过的数据上的表现。
- **模型越大越好**：如果模型相对于数据过大，很容易发生过拟合。不过，对于像大规模 LLM 这样同时使用海量数据的特殊情况则另当别论，不能将本文讨论的小规模示例直接套用。
- **学习就是死记硬背答案**：死记硬背会导致过拟合。目标是掌握规律（泛化）。
- **梯度下降法总能到达最小值**：只有像直线拟合那样损失函数形状简单（凸函数）的情况才成立。对于神经网络等复杂情况，并无此保证。
- **深度学习与机器学习完全不同**：深度学习是机器学习的一个分支。上述三个组件和数据划分方法同样适用。

<summary>详细解析：手动计算梯度下降的一步</summary>

假设有一个点 `(x=2, y=5)`，模型为 `预测 = w × x`，初始 `w = 0`，学习率为 `0.1`。

- 预测 = 0 × 2 = 0，误差 = 0 − 5 = −5
- 损失 = 误差² = 25
- 对 w 求导得 `2 × 误差 × x = 2 × (−5) × 2 = −20`
- 新 w = 0 − 0.1 × (−20) = 2

斜率为负意味着“增大 w 会降低损失”，更新公式中的负号正是将 w 推向增大的方向。当新 w = 2 时，预测值为 4，误差降至 −1。若再进行一次迭代，斜率变为 `2 × (−1) × 2 = −4`，w 更新为 2.4，逐渐接近正确答案 2.5。

上述 numpy 代码则是基于 5 个点的平均值进行计算，并同时更新了 w 和 b 两个参数。
