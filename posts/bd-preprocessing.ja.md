ビッグデータ分析技師試験において、前処理は筆記と実技の両方に登場します。筆記では概念や用語を選ばせられ、実技では同じ作業を pandas や scikit-learn（R を使う場合は R 関数）で直接行います。そのため、用語、いつ使うのか、コードの一行をセットにして覚えるのが良いでしょう。データを収集・保存する前の段階は [詳しく → データ収集と保存](#/post/bd-collection-storage) にあります。

## 一目でわかる流れ

| 作業 | 解決しようとする問題 | 代表的な方法 |
|---|---|---|
| 欠損値処理 | 値が空である | 削除、平均・中央値・最頻値による置換、補間 |
| 外れ値処理 | 他の値とは異なる値が存在する | IQR 基準、標準化スコア、削除・置換 |
| 変換 | 値の範囲や形状がバラバラである | 正規化、標準化、対数変換、区間化 |
| エンコーディング | モデルが文字カテゴリを読み込めない | 独熱エンコーディング、ラベルエンコーディング |
| 不均衡処理 | クラスの一つが極端に少ない | オーバーサンプリング、アンダーサンプリング、重み付け |
| 分割 | 評価を公平に行いたい | 学習・検証・テスト、層化分割 |

以下の例題はすべて同じ小さなデータセットを使用しています。年齢 6 名、所得 6 名、都市 6 名のデータです。

```python
import pandas as pd, numpy as np
df = pd.DataFrame({
    'age':[25,30,np.nan,45,28,100],
    'income':[300,350,400,np.nan,320,330],
    'city':['서울','부산','서울','대구','부산','서울']})
print(df.isna().sum())   # age 1, income 1, city 0
```

## 欠損値

pandas は、空の値を float タイプの列では NaN とします。整数型の列に NaN が一つでも含まれると、その列は float に変換されます。空かどうかを確認する際は `==` ではなく `isna()` を使用します。これは、NaN と NaN は等しくないと判定されるためです。

処理方法は主に 3 つあります。

| 方法 | コード | 何时 |
|---|---|---|
| 削除 | `df.dropna()` | 欠損率が低く、無作為に欠落している場合 |
| 置換 | `df.fillna(値)` | 平均（数値）、中央値（歪んだ分布）、最頻値（カテゴリ） |
| 補間 | `s.interpolate()`, `s.ffill()` | 時系列データの場合 |

```python
df.dropna()             # 6행 중 4행만 남는다
df.fillna({'age': df['age'].median(), 'income': df['income'].mean()})
# age의 빈칸은 30, income의 빈칸은 340이 들어간다
pd.Series([1, np.nan, 3]).interpolate().tolist()  # [1.0, 2.0, 3.0]
pd.Series([1, np.nan, 3]).ffill().tolist()        # [1.0, 1.0, 3.0]
```

ここでは、`dropna()` が 6 行を 4 行に減らした点に注意しました。列が多い場合、一行に空白が一つでもあればその行全体が削除されてしまいます。そのため、試験では置換の方が削除よりも先に登場することが多いです。

置換値は分布に応じて選択します。年齢に 100 が混ざっていると平均が引き上げられるため、中央値の方が安全です。`interpolate()` はデフォルトで線形補間であり、先頭の値をそのまま持ってくる `ffill()` の結果とは異なります。上記の 2 つの出力はその違いを示しています。

<details>
<summary>欠損発生タイプ (MCAR・MAR・MNAR)</summary>

欠損がなぜ生じたかによって 3 つのタイプに分類されます。

| タイプ | 意味 | 例 |
|---|---|---|
| MCAR | 完全に無作為に欠落する | センサーが偶然一度切れた場合 |
| MAR | 他の観測変数に応じて欠落する | 若年層が所得項目をより頻繁にスキップする場合 |
| MNAR | 欠落した値そのものに応じて欠落する | 所得が高い人が所得を記入しない場合 |

MCAR の場合は削除してもバイアスは小さく、MNAR の場合は削除・置換の両方に注意が必要であることを整理しておけばよいでしょう。
</details>

## 外れ値

外れ値とは、他の値と離れた値のことです。エラーである可能性もあれば、真の極端値である可能性もあるため、削除する前に原因を確認します。試験では IQR 基準が最も頻出します。

基準は Q1 − 1.5×IQR 未満、Q3 + 1.5×IQR 超です。年齢値 25, 30, 45, 28, 100（欠損を除く）で計算すると以下のようになります。

```python
x = df[['age']].dropna()
q1, q3 = x['age'].quantile([.25, .75])   # 28.0, 45.0
iqr = q3 - q1                            # 17.0
lo, hi = q1 - 1.5*iqr, q3 + 1.5*iqr      # 2.5, 70.5
x[(x.age < lo) | (x.age > hi)]           # 100만 걸린다
```

下限 2.5、上限 70.5 なので、100 のみが外れ値として検出されます。標準化スコア (z-score) で見る方法もあります。通常、絶対値が 3 を超えると外れ値とみなします。平均と標準偏差自体が外れ値の影響を受けるため、サンプルサイズが小さい場合は IQR の方が影響を受けにくいです。

処理は削除、上下限値での置換、変換（対数など）、そのまま放置し外れ値に強い手法を使うことの中から選択します。探索段階で外れ値をどのように扱うかは [詳しく → 探索的解析と基礎統計](#/post/bd-eda-stats) と続きます。

## 変換

### 正規化と標準化

どちらも変数の単位や範囲を揃える作業です。距離ベースのモデル (k-NN, k-平均) や勾配降下法を使用するモデルでは、単位が大きい変数が結果を支配しやすいため必要です。木ベースのモデルは通常、大きく関係ないと知られています。

| 名前 | 式 | 結果範囲 | scikit-learn |
|---|---|---|---|
| ミニマックス正規化 | (x − min) / (max − min) | 0~1 | `MinMaxScaler` |
| 標準化 (z-score) | (x − 平均) / 標準偏差 | 平均 0, 標準偏差 1 | `StandardScaler` |
| ロバストスケーリング | 中央値・四分位数基準 | 外れ値の影響が小さい | `RobustScaler` |

同じ年齢値 [25, 30, 45, 28, 100] に両方の方法を適用しました。

```python
from sklearn.preprocessing import StandardScaler, MinMaxScaler
StandardScaler().fit_transform(x).ravel().round(3)
# [-0.734 -0.556 -0.021 -0.627  1.939]
MinMaxScaler().fit_transform(x).ravel().round(3)
# [0.    0.067 0.267 0.04  1.   ]
```

最小・最大は 100 が 1 つあるため、残りは 0〜0.27 の間に集中しています。外れ値があると正規化の結果が片寄ってしまいます。そのため、外れ値が多い場合はロバストスケーリングを使うという説明が付けられます。用語の名前が混同しやすいので、筆記試験では式を見て名前を選ぶ問題として出題される可能性があります。

### 学習データのみでフィットさせる

スケーラーは学習データに対して `fit` し、テストデータには `transform` のみを行います。全データでフィットすると、テストデータの情報が学習に漏れてしまいます。scikit-learn のドキュメントでもパイプラインにまとめてこの順序を守るように示しています。

```python
tr = pd.DataFrame({'v':[1,2,3,4]}); te = pd.DataFrame({'v':[10]})
s = MinMaxScaler().fit(tr)
s.transform(te)    # [[3.]]
```

学習範囲が 1〜4 で、テスト値が 10 の場合、結果は 3 になります。0〜1 を超えるのは正常です。これを無理やり防ぐために全データで `fit` するのは避けてください。

### ログ変換と区間化

右側に偏った変数にはログを適用して形状を整えます。`np.log1p([1,10,100,1000])` は約 0.693、2.398、4.615、6.909 となり、1000 倍の差が 10 倍程度の差に縮まります。0 以下がある場合は `log` が使えないため `log1p` を使用します。

区間化は連続値をカテゴリに変換します。`pd.cut` は区間の幅を直接指定し、`pd.qcut` は件数が均等になるように分割します。

```python
pd.cut(pd.Series([5,15,25,35,45]), bins=[0,20,40,60], labels=['a','b','c']).tolist()
# ['a','a','b','b','c']
pd.qcut(pd.Series(range(1,9)), 4, labels=False).tolist()
# [0,0,1,1,2,2,3,3]
```

## エンコーディング

文字列で表されたカテゴリは数値に変換してモデルに入れます。カテゴリ間に順序がない場合はワンホットエンコーディング、順序がある場合はラベル（順位）エンコーディングが基本です。順序のないカテゴリに 1, 2, 3 を付与すると、モデルが数値の大きさを意味として読み取ってしまいます。

```python
pd.get_dummies(df['city'], dtype=int)
#    대구  부산  서울
# 0   0   0   1
# 1   0   1   0
# ...
pd.get_dummies(df['city'], drop_first=True, dtype=int)   # 열 하나를 뺀다
```

カテゴリが 3 つの場合、列も 3 つ生成されます。`drop_first=True` は 1 つの列を除外して残りで復元できるようにします（ダミー変数の罠を避けるため）。scikit-learn の `OneHotEncoder` も同様の処理を行っており、学習データにないカテゴリがテストデータで出現した際の処理オプション (`handle_unknown`) と `drop` オプションがあります。カテゴリの種類が非常に多い場合は列が爆発するため、頻度の低いカテゴリをまとめる手法を使います。

## 不均衡データ

陽性 5%、陰性 95% のような資料は、すべて陰性と判定しても精度が 95% になります。そのため、不均衡な資料では精度ではなく再現率や F1 スコアなどの指標を見ます。詳細については [詳しく → モデル評価](#/post/bd-evaluation) で扱います。

処理方法は 3 つあります。

| 方法 | 内容 | 注意点 |
|---|---|---|
| オーバーサンプリング | 少ない方を増やす（復元抽出による複製、SMOTE） | 複製は過学習しやすい |
| アンダーサンプリング | 多い方を減らす | 情報が失われる |
| 重み付け | 損失関数で少ないクラスに重み (`class_weight`) を付ける | データ自体はそのままにする |

`make_classification(n_samples=1000, weights=[.95,.05])` で作成した資料では、クラスの比率は 946 対 54 でした。これに `sklearn.utils.resample` を使うと以下のようになります。

```python
from sklearn.utils import resample
up = resample(Xm, replace=True,  n_samples=946, random_state=0)  # 54개 -> 946개
dn = resample(Xj, replace=False, n_samples=54,  random_state=0)  # 946개 -> 54개
```

SMOTE は少ない方のサンプル同士を繋いで新しいサンプルを作成する方式です。サンプリングは学習データのみに行い、テストデータは元の比率を維持します。

## 分割

学習・検証・テストに分割して評価を行います。クラス比率を維持するには `stratify` を使います。

```python
from sklearn.model_selection import train_test_split
a, b, c, d = train_test_split(X, y, test_size=.2, stratify=y, random_state=0)
np.bincount(c), np.bincount(d)   # [757 43], [189 11]
```

学習側が 43/800、テスト側が 11/200 で、どちらも約 5% です。`stratify` がなければ少ないクラスのサンプルが片方に偏ってしまいます。分割と交差検証の設計については [詳しく → 分析モデル設計](#/post/bd-model-design) で続きます。

## よくあるパターン

- 欠損値処理方法の長所・短点と、どの値で代替するかを選ぶ
- IQR を基準に外れ値の境界値を計算する
- 正規化・標準化の式を見て名前を当てる、外れ値に強い方を選ぶ
- 順序のないカテゴリにワンホットを使う理由
- 不均衡な資料で精度がなぜ危険なのか、サンプリング手法の違い
- スケーラーをどのデータに `fit` するか（学習データのみ）

実技試験では `isna().sum()`、`fillna`、スケーラーの `fit_transform`/`transform` の区別、`get_dummies`、`train_test_split` がセットで出題されます。試験日程と受験要件は公式サイトで確認してください。
