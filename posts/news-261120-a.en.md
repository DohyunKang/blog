Give it a topic and it pulls the last 30 days of posts from Reddit, X, YouTube, Hacker News, GitHub and more, groups them, and summarizes them in the order people actually reacted to them. It's an agent skill. I read the README, CONCEPTS.md, parts of CONFIGURATION.md and the CHANGELOG. I didn't run it myself.

## What it is
A skill is a folder of instructions an agent pulls out when it needs it. [More → Skills](#/post/ai-skills) In Claude Code you call it with `/last30days topic`, and it installs into other agents like Codex or Cursor with `npx skills add`. The author says he built it to keep up with AI. Model training data is always months behind, and new tricks show up on Reddit and X first.

The README's pitch fits in one line: search engines collect edited writing, this collects people's reactions. So ranking uses engagement signals like Reddit upvotes, X likes, YouTube transcript content and Polymarket odds. Polymarket is a prediction market where people bet money on outcomes, so the odds are the probability people put on something.

## How it runs inside
It's split in two. SKILL.md tells the model which flags to call the engine with, and the actual searching is done by a Python engine, `scripts/last30days.py`. The engine returns a fixed output shape, and the model passes it through and summarizes it.

1. Pull the core subject out of the topic. For something like "X pricing" it drops "pricing" and keeps X. It looks up that subject's X handles, GitHub repos, subreddits and YouTube channels first.
2. Split the question into several subqueries and search each source separately, in parallel.
3. When the same post comes back from several searches, merge it by normalized URL. When different platforms talk about the same thing, group it into one cluster.
4. Posts that don't mention the subject get pushed down hard, no matter how much engagement they have. What's left is ranked by engagement, relevance and freshness.
5. The model writes one brief, cluster by cluster, with sources.

Step 4 was the interesting part. The docs call it Entity grounding, and it only checks the first word of the subject's name. Trailing words are usually search descriptors, and requiring them would drop posts that are on topic. The other way around, if the subject is a common word like "ai" or "new", the bar goes up so viral off-topic posts can't take the slots.

Whether an LLM judges relevance is up to you. With an OpenAI, xAI or Gemini key, it sends the topic and snippets of what it found to that model and reranks them. Without a key it falls back to local scoring. Reddit, HN, Polymarket and GitHub work with no key at all, according to the docs. Answering on top of retrieved posts is a lot like RAG. [More → RAG](#/post/ai-rag)

There's also a Discovery mode that runs without a topic and finds what's trending by itself. It only shows things that appear across several sources or spike very hard in one. If nothing clears the bar, it says nothing solid came up instead of filling the page. That's written into the docs as a rule, which I liked.

## For beginners
For a PM, it bundles the job of opening tab after tab to see how people are talking about something right now. The examples are researching someone before a meeting and finding the problems people hit before building a feature. But the ranking is based on reactions, so loud doesn't mean right. I'd use the brief as a starting point and still open the originals.

If you're new to development, it's worth noticing that every source authenticates differently. For X, the path that reads your logged-in browser session cookie comes first by default, with paths that use API keys after it. It asks for consent before reading cookies, and `--no-browser-cookies` turns that off. For the option that uses your Reddit login session, the docs themselves say it may breach Reddit's terms. There's also `--preflight` to check what it will read and write before running, which is a nice touch. For other skill collections, see the older post.
