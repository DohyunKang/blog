[AI 개념 map](#/post/ai-map)가 용어를 위에서 훑는 글이라면, 이 글은 그 아래쪽, 모델이 실제로 어떻게 배우고 어떻게 돌아가는지를 모았다. 순서는 학습의 기본 → 구조 → 모델이 만들어지는 단계 → 내 쪽에서 손대는 법 → 돌리는 법 → 이미지 모델 순이다. 한 줄 설명만 먼저 읽고, 궁금한 건 링크로 넘어가면 된다.

## 한눈에 보는 흐름

```
학습 기초(손실·경사하강법)
  → 신경망과 역전파
    → 트랜스포머(어텐션)
      → 사전학습 → 지시 튜닝(SFT) → 선호 학습(RLHF·DPO)
        → 파인튜닝(LoRA/QLoRA)
        → 로컬에서 돌리기(양자화·VRAM)
        → 추론 최적화(KV 캐시·배치)
(별도 계열) 이미지 생성 = 확산 모델
```

## 1. 학습이 뭔가

**머신러닝·딥러닝 기초**: 학습은 틀린 정도(손실)를 숫자로 재서 가중치를 조금씩 고쳐 가는 일이다. 훈련 데이터에서 잘 맞는다고 끝이 아니라서 과적합과 검증·테스트 나누기도 같이 나온다.
[자세히 → 머신러닝·딥러닝 기초](#/post/ml-basics)

**신경망과 역전파**: 곱하고 더하고 휘는 계산을 층층이 쌓은 함수가 신경망이고, 역전파는 그 가중치를 어느 쪽으로 고칠지 출력 쪽에서 거꾸로 계산하는 방법이다.
[자세히 → 신경망과 역전파](#/post/ml-neural-net)

## 2. LLM의 뼈대

**트랜스포머와 어텐션**: 단어마다 문장 속 다른 단어를 얼마나 참고할지 점수로 계산하는 구조다. 순서대로 읽지 않고도 문맥을 잡고, 요즘 LLM이 거의 다 이 뼈대를 쓴다.
[자세히 → 트랜스포머와 어텐션](#/post/ml-transformer)

## 3. 챗봇이 만들어지는 과정

**사전학습에서 RLHF까지**: 글을 먹고 다음 단어를 맞히는 사전학습, 질문에 답하는 법을 보여 주는 지시 튜닝(SFT), 사람이 고른 쪽으로 밀어 주는 선호 학습(RLHF·DPO). 세 단계를 거쳐야 대화가 되는 모델이 나온다.
[자세히 → 사전학습에서 RLHF까지](#/post/ml-pretraining)

## 4. 내 쪽에서 손대기

**파인튜닝: 전체 vs LoRA/QLoRA**: 사전학습이 끝난 모델을 내 데이터로 한 번 더 가르치는 일이다. LoRA를 쓰면 모델 전체를 건드리지 않고도 되고, 그래서 필요한 GPU가 크게 줄어든다.
[자세히 → 파인튜닝: 전체 vs LoRA/QLoRA](#/post/ml-finetuning)

## 5. 돌리는 쪽

**로컬 모델 돌리기**: 내 PC 그래픽카드에 모델이 들어가느냐는 파라미터 수, 양자화 비트 수, 컨텍스트 길이로 대략 계산이 된다. 양자화와 VRAM 계산이 중심이다.
[자세히 → 로컬 모델 돌리기](#/post/ml-local-models)

**추론 최적화**: 만드는 게 아니라 돌리는 쪽 이야기다. KV 캐시, 배치, 스트리밍, 투기적 디코딩이 결국 GPU 메모리를 어떻게 나눠 쓰느냐로 이어진다.
[자세히 → 추론 최적화](#/post/ml-inference)

## 6. 글 말고 그림

**이미지 생성 모델(확산)**: 그림을 그리는 게 아니라 노이즈를 조금씩 걷어 내는 법을 배운 모델이다. 이 원리를 알면 ComfyUI 노드 구성이 읽힌다.
[자세히 → 이미지 생성 모델(확산)](#/post/ml-diffusion)
