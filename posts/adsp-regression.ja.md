回帰分析は、入力変数（独立変数）によって結果変数（従属変数）を説明する式を立て、その式の有用性を確認する単元である。ADsP 3 の科目では仮説検定の後に続き、用語が多く見えても問われる項目の数は決まっている。試験日程と受験料は公式サイトで確認すること。

## 単純回帰と多重回帰

単純回帰は独立変数が 1 つだけである。直線 y = b0 + b1x を引き、点が線から外れた距離（残差）の二乗和が最小になるように b0, b1 を定める。これが最小二乗法である。多重回帰は独立変数が 2 つ以上であり、y = b0 + b1x1 + b2x2 + ... の形となる。

| | 単純回帰 | 多重回帰 |
|---|---|---|
| 独立変数 | 1 つ | 2 つ以上 |
| 式 | y = b0 + b1x | y = b0 + b1x1 + b2x2 ... |
| 追加で注意すること | なし | 変数間の絡み合い（多重共線性）、変数の選択 |

回帰係数 b1 は「他の変数がそのままの場合、x が 1 増えると y は平均 b1 だけ変化する」と読み取る。問題で係数の解釈を求められた場合は、この文型の枠に数字を入れるだけでよい。係数が 0 かどうかは t 検定で、モデル全体が有意かどうかは F 検定で見る。p 値の読み方は [詳細 → 仮説検定](#/post/adsp-hypothesis) にまとめた。

## 回帰の基本的な仮定

誤差（残差）に関する仮定は 4 つある。暗記する際はそのままの名前を使えばよい。

| 仮定 | 意味 | 崩れると |
|---|---|---|
| 線形性 | 独立変数と従属変数が直線の関係にあること | 曲線の関係の場合は変換するか項を追加する |
| 独立性 | 誤差同士が互いに無関係であること | 時系列のように前後がつながったデータでよく崩れる |
| 等分散性 | 誤差の広がりがどこでも同じであること | 残差図が漏斗の形になる |
| 正規性 | 誤差が正規分布に従うこと | Q-Q プロットが線から外れる |

statsmodels のドキュメントでも OLS は誤差が互いに独立で分散が等しい場合として定義しており、分散が異なる場合は WLS、任意の共分散の場合は GLS で別に扱っている。試験では「残差図を見てどの仮定が崩れているか」を問う問題が多い。残差が無紋様に 0 の近くに均等に散らばっていれば、仮定は概ね満たされている状態である。

## 決定係数 R²

R² はモデルが y の変動のうちどれくらいを説明しているかを 0 と 1 の間の数字で示す。式は以下の通りである。

- SST（総変動）= Σ(y − 平均)²
- SSE（残差変動）= Σ(y − 予測値)²
- SSR（回帰変動）= SST − SSE
- R² = SSR / SST = 1 − SSE / SST

単純回帰では R² は相関係数の二乗と等しい。ここで試験でよく問われる点は 2 つある。

- 変数を追加すると R² は減らない。無用な変数を入れても同様である。
- そのため、多重回帰では変数の個数に応じてペナルティを課す修正済み決定係数（adjusted R²）も併せて見る。修正済み R² は R² より大きくはならず、新しい変数が偶然以上の説明力を発揮したときだけ上がる。

<details>
<summary>手計算で確認してみる (x = 1~5, y = 2, 4, 5, 4, 5)</summary>

数字 5 つの例題を python で回して得られた値である。

- 最小二乗の結果: b1 = 0.6, b0 = 2.2、式は y = 2.2 + 0.6x
- SST = 6.0, SSE = 2.4, SSR = 3.6
- R² = 3.6 / 6.0 = 0.6（相関係数の二乗も 0.6 で一致）
- 修正済み R² = 1 − (1 − 0.6) × (5 − 1) / (5 − 1 − 1) ≈ 0.467
- F = (SSR / 1) / (SSE / 3) = 4.5

```python
import numpy as np
x = np.array([1, 2, 3, 4, 5.]); y = np.array([2, 4, 5, 4, 5.])
n, p = len(x), 1
b1 = ((x - x.mean()) * (y - y.mean())).sum() / ((x - x.mean())**2).sum()
b0 = y.mean() - b1 * x.mean()
sse = ((y - (b0 + b1 * x))**2).sum()
sst = ((y - y.mean())**2).sum()
r2 = 1 - sse / sst
adj = 1 - (1 - r2) * (n - 1) / (n - p - 1)
F = ((sst - sse) / p) / (sse / (n - p - 1))
```

試験ではこの程度の計算は SST や SSE のうち 2 つが与えられて、R² や F を求める式として出題される。
</details>

## 多重共線性

独立変数同士が強く相関している場合、どの変数が y に影響を与えたかを区別できず、係数の推定が不安定になる。この現象を多重共線性という。よくある兆候は R² は高いのに個々の係数の t 検定が有意でない場合である。

診断には分散膨張係数 (VIF) を用いる。変数を残りの独立変数들로回帰させて得た R² を Ri² とすると VIF = 1 / (1 − Ri²) である。基準は通常 10 以上なら深刻とされ、5 を基準にする場合もある。試験では 10 が正解として出題される傾向にある。ソフトウェアによっては VIF の逆数である共容性 (tolerance) で表示することもある。

解決策は相関の高い変数のうち 1 つを除外するか、変数を結合するか、主成分分析で変数を減らす方法である。主成分分析については [詳細 → 多変量解析と時系列](#/post/adsp-multivariate-ts) に続く。

<details>
<summary>VIF の直接計算を試してみる</summary>

x1 = 1~6, x2 = 2.1, 3.9, 6.2, 8.1, 9.8, 12.1 のようにほぼ 2 倍の関係にある 2 つの変数を生成し、x1 を x2 で回帰させたところ、R² は約 0.998、VIF は約 624 という結果が出た。これは 2 つの変数が実質的に同じ情報を表していることを意味しており、基準となる値 10 を大きく上回る。
</details>

## 変数選択

候補変数が多数ある場合、どの変数を採用するかを決定する方法は 3 つある。

| 方法 | 開始 | 進行 |
|---|---|---|
| 前向き選択 (Forward Selection) | 変数なし | 最も有意に改善させる変数を一つずつ追加し、さらに改善が見られない場合は停止 |
| 後向き除去 (Backward Elimination) | 全変数あり | 除外しても損失が最小となる変数を一つずつ除外し、除外すると損失が大きくなる場合は停止 |
| ステップ選択 (Stepwise Selection) | いずれか | 追加と除去何れもを各段階で交互に検討 |

Wikipedia の stepwise regression 項目でも同様の順序で説明されており、判断基準として F 検定や t 検定の連続が挙げられている。前向き選択は一度入れた変数を外せない点、後向き除去は一度外した変元を復活できない点が比較問題の定番である。ステップ選択はこの両方を補完する。

## よくあるパターンと解き方

- 係数の解釈: 「x1 が 1 増加すると y は b1 変化する（他の変数は固定）」のように記述する。単位も併せて確認する。
- R² vs 修正済み R²: 変数が増えたのに R² だけが上がり、修正済み R² が下がった場合は不要な変数が混入している。
- p 値の判断: 係数の p 値が有意水準より小さい場合、その変数は有意である。F 検定の p 値が小さい場合はモデル全体が有意である。
- 仮定の確認: 残差プロットの形状を仮定の名前と結びつける。漏斗形は等分散性、曲線パターンは線形性の問題を示す。
- 多重共線性: R² は高いのに t 検定でほとんどが不有意な場合は疑い、VIF の基準値 10 を踏まえて判断する。
- 変数選択: 前向き・後向き・ステップ選択の開始点と進行方向を表で暗記する。

過去問は原文をそのままここに転記していない。問題を解く際は、上記 6 つのパターンのうちどのタイプに該当するかをまず分類することから始める。

## よくある誤解

- R² が高いほど良いモデルである: 変数を増やすと R² は必ず上がる。修正済み R² と残差も併せて見る必要がある。
- 回帰係数が大きいほど影響が大きい: 変数の単位が異なる場合は、係数の大きさをそのまま比較できない。
- 相関があれば因果関係がある: 回帰は関係を式で表現するだけで、原因を証明するものではない。
