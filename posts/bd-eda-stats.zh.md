探索性数据分析（EDA）是在构建模型之前，通过数字和图表来浏览数据形态的阶段；在考试中，其基础会涉及关于基础统计概念的**计算与解析**问题。考试日程和报名费用可在官方网站上确认。

## EDA 的工作内容

收到数据后，不要立即运行模型，而应先进行观察：变量有多少个、类型是什么、数值分布在哪里、是否存在异常值、变量之间是否共同变动。基于这些观察，决定如何处理缺失值以及是否需要转换。关于预处理，已在 [详细 → 数据预处理](#/post/bd-preprocessing) 中单独整理。

EDA 使用的工具主要有两大类。

| 工具 | 观察内容 | 代表指标 |
|---|---|---|
| 描述性统计 | 单个变量的中心、离散程度、形状 | 均值、中位数、标准差、四分位数 |
| 相关性分析 | 两个变量共同变动的程度 | 皮尔逊相关系数、斯皮尔曼相关系数 |

图表方面，直方图、箱线图、散点图是基础。何时使用何种图表，请参阅 [详细 → 可视化与结果解读](#/post/bd-visualization)。

## 描述性统计

中心趋势指标包括均值、中位数和众数。如果存在异常值，均值会被拉偏，而中位数则相对稳定。这种差异在考试中经常出现。当数据为 `[2, 4, 4, 4, 5, 5, 7, 9, 30]` 时，直接计算结果如下：

```python
import pandas as pd
s = pd.Series([2, 4, 4, 4, 5, 5, 7, 9, 30])
print(s.mean(), s.median(), s.mode().tolist())
# 7.777777777777778 5.0 [4]
```

由于存在一个 30，均值变为 7.78，而中位数为 5。若均值大于中位数，则为右偏分布（正偏度）；pandas 的 `skew()` 函数在该数据上返回约 2.70。

离散程度指标包括方差、标准差、极差和四分位距（IQR）。这里有一个容易混淆的点：样本方差的分母是 n-1 而非 n。pandas 的 `var()` 和 `std()` 默认使用 n-1，而 numpy 默认使用 n。

```python
print(s.var(), s.var(ddof=0))
# 73.44444444444444 65.28395061728395
```

同一数据集中分别得到 73.44 和 65.28。遇到考题时，需先确认题目询问的是样本方差还是总体方差。

箱线图判定异常值的标准是：低于 Q1 - 1.5×IQR 或高于 Q3 + 1.5×IQR。上述数据中 Q1=4, Q3=7, IQR=3，因此“围栏”为 -0.5 和 11.5，仅 30 落在围栏之外。

```python
q1, q3 = s.quantile([.25, .75]); iqr = q3 - q1
print(s[(s < q1 - 1.5*iqr) | (s > q3 + 1.5*iqr)].tolist())
# [30]
```

<details>
<summary>偏度、峰度、变异系数简述</summary>

- **偏度**：0 表示对称；正数表示右尾较长；负数表示左尾较长。
- **峰度**：衡量分布的尖锐程度。通常以正态分布为基准进行比较，不同工具可能减去 3 后再给出结果，做题时需确认其参考基准。
- **变异系数**：标准差 ÷ 均值。用于比较单位不同的两个变量的离散程度。
- 与算术平均数不同，几何平均数适用于像增长率那样通过乘法变化的数值。
</details>

## 相关性分析

相关系数的取值范围在 -1 到 1 之间，符号表示方向，绝对值表示强度。皮尔逊相关系数关注线性关系，且对异常值敏感；斯皮尔曼相关系数将数据转换为秩次进行计算，关注单调关系，适用于有序数据或存在异常值的情况。

```python
import numpy as np
from scipy import stats
x = np.array([1,2,3,4,5,6,7,8]); y = np.array([2,1,4,3,7,8,6,9])
print(stats.pearsonr(x, y))   # 상관계수 약 0.896, p 약 0.0026
print(stats.spearmanr(x, y))  # 상관계수 약 0.881, p 약 0.0039
```

在 pandas 中，`df.corr(method="pearson")` 是默认选项，也可选择 `"spearman"` 或 `"kendall"`。若存在缺失值，则仅选取两列均有值的行进行逐对计算。

高相关性并不意味着因果关系。第三个变量同时影响两者的情况（虚假相关）是考试中的常见错误选项。即使相关系数接近 0，也可能存在曲线关系。关于如何处理高相关变量，将在 [详细 → 特征选择与降维](#/post/bd-feature-select) 中继续介绍。

## 概率分布

考试中需要记忆的分布种类是固定的。

| 分布 | 用途 | 记忆要点 |
|---|---|---|
| 正态分布 | 连续型、钟形曲线 | 均值±1σ约68%，±1.96σ约95% |
| 二项分布 | n次试验中的成功次数 | 试验独立，成功概率恒定 |
| 泊松分布 | 单位时间或空间内的事件发生次数 | 均值=方差 |
| t分布 | 未知总体方差时的均值估计与检验 | 自由度增大时趋近于正态分布 |
| 卡方分布 | 方差检验、分类变量独立性/拟合优度检验 | 取值≥0，右偏 |
| F分布 | 方差比较、方差分析 | 涉及两个自由度 |

记忆标准正态分布的数值会更方便。使用 scipy 查询结果如下：

```python
print(stats.norm.cdf(1.96), stats.norm.ppf(.975))
# 0.9750021048517795 1.959963984540054
print(stats.t.ppf(.975, 9), stats.chi2.ppf(.95, 3))
# 2.262157162798205 7.814727903251179
```

自由度为 9 的 t 分布中，双侧 5% 临界值为 2.262，大于正态分布的 1.96。这是因为样本量越小，尾部越厚。

中心极限定理也常考。即使总体不服从正态分布，只要样本量足够大，样本均值的分布也会接近正态分布。样本均值的标准误为 σ/√n，因此当样本量增加 4 倍时，标准误减半。

## 估计

点估计指用单个数值来估计参数，区间估计则给出一个范围。对于总体方差未知的正态总体，95% 置信区间的公式为：样本均值 ± t(0.975, n-1) × s/√n。

```python
a = np.array([12.1,11.8,12.5,12.9,11.5,12.2,12.7,12.0,11.9,12.4])
m, se = a.mean(), stats.sem(a)
print(m, se, stats.t.interval(.95, len(a)-1, loc=m, scale=se))
# 12.2 0.1358... (11.8928, 12.5072)
```

在 95% 置信水平的解释中，经常会出现误解。并不是说“总体均值落在这个区间内的概率是 95%"，而是指：如果以相同的方式重复抽取样本并构建区间，那么其中约 95% 的区间会包含总体均值。提高置信水平会使区间变宽，增加样本量则会使区间变窄。

## 假设检验

步骤始终一致：建立零假设（H0）和备择假设（H1），设定显著性水平（通常为 0.05），计算检验统计量和 p-值；若 p-值小于显著性水平，则拒绝 H0。

- 第一类错误：H0 为真却被拒绝。发生概率为显著性水平 α。
- 第二类错误：H0 为假却未能拒绝。发生概率为 β，检验功效为 1-β。
- p-值是指在假设 H0 为真的前提下，观察到当前结果或更极端结果的概率，而非 H0 为真的概率。

检验方法的选择取决于数据类型。

| 情况 | 检验方法 |
|---|---|
| 将单个总体均值与基准值比较 | 单样本 t 检验 |
| 比较两个独立总体均值 | 独立样本 t 检验 |
| 同一对象的前后比较 | 配对样本 t 检验 |
| 三个及以上总体均值比较 | 方差分析（ANOVA, F 检验） |
| 两个分类变量的独立性 | 卡方检验 |
| 正态性检查 | Shapiro-Wilk 等 |

```python
print(stats.ttest_1samp(a, 12.0))
# 통계량 1.4726, p 0.1749, df 9  -> 평균이 12라는 H0를 기각 못 함

b = np.array([12.8,13.1,12.6,13.4,12.9,13.0,12.7,13.3,12.5,13.2])
print(stats.ttest_ind(a, b, equal_var=False))
# 통계량 -4.5136, p 0.000345, df 약 16.17  -> 두 평균이 같다는 H0 기각
```

在 scipy 文档中，`ttest_ind` 用于检验两个独立样本均值是否相等；默认参数 `equal_var=True` 表示假设等方差。若设为 `False`，则进行不假设等方差的 Welch 检验。上述结果中自由度为小数（16.17），这正是 Welch 检验的特征。

卡方独立性检验通过比较观测频数与期望频数来进行。

```python
table = np.array([[30,20],[20,30]])
chi2, p, dof = stats.chi2_contingency(table, correction=False)[:3]
print(chi2, p, dof)
# 4.0 0.0455... 1
```

期望频数计算公式为 (行合计 × 列合计) ÷ 总样本量；本表中每个单元格的期望值均为 25。自由度 = (行数 -1) × (列数 -1)，此处为 1。检验统计量为 4.0，p 值约为 0.0455，因此在 5% 显著性水平下拒绝“独立”的 H0。设置 `correction=False` 的原因是：对于 2×2 列联表，scipy 默认会应用连续性校正；此处是为了与手动计算的答案保持一致而关闭该选项。

<details>
<summary>当正态性不满足时</summary>

t 检验和 ANOVA 均假设数据服从正态分布。若样本量较小且对正态性存疑，则应采用基于秩次的非参数检验（如 Wilcoxon 秩和检验、Kruskal-Wallis 检验等）。非参数检验相关内容将在 [详细 → 高级分析技巧](#/post/bd-advanced-analysis) 中继续探讨。

```python
print(stats.shapiro(a))
# 통계량 0.9885, p 0.9947 -> 정규성을 기각할 근거 없음
```

Shapiro-Wilk 检验的 H0 为“数据服从正态分布”，因此 p 值较大意味着无法拒绝正态性假设，但这并不等同于证明了数据服从正态分布。
</details>

## 问题类型与解题方法

- 比较均值、中位数、众数的位置：从分布尾部方向入手绘制图形，大小关系一目了然。
- 样本方差计算：确认是否除以 n-1。
- 箱线图解读：利用 Q1、Q3 和 IQR 构建边界，统计异常值数量。
- 相关系数解读：关注符号与大小，排除因果关系的干扰选项。
- 检验方法选择：依次判断数据是连续型还是分类型、涉及几个总体、是否为独立或配对设计。
- p-值与显著性水平比较：若拒绝 H0，则结论为“存在差异”；若未能拒绝，则说明“缺乏支持存在差异的证据”。
