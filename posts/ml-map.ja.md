[AI 概念图](#/post/ai-map) が用語を網羅した記事であれば、この記事はその下側にある、モデルが実際にどのように学習し、どのように動作するかを集めました。順序は「学習の基礎 → 構造 → モデルが作られる段階 → 自分の方で触る方法 → 動かす方法 → イメージモデル」です。まず一行の説明だけ読んで、気になることはリンクから進めば OK です。

## 一目でわかる流れ

```
학습 기초(손실·경사하강법)
  → 신경망과 역전파
    → 트랜스포머(어텐션)
      → 사전학습 → 지시 튜닝(SFT) → 선호 학습(RLHF·DPO)
        → 파인튜닝(LoRA/QLoRA)
        → 로컬에서 돌리기(양자화·VRAM)
        → 추론 최적화(KV 캐시·배치)
(별도 계열) 이미지 생성 = 확산 모델
```

## 1. 学習とは何か

**機械学習・ディープラーニングの基礎**: 学習は、誤りの程度（損失）を数値化して重みを少しずつ修正していくことです。訓練データでうまくいくだけで終わるわけではなく、過学習と検証・テストの分割も同時に登場します。
[詳しく → 機械学習・ディープラーニングの基礎](#/post/ml-basics)

**ニューラルネットワークとバックプロパゲーション**: 掛け算と足し算と曲がる計算を層ごとに積み重ねた関数がニューラルネットワークであり、バックプロパゲーションはその重みをどちらに修正すべきか出力側から逆算する方法です。
[詳しく → ニューラルネットワークとバックプロパゲーション](#/post/ml-neural-net)

## 2. LLM の骨格

**トランスフォーマーとアテンション**: 単語ごとに文内の他の単語をどれだけ参照するか点数で計算する構造です。順番に読まなくても文脈を捉えられ、今の LLM はほぼこの骨格を使っています。
[詳しく → トランスフォーマーとアテンション](#/post/ml-transformer)

## 3. チャットボットが作られる過程

**事前学習から RLHF まで**: 文章を食べて次の単語を当てる事前学習、質問への答え方を示す指令チューニング（SFT）、人間が選んだ方向へ押す好みに基づく学習（RLHF・DPO）。この 3 つの段階を経て会話ができるモデルが生まれます。
[詳しく → 事前学習から RLHF まで](#/post/ml-pretraining)

## 4. 自分の方で触る

**ファインチューニング：全体 vs LoRA/QLoRA**: 事前学習が終わったモデルを自分のデータで一度教え直すことです。LoRA を使うとモデル全体を触らずに済み、そのため必要な GPU が大幅に減ります。
[詳しく → ファインチューニング：全体 vs LoRA/QLoRA](#/post/ml-finetuning)

## 5. 動かす方

**ローカルモデルの起動**: 自分の PC のグラフィックカードにモデルが入るかどうかは、パラメータ数、量子化ビット数、コンテキスト長で概算計算になります。量子化と VRAM 計算が中心です。
[詳しく → ローカルモデルの起動](#/post/ml-local-models)

**推論最適化**: 作る話ではなく動かす話です。KV キャッシュ、バッチ、ストリーミング、投機的デコーディングは結局 GPU メモリをどう割り当て使うかにつながります。
[詳しく → 推論最適化](#/post/ml-inference)
