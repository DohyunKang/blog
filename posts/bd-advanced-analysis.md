고급 분석 기법은 기초 통계에서 한 칸 더 나간 도구 네 가지를 묶은 단원이다. 다변량 분석, 시계열 분석, 비모수 검정, 베이지안 추론이다. 계산을 직접 시키는 문제보다 "이 상황에는 어떤 기법인가"를 고르는 문제가 많아서, 각 기법을 쓰는 상황과 짝으로 외우는 쪽이 빠르다. 시험 일정과 응시료는 공식 사이트에서 확인한다. 기초 통계는 [자세히 → 탐색적 분석과 기초 통계](#/post/bd-eda-stats)에 있다.

| 기법 | 이럴 때 | 키워드 |
|---|---|---|
| 다변량 분석 | 변수가 여러 개이고 서로 얽혀 있다 | 주성분, 요인, 다차원 척도법, 군집 |
| 시계열 분석 | 관측값이 시간 순서로 쌓였다 | 정상성, 자기상관, AR·MA·ARIMA |
| 비모수 검정 | 정규분포를 믿기 어렵거나 표본이 작다 | 순위, 중위수, 윌콕슨, 만-휘트니 |
| 베이지안 | 사전 믿음을 자료로 갱신하고 싶다 | 사전·사후확률, 우도 |

## 다변량 분석

변수가 둘 이상인 자료를 한꺼번에 다루는 방법을 통틀어 다변량 분석이라 부른다. 시험에서는 이름과 목적을 연결하는 문제가 나온다.

| 이름 | 하는 일 |
|---|---|
| 주성분 분석(PCA) | 분산이 큰 방향으로 새 축을 만들어 변수 개수를 줄인다 |
| 요인 분석 | 변수들 뒤에 숨은 공통 요인을 찾는다 |
| 다차원 척도법(MDS) | 개체 사이 거리를 가능한 한 보존해서 2~3차원 평면에 배치한다 |
| 군집 분석 | 비슷한 개체끼리 묶는다 |
| 판별 분석 | 이미 알려진 집단으로 새 개체를 분류한다 |

PCA는 scikit-learn 문서 기준으로 분산을 최대한 설명하는 서로 직교하는 성분을 차례로 뽑는 변환이고, 데이터를 평균으로 빼서 중심에 맞추지만 크기(스케일)는 맞춰 주지 않는다. 이 마지막 문장이 실무에서 중요하다. 단위가 다른 변수를 그대로 넣으면 값이 큰 변수가 성분을 독차지한다. iris 자료로 확인했다.

```python
from sklearn.datasets import load_iris
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

X = load_iris().data
print(PCA(2).fit(X).explained_variance_ratio_.round(3))
print(PCA(2).fit(StandardScaler().fit_transform(X)).explained_variance_ratio_.round(3))
```

```
[0.925 0.053]
[0.73  0.229]
```

표준화 전에는 첫 성분이 92.5%를 설명하고, 표준화 후에는 73.0%로 내려가면서 둘째 성분이 22.9%로 올라간다. 변수 척도가 결과를 바꾼다는 걸 이 두 줄이 보여 준다. PCA와 변수 선택 이야기는 [자세히 → 변수 선택과 차원 축소](#/post/bd-feature-select)에서 이어진다. 군집은 [자세히 → 비지도학습 모형](#/post/bd-unsupervised)에 따로 있다.

<details>
<summary>PCA와 요인 분석, 헷갈릴 때</summary>

둘 다 변수를 줄이는 데 쓰이지만 출발점이 다르다. PCA는 원래 변수들의 분산을 최대한 담는 새 축을 만드는 데 목적이 있고, 요인 분석은 변수들이 공통으로 따르는 잠재 요인을 가정하고 그걸 추정하는 데 목적이 있다. 문제 지문에 "잠재 요인", "공통 요인"이 나오면 요인 분석, "분산을 최대한 보존", "차원 축소"가 나오면 PCA로 읽으면 된다.

</details>

## 시계열 분석

시계열은 관측값이 시간 순서로 쌓인 자료다. NIST 핸드북은 시간 순서로 모은 자료에는 "내부 구조"가 있을 수 있다고 설명하고, 그 예로 자기상관을 든다. 앞뒤 값이 서로 영향을 주니 독립 표본을 가정하는 일반 검정을 그대로 쓰면 안 된다.

시험에 자주 나오는 개념은 이렇다.

| 개념 | 뜻 |
|---|---|
| 정상성 | 평균·분산이 시간에 따라 변하지 않고 자기공분산이 시차에만 달린 성질 |
| 차분 | 현재 값에서 직전 값을 빼서 추세를 걷어내는 변환 |
| 계절 차분 | 계절 주기만큼 떨어진 값과의 차이 |
| AR(p) | 자기 자신의 과거 값 p개로 현재를 설명 |
| MA(q) | 과거 충격(오차) q개로 현재를 설명 |
| ARIMA(p,d,q) | 비정상 시계열을 d번 차분한 뒤 AR·MA를 합친 모형 |

NIST 핸드북은 Box-Jenkins 모형이 정상 시계열을 가정하고, 정상이 아니면 한 번 이상 차분해서 ARIMA("I"는 integrated)로 만든다고 적는다. 모형을 쓰는 순서는 식별, 추정, 검증이다.

차분이 왜 먹히는지 직접 돌려 봤다. 난수를 누적해서 만든 추세형 계열(랜덤워크)은 한 칸 뒤의 자기상관이 거의 1이다. 차분하면 거의 0으로 떨어진다.

```python
import numpy as np, pandas as pd
rng = np.random.default_rng(0)
y = pd.Series(np.cumsum(rng.normal(size=200)))
print(round(y.autocorr(1), 3), round(y.diff().dropna().autocorr(1), 3))
```

```
0.977 0.039
```

AR과 MA는 자기상관이 줄어드는 모양이 다르다. AR(1) 계수 0.7과 MA(1) 계수 0.8로 500개씩 만들어 시차별 자기상관을 봤다.

```python
e = rng.normal(size=500)
ar = np.zeros(500)
for t in range(1, 500):
    ar[t] = 0.7 * ar[t-1] + e[t]
s = pd.Series(ar)
print([round(s.autocorr(k), 2) for k in (1, 2, 3, 4)])
m = pd.Series(e[1:] + 0.8 * e[:-1])
print([round(m.autocorr(k), 2) for k in (1, 2, 3)])
```

```
[0.65, 0.41, 0.25, 0.15]
[0.46, -0.07, -0.05]
```

AR은 서서히 줄어드는 꼴이고, MA(1)은 시차 1 이후로 뚝 끊긴다. 시험의 "ACF가 지수적으로 감소하면 AR, 시차 q 뒤에 절단되면 MA"가 이 모양이다. 부분자기상관(PACF)은 반대로 AR이 절단, MA가 감소로 외운다.

<details>
<summary>시계열 분해와 이동평균</summary>

시계열을 추세, 계절, 순환, 불규칙 성분으로 나눠 보는 분해 방식도 단골이다. 이동평균법은 최근 몇 개 값의 평균으로 불규칙 변동을 눌러 추세를 보는 방법이고, 지수평활법은 최근 값에 더 큰 가중치를 준다. 이름과 한 줄 설명만 짝지어 두면 된다.

</details>

## 비모수 검정

모수 검정(t검정 등)은 자료가 특정 분포(주로 정규분포)를 따른다고 보고 평균 같은 모수를 비교한다. 비모수 검정은 분포 모양을 가정하지 않고 순위나 부호를 쓴다. 표본이 작거나 정규성이 의심되거나 순서 척도 자료일 때 선택한다.

| 상황 | 모수 검정 | 비모수 대응 |
|---|---|---|
| 독립 두 집단 | 독립표본 t검정 | 만-휘트니 U (윌콕슨 순위합) |
| 대응 두 집단 | 대응표본 t검정 | 윌콕슨 부호순위 |
| 세 집단 이상 | 일원 분산분석 | 크러스칼-왈리스 |
| 상관 | 피어슨 | 스피어만 순위 상관 |

SciPy 문서는 만-휘트니 U를 독립표본 t검정의 비모수 버전으로 설명한다. 귀무가설은 두 표본의 바탕 분포가 같다는 것이고, 표본이 서로 독립이어야 한다. 대응 표본이면 윌콕슨을 쓰라고 안내한다. 같은 자료에 t검정과 만-휘트니를 돌려 봤다.

```python
import numpy as np
from scipy import stats
a = np.array([12,15,14,10,18,20,11,13])
b = np.array([22,19,25,17,30,21,24,16])
print(stats.mannwhitneyu(a, b, alternative='two-sided').pvalue)
print(stats.ttest_ind(a, b).pvalue)
before = np.array([70,65,80,72,68,75,90,66])
after  = np.array([68,60,79,65,66,70,85,67])
print(stats.wilcoxon(before, after).pvalue)
print(stats.kruskal([5,7,6,9,8],[12,14,11,15,13],[20,18,22,19,21]).pvalue)
```

```
0.00295   (만-휘트니)
0.00211   (t검정)
0.0234    (윌콕슨 부호순위)
0.00193   (크러스칼-왈리스)
```

정규성이 괜찮은 자료에서는 두 검정이 비슷한 결론을 낸다. 문제를 풀 때는 검정 이름 고르기가 먼저다. "대응", "세 집단", "순위"라는 단어가 보이면 위 표에서 칸을 찾으면 된다. p값 읽는 법과 귀무가설은 [자세히 → 탐색적 분석과 기초 통계](#/post/bd-eda-stats)와 같다.

<details>
<summary>그 밖의 비모수 검정</summary>

부호 검정은 짝지은 값의 차이가 양인지 음인지만 센다. 런 검정은 값이 +, -로 나뉘는 연속(run)의 개수로 데이터가 무작위로 배열됐는지 본다. 콜모고로프-스미르노프 검정은 표본이 특정 분포를 따르는지, 또는 두 표본이 같은 분포인지 확인한다. 이름과 목적만 연결해 둔다.

</details>

## 베이지안 추론

빈도주의는 모수를 고정된 값으로 보고 자료의 확률을 따진다. 베이지안은 모수에 대한 믿음을 확률분포로 두고, 자료를 보면서 갱신한다.

사후확률은 우도와 사전확률의 곱에 비례한다.

P(A|B) = P(B|A) × P(A) / P(B)

시험에서는 이 식을 숫자로 푸는 문제가 나온다. 유병률 1%인 병에서 검사 민감도 95%, 건강한 사람이 양성으로 나오는 비율 5%일 때 양성 판정을 받은 사람이 실제 환자일 확률을 구해 봤다.

```python
p, sens, fp = 0.01, 0.95, 0.05
print(sens * p / (sens * p + fp * (1 - p)))
```

```
0.161
```

양성인데 환자일 확률이 16% 정도다. 검사가 95%로 정확해 보여도 사전확률(1%)이 작으면 사후확률이 낮다. "민감도"와 "사후확률"을 혼동하게 하는 문제가 이 구조다.

사전분포 Beta(1,1)에서 시작해 성공 7번, 실패 3번을 관찰하면 사후분포는 Beta(1+7, 1+3) = Beta(8,4)가 되고 평균은 8/12, 약 0.667이다. 사전분포와 사후분포가 같은 계열이 되는 짝을 켤레 사전분포라고 부르고, 이항 자료에는 베타 분포가 이런 짝이 된다.

<summary>나이브 베이즈와의 관계</summary>

분류 모형인 나이브 베이즈는 베이즈 정리에 "변수들이 클래스가 주어지면 서로 독립"이라는 단순화를 얹은 것이다. 지도학습 쪽 설명은 [자세히 → 분석 모형 설계](#/post/bd-model-design)에서 이어서 본다.
