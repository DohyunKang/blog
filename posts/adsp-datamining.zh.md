结构化数据挖掘主要分为分类、聚类和相关性分析三类，考试中常出现“在何种情境下使用何种技术”以及“能否计算指标”这两类问题。本文据此进行了整理。

## 宏观概览

首先根据是否存在正确答案（标签）进行划分。

| 类别 | 是否有标签 | 典型问题 | 代表算法 |
|---|---|---|---|
| 分类 | 有 | 该数据属于哪个类别？ | 决策树、集成学习 |
| 聚类 | 无 | 相似的数据如何分组？ | K-means、层次聚类、DBSCAN |
| 关联分析 | 无 | 共同出现的项是什么？ | 支持度、置信度、提升度 |

有标签的称为监督学习，无标签的称为无监督学习。基本概念详见 [详解 → 机器学习基础](#/post/ml-basics)。在整个分析流程中该步骤的位置，可参考 [详解 → 分析方法论](#/post/adsp-methodology)。

## 分类：决策树

决策树是一种通过特征值构建 if-then 规则来划分数据的模型。scikit-learn 文档指出其规则直观可见、易于解释是其主要优势。

核心在于“在哪里进行划分”，依据是不纯度（impurity）。选择使划分后子节点的加权平均不纯度最小的方案。

- Gini 指数：1 − Σp²。当两类各占一半时达到最大值 0.5，仅有一类时为 0。CART 算法在分类树中使用此指标。
- 熵：−Σp·log p。两类均衡时最大，仅一类时为 0。ID3 算法基于熵计算信息增益。

直接进行计算验证。假设一个包含 10 个样本的节点（A 类 5 个，B 类 5 个）被划分为两个子节点：左侧 6 个（A 类 5 个，B 类 1 个），右侧 4 个（均为 B 类）。

- Gini：父节点 0.5，加权子节点 (0.6 × 0.278) + (0.4 × 0) = 0.167 → 减少量 0.333
- 熵 (log2)：父节点 1.0，加权子节点约 0.39 → 减少量约 0.61

选择信息增益（即不纯度减少量）较大的划分方案。考试中常考察“Gini 指数越小表示纯度越高”这一方向。

若将树无限生长，模型会记忆训练数据而在新数据上表现变差（过拟合）。因此需要限制深度（max_depth）或进行剪枝。文档中描述的基于成本的复杂度剪枝方法，通过计算错误数 + 叶子节点数 × α 来评估树，α 值越大，保留的树越小。

<summary>详细解答：Gini 与熵的计算步骤</summary>

设节点内各类别比例为 p，则 Gini 为 1 − Σp²。

- (5, 1) 节点：p = 5/6, 1/6 → 1 − (0.694 + 0.028) = 0.278
- (0, 4) 节点：p = 0, 1 → 0
- 加权平均：(6/10)×0.278 + (4/10)×0 = 0.167
- 父节点 (5, 5)：1 − (0.25 + 0.25) = 0.5

熵方面，父节点为 1.0，(5, 1) 节点约为 0.65。加权平均 0.6×0.65 = 0.39，减少量 0.61。上述数值已通过 Python 计算验证。

## 分类：集成学习

并非使用单个模型，而是结合多个模型进行预测。根据文档整理如下：

| 方法 | 学习方式 | 作用机制 |
|---|---|---|
| Bagging | 并行、相互独立 | 对每个重采样样本训练模型并合并，降低方差 |
| Random Forest | 并行 | Bagging + 每次划分时仅考虑部分变量作为候选 |
| Boosting | 串行 | 聚焦于前序模型错误的样本以构建下一模型（如 AdaBoost、梯度提升） |

文档指出：Bagging 通过降低方差，适合深度较大的复杂树；Boosting 则通过堆叠浅层树（弱学习器）来减少偏差。考试中若描述为“独立生成多个样本并投票”，则为 Bagging；若描述为“对错误样本赋予更高权重并顺序构建”，则为 Boosting。

## 分类模型评估

二分类问题的混淆矩阵中，行为实际类别，列为预测类别：

| | 预测阴性 | 预测阳性 |
|---|---|---|
| 实际阴性 | TN | FP |
| 实际阳性 | FN | TP |

所有指标均基于这四个单元格计算得出：

- 准确率 = (TP + TN) / 总数
- 精确率 = TP / (TP + FP) — 预测为阳性的样本中真正为阳性的比例
- 召回率 = TP / (TP + FN) — 实际阳性样本中被找出的比例，也称为灵敏度
- F1 = 精确率与召回率的调和平均数

举例说明：若 TN=50, FP=10, FN=5, TP=35，则准确率为 85/100 = 0.85，精确率为 35/45 ≈ 0.778，召回率为 35/40 = 0.875，F1 ≈ 0.824。解题时首先确认单元格位置，再判断分母是“预测阳性之和”还是“实际阳性之和”：精确率的分母为列合计，召回率的分母为行合计。

ROC 曲线是通过改变基准值（阈值）绘制 FPR（假正率）为横轴、TPR（召回率）为纵轴的图形，其下方的面积即为 AUC。当需要用一个数值来总结模型以便进行模型间比较时，会使用 AUC。

## 聚类分析

在没有正确答案的情况下，将相似的事物归为一类。文中提到的三种方法如下：

- K-means：必须预先指定聚类数量 K。算法通过减少聚类内部的平方和（inertia）来进行划分，且结果会受到初始中心点的影响。对于形状细长或弯曲的数据效果较差。
- 层次聚类：从每个数据点开始，逐步合并距离最近的聚类，结果以树状图（dendrogram）呈现。衡量聚类间距离的方法（连接法）包括单链接、全链接、平均链接和 Ward 法。其中单链接基于最近的一对点，全链接基于最远的一对点，平均链接则是所有点对的平均距离。
- DBSCAN：将密度较高的区域视为聚类。如果某个半径 eps 范围内包含至少 min_samples 个点，则该点为核心点；不属于任何聚类的点则被视为噪声（noise）。该方法对形状没有特定限制且无需指定 K 值，但需要仔细调整 eps 参数。eps 设置过小会导致大部分点被标记为噪声，过大则会将所有点合并为一个聚类。

评估聚类效果通常使用轮廓系数。设某点到其所属聚类内其他点的平均距离为 a，到最近的其他聚类的平均距离为 b，则轮廓系数为 (b − a) / max(a, b)。该值越大，表示聚类越清晰。

## 关联分析

购物篮分析是典型的关联分析应用。针对规则 A → B，通常使用以下三个指标：

- 支持度（Support）：A 和 B 同时出现的交易比例
- 置信度（Confidence）：在包含 A 的交易中，同时也包含 B 的比例（具有方向性，因此 A→B 与 B→A 不同）
- 提升度（Lift）：置信度 / B 的支持度。若为 1 则表示两者无关；大于 1 则表明它们倾向于共同出现

通过直接计算 5 笔交易进行了验证：

| 交易 | 项目 |
|---|---|
| 1 | 面包，牛奶 |
| 2 | 面包，尿布，啤酒，鸡蛋 |
| 3 | 牛奶，尿布，啤酒，可乐 |
| 4 | 面包，牛奶，尿布，啤酒 |
| 5 | 面包，牛奶，尿布，可乐 |

其中尿布出现 4 次，啤酒出现 3 次，两者同时出现 3 次。对于规则“尿布 → 啤酒”：支持度为 3/5 = 0.6，置信度为 3/4 = 0.75，提升度为 0.75 / 0.6 = 1.25。对于规则“面包 → 牛奶”：支持度为 0.6，置信度为 0.75，但由于牛奶出现次数为 4 次（即支持度为 0.8），其提升度为 0.75 / 0.8 = 0.94。尽管置信度相同，但提升度未能超过 1。

解题步骤通常遵循固定顺序：首先统计交易总数，然后确定分子（A 和 B 同时出现的次数）与分母（A 出现的次数或总交易数），最后进行除法运算。若对提升度感到困惑，可再次确认 B 原本的出现频率。

## 常见误区

- **准确率高即代表好模型**：在阳性样本稀少的数据集中，即使将所有样本预测为阴性，也能获得较高的准确率。因此应同时关注精确率和召回率。
- **聚类存在标准答案**：由于没有正确答案，需依赖轮廓系数等内部指标进行评估。
- **置信度高即表示规则强**：若结果项本身很常见，置信度自然会显得较高，因此必须结合提升度一起分析。
- **集成方法总是更优**：文档中指出 Bagging 适用于复杂模型，Boosting 则更适合简单模型，应根据具体情况选择合适的方法。
