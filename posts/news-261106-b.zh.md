## 它做什么
编码代理在会话结束后会遗忘之前的操作。claude-mem 会在会话期间收集使用工具的记录（observation），由 AI 进行压缩，并在下一个会话开始时重新注入相关内容。README 中列出的支持代理包括：Claude Code、OpenClaw、Codex、Gemini、Hermes、Copilot 和 OpenCode。

## 架构
- **六个钩子**：SessionStart、UserPromptSubmit、PreToolUse、PostToolUse、Stop、SessionEnd。每个钩子执行一个 claude-mem 命令。
- **Worker**：这是一个带有本地 HTTP API 和 Web 查看器的服务，使用 Bun 进行管理。
- **存储**：将会话、观察记录和摘要存入 SQLite，并使用 FTS5 进行全文检索。向量检索使用 Chroma，并结合关键词进行搜索。
- **搜索**：mem-search 技能及三个 MCP 工具（search、timeline、get_observations）。README 声称其先以列表形式过滤，再详细获取所需内容，因此可节省约 10 倍的 Token。这是作者的主张，我尚未验证。
- **模式**：默认模式为 code；还有记录较少的 code--chill 模式，以及支持其他语言的 code--[lang] 变体。

## 安装
根据 README，可使用 `npx claude-mem install`，或在 Claude Code 内部执行 `/plugin marketplace add thedotmack/claude-mem` 后运行 `/plugin install claude-mem`。需要 Node.js 20 或更高版本；如果没有 Bun 和 uv，会自动安装。npm 包仅安装库文件，不会注册钩子和 Worker。Windows 用户需在 PATH 中包含 node 和 npm，否则若找不到 claude-mem，钩子将失败。

## 安装前需阅读的内容
README 中关于隐私的部分值得在安装前阅读。

- 登录后会启动托管的"claude-mem observer"的 30 天免费试用。试用结束后，若不订阅，摘要将回退至 Anthropic 计费方案。也可以直接使用 OpenRouter 或 Gemini 密钥，或通过 `--provider` 参数或设置 `CLAUDE_MEM_ONLINE_OPTIN=false` 在不登录的情况下使用。
- 用 `<private>` 标签包裹的内容不会被存储。
- 开启 Cloud Sync 后，记忆会备份到 cmem.ai。截图默认关闭，且仅在开启 Cloud Sync 时才会上传。
- 会话开始时注入的上下文默认为当前使用的 Harness 内容；另有环境变量可用于扩展。

如果处理的是公司代码，建议先确认哪些内容会被传入摘要生成器。
