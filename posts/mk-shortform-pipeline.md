# 숏폼을 AI로 반자동 제작·배포하는 파이프라인 정리

한 줄 요약: 숏폼 자동화는 만드는 것보다 "사람이 어디서 한 번 눈으로 보느냐"를 정하는 일이 더 컸고, 업로드 API는 의외로 쉬운 편이었다.

공부 노트라 직접 돌려 본 건 아니고, 공식 문서와 자료를 찾아 정리했다. 회사 일과는 무관한 일반론이다.

## 전체 흐름

```
[주제 발굴] → [대본] → [음성(TTS)] → [영상 합성] → [자막] → [검수] → [업로드 예약] → [성과 분석]
 트렌드·댓글   LLM     TTS API      템플릿 렌더    음성 인식     사람     각 플랫폼 API    조회·시청유지
      ▲                                                                              │
      └──────────────────────── 잘 된 주제를 다시 주제 목록으로 ─────────────────────────┘
```

반자동이라고 한 건 검수 칸 때문이다. 이 칸을 빼면 완전 자동인데, 아래 한계 절에서 말하겠지만 빼기가 쉽지 않다.

## 단계별로

**주제 발굴.** 제일 자동화하기 애매한 단계였다. 방법은 크게 둘이다. 내 채널 댓글·조회 데이터에서 잘 된 걸 뽑거나, 남의 채널·검색어 트렌드를 긁어 오는 것. 도구는 YouTube Data API, 구글 트렌드, 각종 키워드 도구 정도가 나온다. 이 단계는 LLM에게 후보 20개를 뽑게 하고 사람이 3개 고르는 식이 현실적으로 보였다.

**대본.** LLM이 제일 잘하는 구간이다. 숏폼은 길이가 짧아서 15~45초, 한국어로 대략 150~400자다. 구조(첫 2초 훅 → 본론 → 마무리)를 프롬프트에 고정해 두면 편차가 줄어든다. 비용은 사실상 무시할 수준이다. 다만 사실 관계는 틀릴 수 있어서 수치·고유명사가 들어가는 주제는 사람이 한 번 봐야 한다.

**음성.** TTS API가 대표적이다. ElevenLabs는 문자 단위 과금이고, 공식 가격 페이지에는 Flash/Turbo가 1,000자당 $0.05, Multilingual v2/v3가 $0.10로 나온다. 서드파티 글에는 Flash를 $0.04로 적은 곳도 있어서 숫자가 엇갈린다. 쓰기 전에 가격 페이지를 직접 봐야 한다. 300자짜리 대본이면 한 편에 몇 십 원 수준이라는 계산이 나온다. 한국어 억양이 어색한 경우가 있다는 후기는 많다.

**영상 합성.** 두 갈래다.
- 템플릿형: Remotion(React로 영상을 코드로 짬)이나 FFmpeg로 배경 영상 + 음성 + 텍스트를 조립한다. 같은 틀에 데이터만 갈아 끼우니 결과가 일정하다. `npx remotion render`나 `renderMedia()`로 스크립트에서 돌릴 수 있다. Remotion은 개인·소규모는 무료지만 회사는 유료 라이선스가 필요하다고 한다. 버전에 따라 바뀌었다는 말이 있어서 LICENSE 파일을 직접 봐야 한다.
- 생성형: 이미지·영상 생성 모델로 장면을 만드는 방식. 비용이 클립 단위로 붙고 결과가 들쭉날쭉해서, 반자동 파이프라인에서는 보조로만 쓰는 쪽이 낫겠다고 생각했다. 구체 단가는 서비스마다 자주 바뀐다.

**자막.** 쇼츠·릴스는 소리 없이 보는 사람이 많아서 자막이 거의 필수다. TTS로 만든 음성이라면 대본 텍스트를 그대로 쓰고, 타이밍만 음성 인식으로 뽑으면 된다. openai-whisper 라이브러리는 `word_timestamps` 옵션으로 단어별 시작·끝 시간을 준다. 호스티드 API는 이 출력이 로컬 라이브러리만큼 안 된다는 포럼 글이 있었고, WhisperX 같은 보완 프로젝트가 있다. 로컬로 돌리면 GPU만 있으면 비용이 0이다.

**업로드 예약.** 이 단계가 생각보다 정리돼 있었다.
- 유튜브: Data API의 `videos.insert`로 올린다. 기본 할당량은 하루 10,000 유닛이고, 업로드 한 건당 비용은 예전 자료에 1,600유닛이라고 나온다. 그런데 2025년 12월에 약 100으로 줄었다는 서드파티 글이 있고, 공식 문서를 가져와 본 요약에서는 `videos.insert`를 별도 하루 100회 버킷으로 적어 놨다. 자료마다 엇갈려서 정확한 숫자는 공식 문서로 다시 봐야 한다. 어느 쪽이든 하루 몇 편 올리는 개인 규모에서는 문제될 일이 없어 보였다.
- 인스타 릴스: Instagram Graph API의 Content Publishing. 컨테이너를 만들고(`media_type=REELS`, `video_url`) `media_publish`로 게시한다. 공식 문서(2026-06-30 갱신)에 API 게시는 24시간에 100건까지라고 돼 있다. 예전 문서는 50건이라 적혀 있었다. 영상은 공개 URL에 올려 두어야 한다는 점이 번거롭다. 비즈니스·크리에이터 계정이 필요하다.
- 예약은 각 플랫폼 기능을 쓰거나, 내 쪽 스케줄러(cron, 큐)가 정해진 시각에 API를 부르게 하면 된다.

**성과 분석.** 유튜브 Analytics API, 인스타 Insights로 조회수·평균 시청 시간·유지율을 가져온다. 숏폼에서는 조회수보다 "끝까지 본 비율"이 다음 주제를 고를 때 쓸 만하다는 말이 많은데, 이건 경험담 수준이라 근거 링크는 따로 못 달았다. 이 값을 주제 목록으로 되돌리는 게 위 다이어그램의 화살표다.

## 비용과 한계

대략 한 편 기준으로 계산해 보면 이렇다. 가정은 대본 300자, LLM 1회 호출.

| 항목 | 방식 | 한 편 비용 추정 |
|---|---|---|
| 대본 | LLM 호출 | 수 원 이하 |
| 음성 | 클라우드 TTS | 수십 원 (위 단가 기준) |
| 영상 | Remotion·FFmpeg 로컬 | 0원 (PC 전기) |
| 자막 | Whisper 로컬 | 0원 |
| 업로드 | 공식 API | 0원 |

한 편에 100원 안쪽이라 월 100편이어도 만 원 안팎이다. 돈보다 시간과 품질이 문제다.

한계로 느낀 것들:
- 유튜브는 대량 생산·반복 콘텐츠를 "inauthentic content"로 보고 수익화에서 제외할 수 있다. 2025년 7월 15일에 이름이 바뀌었고, 새 규칙이 아니라 문구를 명확히 한 거라는 보도가 있다. 다만 이건 대부분 서드파티 기사에서 나온 얘기다.
- 실제처럼 보이는 AI 생성·변형 콘텐츠는 YouTube Studio에서 "변형 또는 합성 콘텐츠" 공개 설정을 켜야 한다. 켠다고 노출이 줄지는 않는다고 공식 도움말이 설명한다는 요약을 봤다.
- 같은 템플릿으로 계속 찍으면 영상이 다 비슷해진다. 이게 위 정책과 맞닿는 지점이라 검수 칸을 빼기 어렵다고 본다.
- API 숫자(쿼터·게시 한도)는 문서마다 달라서 구현 전에 현재 문서를 직접 확인해야 한다.

## 직접 만든다면

욕심을 줄이고 이렇게 시작할 것 같다.

1. 주제 목록은 스프레드시트나 JSON 파일 하나. LLM이 후보를 채우고 내가 승인 표시를 한다.
2. 승인된 주제만 대본 생성 → TTS → Whisper로 단어 타이밍 → Remotion 템플릿으로 렌더, 여기까지 스크립트 하나로 묶는다.
3. 결과 mp4와 대본을 폴더에 쌓고, 내가 훑어보고 통과한 것만 `approved/`로 옮긴다. 이게 유일한 수동 칸이다.
4. 스케줄러가 `approved/`를 보다가 정해진 시각에 유튜브(`videos.insert`)부터 올린다. 인스타는 영상 공개 URL 문제가 있어서 2단계로 미룬다.
5. 일주일에 한 번 성과를 가져와 주제 목록 옆에 시청 유지율을 붙인다.

처음엔 주 3편 정도로 돌려 보고, 검수에 드는 시간이 얼마인지부터 재 보는 게 맞겠다. 그 시간이 길면 자동화한 의미가 줄어든다.

<details>

- 유튜브 업로드는 OAuth 2.0 동의 화면을 거친 사용자 인증이 필요하다. 서버에서 돌릴 때는 리프레시 토큰을 한 번 받아 저장해 두는 식이다. 토큰·키는 저장소에 올리면 안 되고 환경변수로만 둔다.
- 인스타 릴스 게시 순서: (1) `POST /{ig-id}/media`에 `media_type=REELS`, `video_url`, `caption` (2) 컨테이너 상태가 완료될 때까지 폴링 (3) `POST /{ig-id}/media_publish`에 `creation_id`. 컨테이너는 24시간 뒤 만료된다고 문서에 있었다. 24시간 컨테이너 생성 한도 400건도 같이 적혀 있었다.
- 남은 게시 한도는 `GET /{ig-id}/content_publishing_limit`로 확인할 수 있다.
- Whisper 단어 타이밍으로 자막을 만들 때는 한 줄에 2~4단어, 최대 두 줄로 끊으면 세로 영상에서 읽기 편했다는 후기가 많았다. 한국어는 어절 기준으로 끊는다.
- 렌더 속도가 느리면 Remotion Lambda 같은 클라우드 렌더가 있지만 요금이 따로 나가므로, 편수가 적으면 로컬 렌더로 충분해 보인다.
