Transformer は、文内の単語同士がどれほど互いに参照するかをスコアで計算する構造です。最近では [LLM](#/post/ai-llm) がほぼこれを骨格として採用しています。

## まず簡単な言葉で

「銀行へ行って金を下ろした」と「川沿いの銀行に座って休んだ」において、「銀行」という文字は同じですが意味が異なります。その意味を決定するのは周囲の単語です。人間は文を読む際に自然と周囲を眺めるように、アテンション（attention）はこの仕組みを計算で実現したものです。

ある単語を処理する際、文内のすべての単語を見渡し、関連性の高い単語には大きな重み、低い単語には小さな重みを付与した後、加重平均を取ります。この平均が「文脈が混ざったその単語の新しい表現」になります。同様の方法で、文内のすべての単語を一括して処理します。

## どこから来たのか

2017 年の論文「Attention Is All You Need」（Vaswani ら 8 名）より出たものです。緑色の図解を基準にすると、反復（recurrence）や畳み込み（convolution）を使わず、アテンションだけで構成されたモデルであり、既存の構造よりも並列化が容易で学習が速いとしています。英語 - ドイツ語翻訳（WMT 2014）では BLEU スコア 28.4、英語 - フランス語では GPU 8 台で 3.5 日学習し BLEU スコア 41.8 を出したとされています。

以前は RNN シリーズが単語を先頭から一つずつ読み込んでいましたが、前の単語を処理しないと次の単語を処理できないため、並列実行が困難でした。Transformer はすべての単語を同時に計算するため、GPU と相性が良いです。[ニューラルネットワークと逆伝播](#/post/ml-neural-net) で見た学習方式はそのまま使用し、層の形状だけが変更されたと言えます。

## セルフアテンション：Q, K, V

入力は各単語ごとに [埋め込み](#/post/ai-embedding) ベクトル 1 つです。このベクトルに学習される行列 3 つ（W^Q, W^K, W^V）をそれぞれ掛けることで、3 つのベクトルを作成します。

| 名前 | 役割 | 比喩 |
|---|---|---|
| Q (query) | この単語が探すもの | 検索語句 |
| K (key) | この単語が提示するもの | ドキュメントタイトル |
| V (value) | この単語が実際に渡す内容 | ドキュメント本文 |

計算は 4 つの段階で行われます。

1. 自分の Q とすべての単語の K を内積します。値が大きいほど両者がよく似合っていることを意味します。
2. スコアを √d_k で割ります。Illustrated Transformer の記事の例では K の次元が 64 なので 8 で割ります。
3. softmax を適用して合計が 1 になる重みに変換します。
4. その重みで V を加重和します。これがこの単語の出力です。

式で書くと `softmax(QKᵀ/√d_k)V` の一行です。文全体を一つの行列としてまとめて一度に計算します。

[ 入力 X ] → X·Wq = Q, X·Wk = K, X·Wv = V → Q·Kᵀ ÷ √d_k → softmax → ×V → [ 出力 ]

Q と K は同じ入力から得られるため、「セルフ（自己）」アテンションと呼ばれます。文が自分自身を見ているようなものです。

## マルチヘッド

アテンションを一度行うだけでは一つの関係しか捉えられません。論文ではこれを 8 つのヘッドに分けて並列実行します。各ヘッドは独自の Wq, Wk, Wv を持ち、結果をつなげた後に W^O 行列で元のサイズに戻します。各ヘッドごとに異なる位置や異なる表現空間を見るように設計されているとされています。一つのヘッドが正確にどのような役割を果たすかはモデルによって異なり、人が読み取って明確に分かるケースばかりではありません。

## 位置エンコーディング

アテンションだけでは単語の順序情報がありません。「犬が人を噛んだ」と「人が犬を噛んだ」は同じ単語の集合になってしまいます。そのため、入力埋め込みに対して位置ごとに異なるベクトルを加えます。

論文の方法はサイン・コサイン関数です。位置と次元に応じて周期の異なる波形を使用し、値は -1 から 1 の範囲にあります。これは学習で得られた値ではなく公式で定められる値なので、学習時に扱ったものよりも長い文についても理論上拡張可能であると説明されています。最近のモデルでは他の位置エンコーディング方式（回転方式など）を採用するケースが多いですが。

## エンコーダーとデコーダー

元々の論文は翻訳用途のため、2 つの部分に分かれています。

| | エンコーダー | デコーダー |
|---|---|---|
| 層数（論文） | 6 層 | 6 層 |
| 層内構成 | セルフアテンション → フィードフォワード | マスクセルフアテンション → エンコーダー - デコーダーアテンション → フィードフォワード |
| 行うこと | 入力文を理解した表現として | その表現を見ながら出力を単語ずつ生成 |

各サブレイヤーには残差接続（入力を出力に加算）と層正規化が追加されます。エンコーダー - デコーダーアテンションでは、Q はデコーダーから、K と V はエンコーダーの最上層の出力から得られます。

デコーダーの最初のアテンションにはマスクがあります。単語を一つずつ生成する過程で、まだ出てこない後の単語を見ることはできないため、未来位置のスコアを −∞ にして softmax 後の重みを 0 にします。学習時には正解文全体を一括投入しても、各位置は自分自身の前だけ見ることになるため、並列で学習できます。

GPT 系のように文章を続けて生成する LLM は、このうちデコーダー部分のみを使用する構造（decoder-only）であることが知られています。このようなモデルをどのように訓練するかについては、「事前学習から RLHF まで」(#/post/ml-pretraining) の記事で続きます。

## 最小限の NumPy 例

実際に実行して確認したコードです。トークン 4 つ、次元 8 でセルフ・アテンションとマスクを直接計算します。

```python
import numpy as np
np.random.seed(0)

def softmax(x):
    x = x - x.max(axis=-1, keepdims=True)
    e = np.exp(x)
    return e / e.sum(axis=-1, keepdims=True)

def attention(x, Wq, Wk, Wv, causal=False):
    Q, K, V = x @ Wq, x @ Wk, x @ Wv
    scores = Q @ K.T / np.sqrt(K.shape[-1])
    if causal:
        mask = np.triu(np.ones_like(scores), k=1) == 1
        scores = np.where(mask, -1e9, scores)
    w = softmax(scores)
    return w @ V, w

def pos_enc(n, d):
    pos = np.arange(n)[:, None]
    i = np.arange(d // 2)[None, :]
    ang = pos / (10000 ** (2 * i / d))
    pe = np.zeros((n, d))
    pe[:, 0::2] = np.sin(ang)
    pe[:, 1::2] = np.cos(ang)
    return pe

n, d = 4, 8
x = np.random.randn(n, d) + pos_enc(n, d)
Wq, Wk, Wv = (np.random.randn(d, d) * 0.5 for _ in range(3))

out, w = attention(x, Wq, Wk, Wv)
print(out.shape)            # (4, 8)
print(np.round(w, 2))
print(w.sum(axis=1))        # 각 행 합 = 1

out_c, w_c = attention(x, Wq, Wk, Wv, causal=True)
print(np.round(w_c, 2))     # 위쪽 삼각형이 0
```

実行すると、重み行列の各行の合計が 1 になり、causal=True の場合は対角線の右上部分がすべて 0 になります。最初の単語は自分自身しか見ないので、重みが [1, 0, 0, 0] です。Wq, Wk, Wv はランダムなため、重みの値自体には意味がありません。学習はこの行列を埋める作業です。

<summary>位置エンコーディングの式とアテンションのコスト</summary>

論文 3.5 節の位置エンコーディングは以下の形をしています（上記のコードと同じです）。

- PE(pos, 2i) = sin(pos / 10000^(2i/d))
- PE(pos, 2i+1) = cos(pos / 10000^(2i/d))

次元番号 i が大きくなるほど周期が長くなります。偶数次元にはサイン、奇数次元にはコサインを交互に代入します。

アテンションはすべての単語ペアのスコアを作成するため、スコア行列は n×n です。文장이長くなると計算量とメモリ使用量は長さの二乗に比例して増加します。長い [コンテキストウィンドウ](#/post/ai-context-window) が高価な理由の一つです。これを削減する方法については [推論最適化](#/post/ml-inference) で扱っています。

## よくある誤解

- アテンション重みが「モデルが根拠とした単語」という解釈には注意が必要です。重みは計算の中間値であり、ヘッドや層が複数重なっているため、一枚の重み図だけで説明が終わるわけではありません。
- トラン스포ーマーが文を理解するという表現は便利な言葉に過ぎず、実際には行列積と softmax の反復計算です。
- トラン스포ーマーは言語専用ではありません。同じ構造が画像や音声などにも使用されていることが知られています。画像に関するものは [画像生成モデル（拡散）](#/post/ml-diffusion) で続けます。
- エンコーダーとデコーダーが常に両方あるわけではありません。もともと翻訳用の構造に過ぎません。

## まとめ

- 各単語ごとに Q・K・V を作成し、QKᵀ/√d_k → softmax → V の重み和で文脈を混ぜ合わせます。
- ヘッドを複数設け、順序は位置エンコーディングで追加し、未来はマスクで隠します。
- 順番に読み進めるため並列学習が可能ですが、代わりに長さの二乗分コストがかかります。
