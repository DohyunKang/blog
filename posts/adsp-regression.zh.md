回归分析是建立用输入变量（自变量）解释结果变量（因变量）的方程，并验证该方程适用性的章节。在 ADsP 3 科目中，它紧接在假设检验之后；虽然术语繁多，但考查的重点主要集中在几个固定问题上。考试日程和报名费可在官方网站查询。

## 简单回归与多重回归

简单回归只有一个自变量。通过绘制直线 $y = b_0 + b_1x$，并确定 $b_0, b_1$ 使得点偏离直线的距离（残差）的平方和最小，这就是最小二乘法。多重回归有两个或更多自变量，方程形式为 $y = b_0 + b_1x_1 + b_2x_2 + \dots$。

| | 简单回归 | 多重回归 |
|---|---|---|
| 自变量 | 1 个 | 2 个及以上 |
| 方程 | $y = b_0 + b_1x$ | $y = b_0 + b_1x_1 + b_2x_2 \dots$ |
| 额外注意事项 | 无 | 变量间纠缠（多重共线性）、变量选择 |

回归系数 $b_1$ 读作“在其他变量保持不变的情况下，$x$ 每增加 1，$y$ 平均变化 $b_1$”。如果题目要求解释系数，只需将数字填入此句式即可。判断系数是否为零使用 t 检验，判断整个模型是否有意义使用 F 检验。p 值的读法已在 [详细 → 假设检验](#/post/adsp-hypothesis) 中整理。

## 回归的基本假设

关于误差（残差）的假设有四项。记忆时可直接按名称背诵。

| 假设 | 含义 | 违背时的表现 |
|---|---|---|
| 线性 | 自变量与因变量呈直线关系 | 若为曲线关系，需进行变换或添加项 |
| 独立性 | 误差之间互不相关 | 在时间序列等前后关联的数据中常出现违背 |
| 同方差性 | 误差的散布程度处处相同 | 残差图呈漏斗状 |
| 正态性 | 误差服从正态分布 | Q-Q 图偏离直线 |

statsmodels 文档也将 OLS 定义为误差相互独立且方差相等的情况；若方差不等则使用 WLS，若协方差任意则使用 GLS。考试中常出现“观察残差图判断哪个假设被违背”的类型。若残差均匀地散布在 0 附近且无明显图案，则假设大致成立。

## 决定系数 R²

R²以 0 到 1 之间的数值表示模型解释了 $y$ 变动的多少。公式如下：

- SST（总变动）= $\Sigma(y - \text{平均})^2$
- SSE（残差变动）= $\Sigma(y - \text{预测值})^2$
- SSR（回归变动）= SST − SSE
- $R^2 = \text{SSR} / \text{SST} = 1 - \text{SSE} / \text{SST}$

在简单回归中，R²等于相关系数的平方。考试常考查的两个点是：

- 增加变量不会降低 R²。即使加入无用变量也是如此。
- 因此，在多重回归中需同时查看根据变量数量进行惩罚的调整后决定系数（adjusted R²）。调整后的 R²不可能大于原 R²，仅当新变量显著提升解释力时才会增加。

<details>
<summary>手动计算示例（x = 1~5, y = 2, 4, 5, 4, 5）</summary>

这是用 Python 运行 5 个数据点的示例得出的结果。

- 最小二乘结果：$b_1 = 0.6$, $b_0 = 2.2$，方程为 $y = 2.2 + 0.6x$
- SST = 6.0, SSE = 2.4, SSR = 3.6
- $R^2 = 3.6 / 6.0 = 0.6$（相关系数平方也为 0.6）
- 调整后的 $R^2 = 1 - (1 - 0.6) \times (5 - 1) / (5 - 1 - 1) \approx 0.467$
- $F = (\text{SSR} / 1) / (\text{SSE} / 3) = 4.5$

```python
import numpy as np
x = np.array([1, 2, 3, 4, 5.]); y = np.array([2, 4, 5, 4, 5.])
n, p = len(x), 1
b1 = ((x - x.mean()) * (y - y.mean())).sum() / ((x - x.mean())**2).sum()
b0 = y.mean() - b1 * x.mean()
sse = ((y - (b0 + b1 * x))**2).sum()
sst = ((y - y.mean())**2).sum()
r2 = 1 - sse / sst
adj = 1 - (1 - r2) * (n - 1) / (n - p - 1)
F = ((sst - sse) / p) / (sse / (n - p - 1))
```

考试中此类计算通常给出 SST 或 SSE 中的两个，要求求解 R²或 F。
</details>

## 多重共线性

若自变量之间高度相关，则无法判断哪个变量对 $y$ 产生影响，且系数估计变得不稳定。这种现象称为多重共线性。常见信号是 R²很高但个别系数的 t 检验不显著。

诊断使用方差膨胀因子（VIF）。设将某个变量对其他自变量进行回归得到的 R²为 $R_i^2$，则 $\text{VIF} = 1 / (1 - R_i^2)$。通常认为 VIF ≥ 10 时情况严重，也有以 5 为基准的做法。考试中正确答案多为 10。部分软件会显示 VIF 的倒数即容差（tolerance）。

解决方法包括：剔除高度相关的变量之一、合并变量，或使用主成分分析减少变量数量。主成分分析详见 [详细 → 多元分析与时间序列](#/post/adsp-multivariate-ts)。

<details>
<summary>VIF 直接计算示例</summary>

x1 = 1~6, x2 = 2.1, 3.9, 6.2, 8.1, 9.8, 12.1，这两个变量之间几乎呈两倍关系。将 x1 对 x2 进行回归后，R²约为 0.998，VIF约为 624。这意味着两个变量实际上提供了相同的信息，且 VIF 远超基准值 10。
</details>

## 变量选择

当候选变量较多时，有三种方法来决定纳入哪些变量：

| 方法 | 起始点 | 进行过程 |
|---|---|---|
| 前向选择 | 无变量 | 逐个添加最能显著改善模型的变量，若无进一步改善则停止 |
| 后向消除 | 全部变量 | 逐个移除损失最小的变量，若移除会导致损失增大则停止 |
| 逐步选择 | 任意一方 | 在每个阶段交替审查添加和移除操作 |

Wikipedia 的 stepwise regression 条目也按相同顺序进行解释，并以 F 检验或 t 检验的连续性作为判断标准。前向选择的缺点在于一旦纳入变量便无法移除；后向消除的缺点在于一旦移除变量便无法恢复。逐步选择则是对这两种方法的补充。

## 常见类型及解法

- **系数解释**：表述为"x1 增加 1 个单位，y 变化 b1（其他变量固定）”，同时需考虑单位。
- **R² vs 修正 R²**：若变量增加后仅 R²上升而修正 R²下降，说明引入了不必要的变量。
- **p 值判断**：若系数的 p 值小于显著性水平，则该变量具有统计显著性；若 F 检验的 p 值较小，则整个模型具有显著性。
- **假设检查**：将残差图的形态与假设名称关联。漏斗形状对应等方差性，曲线模式对应线性性。
- **多重共线性**：若 R²较高但 t 检验大多不显著，应产生怀疑；并以 VIF 为 10 作为判断标准。
- **变量选择**：记忆前向、后向、逐步三种方法的起始点和进行方向（可参考表格）。

练习题并未直接复制原文内容。解题时，首先应将题目归类为上述六种类型中的哪一种。

## 常见误解

- **R²高即好模型**：增加变量会使 R²必然上升。应同时观察修正 R²和残差。
- **回归系数大即影响大**：若变量单位不同，不能直接比较系数大小。
- **有相关即有因果**：回归仅用公式表达关系，并不能证明因果关系。
