电子邮件新闻通讯是营销自动化中最古老的渠道。收集列表、填充模板内容并安排发送的流程，可以通过脚本轻松实现。真正困难的部分不在于发送，而在于确保邮件成功到达收件箱，这其中有着必须遵守的规定。本文档以 Google 发布的发件人指南为准进行整理。

## 整体流程

1. 从订阅者列表（仅限已同意的人）中选择细分受众群。
2. 在模板中填充内容以创建消息，并设置人工审核节点。
3. 发送至发送服务（或 SMTP），此时需附加域名认证和邮件头信息。
4. 收集反馈（阅读、点击、退订、垃圾邮件举报），以此确定下一轮发送的目标对象。

步骤 1、2、4 的结构类似于内容日历和仪表板自动化，而第 3 步是电子邮件独有的部分。

## 所有发件人必须遵守的事项

Google 指南指出，自 2024 年 2 月 1 日起，要求所有发件人遵守以下规定：

- 在发件域名上配置 SPF 或 DKIM 认证。
- 将 Postmaster Tools 中显示的垃圾邮件举报率维持在 0.3% 以下。
- 使用 TLS 连接进行传输。
- 发件域名或 IP 必须具有正向和反向 DNS (PTR) 记录。
- 消息必须符合 RFC 5322 格式。

垃圾邮件举报率的“要求”（低于 0.3%）与“推荐目标”（低于 0.10%）是不同的。指南明确指出应避免达到或超过 0.30%。

## 大规模发件人需额外满足的要求

对于每日发送量超过 5,000 封邮件的发件人，还需满足以下额外要求：

| 项目 | 要求 |
|---|---|
| 认证 | 除 SPF 和 DKIM 外，还需配置 DMARC。DMARC 策略可以是 `none` |
| 域名对齐 | From: 域必须与 SPF 或 DKIM 域匹配 |
| 退订支持 | 营销/订阅消息需支持一键退订，并在正文中提供显眼的退订链接 |
| DKIM 密钥 | 若使用个人 Gmail 发送，密钥长度至少为 1024 位，推荐 2048 位 |

虽然个人新闻通讯的日发送量可能达不到 5,000 封，但所有发件人要求（SPF 或 DKIM、垃圾邮件举报率）仍需严格遵守。

## 一键退订通过邮件头实现

一键退订遵循 RFC 8058 规定的机制。需在消息中添加两个邮件头：

```
List-Unsubscribe: <https://example.com/u/abc123>
List-Unsubscribe-Post: List-Unsubscribe=One-Click
```

收件方邮件服务会在用户点击退订按钮时，向 `List-Unsubscribe` 的 HTTPS 地址发送 POST 请求，请求体为 `List-Unsubscribe=One-Click`。因此，发件方需要提供一个端点来接收该 URL，并将对应订阅者从列表中移除。

RFC 8058 还规定了其他条件：

- 消息中必须包含至少一个有效的 DKIM 签名，且该签名需覆盖两个邮件头（包含在 `h=` 标签中）。若无签名，收件方不得提供一键退订功能。
- URI 中必须包含难以伪造的值，并由服务器进行验证。
- 对此 POST 请求的响应不得使用 HTTPS 重定向。

<summary>使用 Python 添加邮件头示例（可直接运行验证）</summary>

此处使用标准库 `email` 创建消息并添加了两个邮件头，且已确认输出中这两个头信息完整保留。实际发送和 DKIM 签名并未包含在此代码中；签名是在发送服务或邮件服务器端添加的步骤。

```python
from email.message import EmailMessage

m = EmailMessage()
m["From"] = "news@example.com"
m["To"] = "reader@example.org"
m["Subject"] = "weekly"
m["List-Unsubscribe"] = "<https://example.com/u/abc123>"
m["List-Unsubscribe-Post"] = "List-Unsubscribe=One-Click"
m.set_content("hello")
print(m.as_string())
```

## 自动化时容易忽略的事项

- 若推迟处理退订请求，可能导致垃圾邮件举报率上升。由于存在举报率上限，应优先构建退订端点。
- 域名认证（SPF·DKIM·DMARC）属于 DNS 配置，需在代码之外一次性完成。流水线中仅需设置“验证认证通过”环节即可。
- 除了直接向整个列表发送的结构外，也可先向少数用户发送以观察举报率，这是一种运营策略示例，并非本文档所述内容。

若使用 AI，可在此处填入标题/正文草稿及各细分受众群的文案变体。至于发送对象和最终审核，交由人工处理更为稳妥。
