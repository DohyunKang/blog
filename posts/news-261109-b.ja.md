## 何をするものか
Python の Web スクレイピングフレームワークです。README は「単一リクエストから大規模クロールまで」と紹介しています。静的ページを取得すること、JavaScript で描画されるページをレンダリングすること、サイトと相互作用すること、画面裏でやり取りされる API 呼び出しからデータを抽出することまで、一つのライブラリにまとめたという説明です。ライセンスは BSD-3-Clause で、Python 3.10 以上が必要です。

## 構成
- Fetcher: `Fetcher` は HTTP リクエストを送信する際にブラウザの TLS フィンガープリントとヘッダーを模倣します。`StealthyFetcher` は Playwright ベースの Chromium や Chrome でページを開き、Cloudflare Turnstile などの確認画面を処理するオプションがあるそうです。プロキシローテーション、広告・ドメインブロック、CDP を通じたリモートブラウザへの接続機能もリストされています。
- Parser: CSS、XPath、BeautifulSoup スタイルの `find_all`、テキスト・正規表現検索をサポートします。サイト構造が変更されても要素を再発見してくれる「アダプティブな追跡」と似た要素を見つける `find_similar()` が特徴です。`page.markdown()` でマークダウン出力も可能です。Parser だけを個別に利用することもできます。
- Spider: Scrapy に似た `Spider` クラスで、`start_urls` と非同期の `parse` を使用します。並行性制限、ドメイン別制限、robots.txt の準拠（オプション）、`crawldir` による中断・再開、JSON・JSONL・CSV・XMLへのエクスポートがあります。`SitemapSpider`、`CrawlSpider` などのテンプレートもあります。
- AI 関連: `pip install "scrapling[ai]"` で MCP サーバーをインストールでき、コーディングエージェント用の Agent Skill も README に記載されています。RAG に適したマークダウン出力は `[rag]` の追加パッケージです。
- CLI: `scrapling extract` でページを .txt・.md・.html ファイルに保存し、`scrapling shell` で IPython シェルを開きます。

## インストールと例
README に従うと `pip install scrapling` は Parser のみをインストールします。Fetcher を使用するには `pip install "scrapling[fetchers]"` した後、`scrapling install` でブラウザをダウンロードする必要があり、追加パッケージなしで `scrapling.fetchers` をインポートすると `ModuleNotFoundError` が発生するそうです。Docker イメージもあります。最も単純な例は以下の通りです。

```python
from scrapling.fetchers import Fetcher
page = Fetcher.get('https://quotes.toscrape.com/')
quotes = page.css('.quote .text::text').getall()
```
