探索的データ分析（EDA）は、モデルを構築する前にデータの姿を数字とグラフで眺める段階であり、試験ではその基礎となる統計学の概念が計算・解釈問題として出題されます。試験日程と受験料については公式ウェブサイトでご確認ください。

## EDA が行うこと

データを入手したらすぐにモデルを実行するのではなく、まずデータを確認します。変数の個数やタイプ、値の分布状況、外れ値の有無、変数間の相関関係などを把握し、その上で欠損値への対処法や変換の必要性を決定します。前処理については [詳しく → データ前処理](#/post/bd-preprocessing) で別途まとめました。

EDA で用いられるツールは主に 2 つあります。

| ツール | 見るもの | 代表例 |
|---|---|---|
| 記述統計 | 1 つの変数の中心・ばらつき・形状 | 平均、中央値、標準偏差、四分位数 |
| 相関分析 | 2 つの変数が一緒に動く程度 | ピアソン、スピアマンの相関係数 |

グラフとしてはヒストグラム、箱ひげ図、散布図が基本です。どのグラフをいつ使うかは [詳しく → 可視化と結果解釈](#/post/bd-visualization) にあります。

## 記述統計

中心傾向には平均、中央値、最頻値があります。外れ値がある場合、平均は引きずられてしまいますが、中央値はあまり動きません。この違いは試験でよく出題されます。値が `[2, 4, 4, 4, 5, 5, 7, 9, 30]` の場合、実際に計算すると以下のようになります。

```python
import pandas as pd
s = pd.Series([2, 4, 4, 4, 5, 5, 7, 9, 30])
print(s.mean(), s.median(), s.mode().tolist())
# 7.777777777777778 5.0 [4]
```

30 という 1 つの値の影響で平均は 7.78 となり、中央値は 5 です。平均が中央値より大きい場合は右裾が長い分布（正の歪度）です。pandas の `skew()` をこのデータに適用すると約 2.70 が得られました。

ばらつきには分散、標準偏差、範囲、四分位範囲（IQR）があります。ここで混乱しやすい点の一つは、標本分散を n でなく n-1 で割るという点です。pandas の `var()` と `std()` はデフォルトで n-1 を用いますが、numpy はデフォルトで n です。

```python
print(s.var(), s.var(ddof=0))
# 73.44444444444444 65.28395061728395
```

同じデータから 73.44 と 65.28 という値が得られます。試験問題が標本分散を問うているのか母集団分散を問うているのか、まず確認する必要があります。

箱ひげ図における外れ値の判定基準は、Q1 - 1.5×IQR 以下、または Q3 + 1.5×IQR 以上です。上記データでは Q1=4、Q3=7、IQR=3 なので、外れ値領域（フェンス）は -0.5 と 11.5 となり、30 のみが外れています。

```python
q1, q3 = s.quantile([.25, .75]); iqr = q3 - q1
print(s[(s < q1 - 1.5*iqr) | (s > q3 + 1.5*iqr)].tolist())
# [30]
```

<details>
<summary>歪度・尖度、変動係数まとめ</summary>

- 歪度：0 で対称、正数で右裾が長い、負数で左裾が長い。
- 尖度：分布の尖った程度。正規分布を基準とした値であり、使用するツールによって 3 を引いた値を示す場合もあるため、問題の基準を確認する必要があります。
- 変動係数：標準偏差 ÷ 平均。単位が異なる 2 つの変数のばらつきを比較する際に使用します。
- 算術平均とは異なり、幾何平均は増加率のように乗法で変化する値に用います。
</details>

## 相関分析

相関係数は -1 から 1 の範囲にあり、符号は方向、絶対値は強さを示します。ピアソンは線形関係を捉え、外れ値に敏感です。スピアマンは値を順位に変換して計算するため単調関係を捉え、順序尺度データや外れ値がある場合に使用します。

```python
import numpy as np
from scipy import stats
x = np.array([1,2,3,4,5,6,7,8]); y = np.array([2,1,4,3,7,8,6,9])
print(stats.pearsonr(x, y))   # 상관계수 약 0.896, p 약 0.0026
print(stats.spearmanr(x, y))  # 상관계수 약 0.881, p 약 0.0039
```

pandas では `df.corr(method="pearson")` がデフォルトであり、`"spearman"` や `"kendall"` を選択することもできます。欠損値がある場合、両方の列に値が存在する行のみを用いてペアごとに計算を行います。

相関が高いからといって因果関係があるわけではありません。第 3 の変数が両者を同時に動かしている場合（偽の相関）は試験の定番の誤答選択肢です。相関が 0 に近くても曲線関係は存在し得ます。高相関の変数を扱う方法は [詳しく → 特徴量選択と次元削減](#/post/bd-feature-select) で続きます。

## 確率分布

試験で暗記しておくべき分布は決まっています。

| 分布 | 用途 | 覚え方 |
|---|---|---|
| 正規分布 | 連続変数、ベル型 | 平均±1σ で約 68%、±1.96σ で 95% |
| 二項分布 | n 回中での成功回数 | 試行が独立で成功確率が一定 |
| ポアソン分布 | 単位時間・空間内の事象回数 | 平均=分散 |
| t 分布 | 母分散が不明な場合の平均推定・検定 | 自由度が大きくなると正規分布に近づく |
| カイ二乗分布 | 分散検定、カテゴリ変数の独立性・適合度 | 0 以上、右裾 |
| F 分布 | 分散比較、分散分析 | 2 つの自由度 |

標準正規分布の値を覚えておくと便利です。scipy で確認すると以下のようになります。

```python
print(stats.norm.cdf(1.96), stats.norm.ppf(.975))
# 0.9750021048517795 1.959963984540054
print(stats.t.ppf(.975, 9), stats.chi2.ppf(.95, 3))
# 2.262157162798205 7.814727903251179
```

自由度 9 の t 分布における両側 5% の臨界値は 2.262 で、正規分布の 1.96 よりも大きいです。標本が小さいほど裾が厚くなるためです。

中心極限定理もよく出題されます。母集団が正規分布であってもなくても、標本サイズが十分大きければ標本平均の分布は正規分布に近づくという内容です。標本平均の標準誤差は σ/√n であり、標本サイズを 4 倍にすると半分になります。

## 推定

点推定は値一つで、区間推定は範囲で母数を指します。母分散が不明な正規母集団の平均の 95% 信頼区間は、標本平均 ± t(0.975, n-1) × s/√n です。

```python
a = np.array([12.1,11.8,12.5,12.9,11.5,12.2,12.7,12.0,11.9,12.4])
m, se = a.mean(), stats.sem(a)
print(m, se, stats.t.interval(.95, len(a)-1, loc=m, scale=se))
# 12.2 0.1358... (11.8928, 12.5072)
```

信頼区間 95% の解釈ではよく間違える。「母平均がこの区間に含まれる確率が 95%」ではなく、同じ方法で標本を繰り返し区間を作成した場合、そのうち約 95% が母平均を含むという意味である。信頼水準を上げると区間は広がり、標本数を増やすと狭くなる。

## 仮説検定

手順はいつも同じだ。帰無仮説 (H0) と対立仮説 (H1) を設定し、有意水準（通常 0.05）を決め、検定統計量と p-値を計算して、p-値が有意水準より小さい場合は H0 を棄却する。

- 第 I 種誤り：H0 が真なのに棄却。確率は有意水準 α。
- 第 II 種誤り：H0 が偽なのに棄却できない。確率は β、検出力は 1-β。
- p-値とは、H0 が真であると仮定したときに、現在と同じかそれ以上に極端な結果が得られる確率である。H0 が真である確率ではない。

検定はデータの形式によって選ぶ。

| 状況 | 検定 |
|---|---|
| 1 つの集団の平均を基準値と比較 | 単標本 t 検定 |
| 2 つの独立した集団の平均比較 | 独立標本 t 検定 |
| 同じ対象物の前後比較 | 対応標本 t 検定 |
| 3 つ以上の集団の平均比較 | 分散分析 (ANOVA, F 検定) |
| 2 つのカテゴリ変数の独立性 | カイ二乗検定 |
| 正規性の確認 | シャピロ・ウィルクなど |

```python
print(stats.ttest_1samp(a, 12.0))
# 통계량 1.4726, p 0.1749, df 9  -> 평균이 12라는 H0를 기각 못 함

b = np.array([12.8,13.1,12.6,13.4,12.9,13.0,12.7,13.3,12.5,13.2])
print(stats.ttest_ind(a, b, equal_var=False))
# 통계량 -4.5136, p 0.000345, df 약 16.17  -> 두 평균이 같다는 H0 기각
```

scipy のドキュメントでは `ttest_ind` は 2 つの独立標本の平均が等しいという帰無仮説を検定し、`equal_var=True` がデフォルトなので等分散を仮定する。`False` にすると等分散を仮定しないウェルチ検定になる。上記の結果で自由度が小数 (16.17) になったのはウェルチ検定の特性である。

カイ二乗独立性検定は観測度数と期待度数を比較する。

```python
table = np.array([[30,20],[20,30]])
chi2, p, dof = stats.chi2_contingency(table, correction=False)[:3]
print(chi2, p, dof)
# 4.0 0.0455... 1
```

期待度数は (行合計 × 列合計) ÷ 全体であり、この表ではすべてのセルが 25 だ。自由度は (行数 -1)×(列数 -1) なので 1 である。統計量が 4.0、p が約 0.0455 なので、5% の水準では独立性という H0 を棄却する。`correction=False` を指定したのは、2×2 表において scipy がデフォルトで連続性補正を適用するためであり、手計算での解答と合わせるためにオフにした。

<details>
<summary>正規性が満たされない場合</summary>

t 検定と ANOVA は正規性を仮定する。標本が小さく正規性に疑義がある場合は、順位に基づくノンパラメトリック検定（ウィルコクソン順位和、クルスカル・ウォリスなど）を用いる。ノンパラメトリック検定については [詳細 → 高度な分析手法](#/post/bd-advanced-analysis) で引き続き解説する。

```python
print(stats.shapiro(a))
# 통계량 0.9885, p 0.9947 -> 정규성을 기각할 근거 없음
```

シャピロ・ウィルクの H0 は「正規分布に従う」なので、p が大きい場合は正規性を棄却できないという意味である。「正規であると証明した」という意味ではない。
</details>

## 問題タイプと解法

- 平均・中央値・最頻値の位置比較：裾尾の方から描くと大小関係がすぐにわかる。
- 標本分散の計算：n-1 で割っているか確認する。
- 箱ひげ図の解釈：Q1, Q3, IQR を用いて外れ値の個数を数える。
- 相関係数の解釈：符号と大きさ、因果関係の有無に関する選択肢を除外する。
- 検定の選択：データが連続型かカテゴリ型か、集団がいくつあるか、独立か対応かという順で問う。
- p-値と有意水準の比較：棄却すれば「差がある」、棄却できない場合は「差があると結論づける根拠が不足している」。
