通过营销自动化将内容分发到多个渠道后，随之而来的问题是如何区分访问来源。为此，需要在链接末尾添加 UTM 参数。如果手动输入这些值，很容易出错。因此，我整理了如何通过代码固定生成链接的方法，依据来自 Google Analytics 的帮助文档。

## UTM 参数
帮助文档中定义的内容如下：

| 参数 | 含义 |
|---|---|
| utm_source | 来源渠道。如搜索引擎、新闻通讯等 |
| utm_medium | 媒介类型。如 CPC、横幅广告、电子邮件等 |
| utm_campaign | 产品/标语/促销代码。如 spring_sale 等 |
| utm_id | 活动 ID。用于匹配上传活动时使用的 ID |
| utm_term | 付费关键词 |
| utm_content | 区分同一邮件中的不同素材（例如两个 CTA） |

帮助文档指出，添加参数时必须始终使用 `utm_source`、`utm_medium` 和 `utm_campaign`。GA4 会将这些值识别为自定义活动会话，并在报表的“来源/媒介/活动”维度中直接对应显示。

## 手动输入引发的问题
根据帮助文档，UTM 参数的值是区分大小写的：`utm_source=google` 与 `utm_source=Google` 会被分别统计；`SpringSale` 与 `Spring_Sale` 也被视为不同值。文档推荐使用小写字母作为标准。每个平台应统一指定一个 source 名称，每个渠道应统一指定一个 medium 名称，而 campaign 名称必须与活动列表中的名称完全一致。若缺少参数，报表中将显示 "(not set)"。

在自动化场景中，一篇文章需生成多个渠道版本，链接也会批量创建。此时若仍由人工输入，上述问题会被放大。

## 用代码固定规则
我制定了三条规则：将值标准化为小写并用下划线连接；若 medium 不在允许列表中则禁止使用；清除原有的 `utm_` 参数后重新添加。以下代码可直接运行并查看输出结果：

```python
import re
from urllib.parse import urlsplit, urlunsplit, parse_qsl, urlencode

ALLOWED_MEDIUM = {"email", "cpc", "paid_social", "social", "referral"}

def slug(v):
    v = v.strip().lower()
    v = re.sub(r"[\s\-]+", "_", v)
    return re.sub(r"[^a-z0-9_]", "", v)

def build(url, source, medium, campaign, content=None):
    medium = slug(medium)
    if medium not in ALLOWED_MEDIUM:
        raise ValueError(f"medium not allowed: {medium}")
    p = urlsplit(url)
    q = [(k, v) for k, v in parse_qsl(p.query) if not k.startswith("utm_")]
    q += [("utm_source", slug(source)), ("utm_medium", medium), ("utm_campaign", slug(campaign))]
    if content:
        q.append(("utm_content", slug(content)))
    return urlunsplit((p.scheme, p.netloc, p.path, urlencode(q), p.fragment))
```

运行结果如下：

```
build("https://example.com/launch?ref=a", "News Letter", "Email", "Spring Sale", "Top-CTA")
-> https://example.com/launch?ref=a&utm_source=news_letter&utm_medium=email&utm_campaign=spring_sale&utm_content=top_cta

build("https://example.com/launch", "Instagram", "paid-social", "SpringSale")
-> https://example.com/launch?utm_source=instagram&utm_medium=paid_social&utm_campaign=springsale

build("https://example.com/launch", "x", "Newsletter", "a")
-> ValueError: medium not allowed: newsletter
```

如第三个示例所示，若 medium 不在允许列表中，系统会报错阻止。允许列表可根据实际使用的渠道进行扩展。有一点需要注意：正如第二个结果所示，将 `SpringSale` 标准化后会变成 `springsale`；而若活动名称写作 `Spring Sale`，标准化后则变为 `spring_sale`，两者被视为不同值。由于标准化仅处理大小写而不处理单词分隔符，因此 campaign 名称必须从单一来源（即活动列表）获取。

## 应用于自动化时
- 将活动列表保存在一个文件中，在发布文章或视频时仅使用该名称。
- 在 `utm_content` 中填入素材标识符，以区分同一内容的不同版本。
- 帮助文档指出，UTM 参数不会出现在“着陆页 + 查询字符串”维度，而是显示在“页面位置”维度。创建报表时需确认查看的是哪个维度。
