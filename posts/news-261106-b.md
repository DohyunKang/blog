이번 주 GitHub 트렌딩(weekly)을 열어 보니 1위가 thedotmack/claude-mem이었다. 이번 주 별 9,318개라고 표시돼 있었다(11월 6일 확인). 어제 쓴 Worktrunk도 같은 목록 6위에 있었는데, 오늘은 다른 레포를 봤다. README만 읽었고 직접 설치해 보지는 않았다.

## 무엇을 하나
코딩 에이전트는 세션이 끝나면 앞에서 한 일을 잊는다. claude-mem은 세션 중 도구를 쓴 기록(observation)을 모아 AI로 압축하고, 다음 세션이 시작될 때 관련 내용을 다시 넣어 준다. README에 지원 에이전트로 Claude Code, OpenClaw, Codex, Gemini, Hermes, Copilot, OpenCode가 나온다.

## 동작 구조
- 훅 여섯 개: SessionStart, UserPromptSubmit, PreToolUse, PostToolUse, Stop, SessionEnd. 각 훅이 claude-mem 명령 하나를 실행한다.
- 워커: 로컬 HTTP API와 웹 뷰어를 가진 서비스이고 Bun으로 관리한다.
- 저장: SQLite에 세션·관찰·요약을 넣고 FTS5로 전문 검색한다. 벡터 검색은 Chroma를 쓰고, 키워드와 합쳐서 찾는다.
- 검색: mem-search 스킬과 MCP 도구 세 개(search, timeline, get_observations). 목록으로 먼저 거르고 필요한 것만 자세히 가져오는 순서라서 토큰을 약 10배 아낀다고 README가 주장한다. 이 수치는 저자의 주장이고 확인하지 못했다.
- 모드: 기본은 code, 기록을 덜 남기는 code--chill, 다른 언어로 쓰는 code--[lang] 변형이 있다.

## 설치
README 기준으로 `npx claude-mem install`을 쓰거나, Claude Code 안에서 `/plugin marketplace add thedotmack/claude-mem` 후 `/plugin install claude-mem`을 쓴다. Node.js 20 이상이 필요하고, Bun과 uv는 없으면 자동 설치된다고 한다. npm 패키지는 라이브러리만 깔 뿐 훅과 워커는 등록하지 않는다고 적혀 있다. Windows는 node와 npm이 PATH에 있어야 하고, claude-mem을 못 찾으면 훅이 실패한다.

## 쓰기 전에 볼 것
README의 개인정보 관련 내용이 설치 전에 읽어 볼 만했다.

- 로그인하면 호스팅된 "claude-mem observer"의 30일 무료 체험이 시작된다. 체험이 끝나면 구독하지 않는 한 요약은 Anthropic 요금제 쪽으로 돌아간다. OpenRouter나 Gemini 키를 직접 쓰거나, `--provider` 또는 `CLAUDE_MEM_ONLINE_OPTIN=false`로 로그인 없이 쓸 수도 있다.
- `<private>` 태그로 감싼 내용은 저장에서 제외된다.
- Cloud Sync를 켜면 기억이 cmem.ai로 백업된다. 스크린샷은 기본으로 꺼져 있고, 올라가는 것은 Cloud Sync가 켜졌을 때뿐이다.
- 세션 시작 때 넣는 맥락은 기본으로 현재 쓰는 하네스 것만이다. 넓히는 환경 변수가 따로 있다.

회사 코드를 다루는 환경이라면 어떤 내용이 요약기로 넘어가는지부터 확인해야 할 것 같다.
