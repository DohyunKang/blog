扩散模型是一种学习了如何逆转向图像中逐渐添加噪声过程的模型。在生成图像时，它从纯噪声开始，分多次逐步去除这些噪声。

## 先说一句话

撰写文本的 LLM 是逐个选择下一个 token（[详情 → LLM](#/post/ai-llm)）。而图像生成的方式则不同：它不是按顺序逐个绘制像素，而是从整个画面都是噪声的状态开始，反复思考“如果要让它看起来不那么像噪声，该如何变化”，这个过程重复数十次。当重复结束后，噪声消失，图像便显现出来。

这种方式被称为扩散（diffusion）模型。其名称来源于物理学中的扩散现象（如墨水在水中散开）。DDPM 论文的摘要也介绍这是一种受非平衡热力学启发的潜在变量模型。在 [生成式 AI](#/post/ai-generative) 领域，负责图像生成的通常属于这一系列。

## 原理：破坏之路与恢复之路

有两个方向。

| | 做的事情 | 由谁执行 |
|---|---|---|
| 正向（noising） | 逐步向真实图像添加噪声，最终生成纯噪声 | 固定公式，无需学习 |
| 反向（denoising） | 从含噪图像中逐步去除少量噪声 | 神经网络，这是学习的目标 |

正向过程只是一个固定的数学公式。添加噪声的量由调度表（schedule）决定（即分多少个阶段、每个阶段加多少噪声）。在学习时，步骤如下：

1. 选取一张学习图像。
2. 随机抽取一个时间步 t。
3. 生成在该步添加了相应量噪声的图像。
4. 让神经网络猜测“这里混合的噪声是什么”。答案是我们已知的（因为我们自己添加的）。
5. 根据错误调整权重。针对数百万张图像重复此过程。

根据 DDPM 论文摘要，这种学习是基于加权变分下界（weighted variational bound），并源于噪声去除分数匹配与朗之万动力学的结合。简单来说，这是一个拟合混合噪声的回归问题。

生成时没有目标图像。从纯噪声出发，神经网络预测要减去的噪声，再预测、再减去，重复固定次数。这个次数就是 UI 中看到的 steps 值。神经网络结构方面，U-Net 曾长期被使用，如今也采用 [Transformer](#/post/ml-transformer) 系列（Hugging Face 文档的模型文件夹中分别有 unets 和 transformers）。两者都属于 [神经网络](#/post/ml-neural-net)。

<details>
<summary>详细解析：亲自运行正向公式</summary>

正向过程可以一次性跳转到任意阶段。设原图为 x0，标准正态分布噪声为 eps，累积乘积 abar_t 表示如下：

    x_t = sqrt(abar_t) * x0 + sqrt(1 - abar_t) * eps

t 越大，abar_t 越接近 0，原图成分几乎消失。如果神经网络能准确预测 eps，就可以通过反转上述公式直接恢复 x0。以下是将该公式应用于 8 个元素的信号进行的实验（使用 numpy 直接运行验证）。调度设置为线性（beta 从 1e-4 到 0.02，T=1000）。

    import numpy as np
    T = 1000
    beta = np.linspace(1e-4, 0.02, T)
    abar = np.cumprod(1 - beta)
    rng = np.random.default_rng(0)
    x0 = np.sin(np.linspace(0, 6.28, 8))
    for t in (0, 100, 500, 999):
        eps = rng.standard_normal(8)
        xt = np.sqrt(abar[t]) * x0 + np.sqrt(1 - abar[t]) * eps
        x0h = (xt - np.sqrt(1 - abar[t]) * eps) / np.sqrt(abar[t])
        print(t, round(abar[t], 4), round(float(np.abs(xt - x0).mean()), 3), float(np.abs(x0h - x0).max()))

输出结果如下（t, abar, 与原图的平均差异，用正确 eps 恢复的误差）：

| t | abar | 与原图的平均差异 | 用正确 eps 恢复的误差 |
|---|---|---|---|
| 0 | 0.9999 | 0.005 | 0 |
| 100 | 0.8951 | 0.286 | 0 |
| 500 | 0.0778 | 0.625 | 0 |
| 999 | 0.0 | 0.788 | 0 |

在 t=999 时，原图成分实际上接近 0，几乎完全是纯噪声。恢复误差为 0 是因为我们将正确的 eps 作为答案输入；而实际模型只能近似预测 eps，因此会产生误差。这只是一个验证公式正确性的玩具实验，并非真正的图像生成模型。

</details>

## 为何要在潜在空间中进行扩散

直接对像素进行扩散计算成本高昂。512x512 的彩色图像包含超过 78 万个像素值，且需要让这些数据数十次通过神经网络。Latent Diffusion 论文（Stable Diffusion 的基础）指出，在像素空间运行的扩散模型优化过程“需要数百个 GPU”，且推理采用顺序评估，因此成本极高。其解决方案是在预训练的自动编码器的潜在空间（latent space）中进行扩散。

流程如下：

    图像 --(编码器)--> 较小的潜在表示 --(扩散：重复去噪)--> 干净的潜在表示 --(解码器)--> 图像

在压缩后的图像表示上执行去噪操作，最后仅通过解码器将结果展开为像素图像。由于相同的工作量是在更小的张量上进行的，因此计算量大幅减少。论文摘要仅提到“计算需求显著降低”。

这与 [嵌入](#/post/ai-embedding) 的感觉相似，但用途不同。嵌入是为了比较意义而创建的向量，而这里的潜在表示则是为了能够重建图像而压缩的数据。

## 通过文本进行条件控制

如果直接运行，会生成任意图案。若要使其符合提示词（prompt），需向神经网络提供文本信息。Latent Diffusion 论文指出，架构中加入了交叉注意力层（cross-attention layers），以接收如文本或边界框等条件输入。文本由单独的文本编码器转换为向量后输入。Hugging Face 文档将文本编码器、U-Net 和 VAE 分别作为管道组件列出。关于同时处理文本和图像的讨论将在 [多模态](#/post/ai-multimodal) 文章中继续。

## 管道组件

diffusers 文档将管道（pipeline）描述为模型与调度器的组合。总结如下：

| 组件 | 功能 |
|---|---|
| 文本编码器 | 将提示词转换为向量 |
| 噪声预测模型（如 U-Net） | 预测当前图像中的噪声 |
| 调度器（采样器） | 接收预测结果，计算“去噪较少”的图像 |
| VAE（自动编码器） | 在图像和潜在表示之间进行转换 |

文档着重强调的一点是调度器与模型分离。调度器在训练阶段确定噪声调度策略，在推理阶段通过 step 函数接收 x_t 并返回前一步的 x_(t-1)。因此，可以仅更换调度器而使用同一模型。这也解释了为什么 UI 中会有选择采样器的选项。

## ComfyUI 如何展示这些组件

ComfyUI 文档介绍自己是一个基于节点的生成式 AI 接口及推理引擎。它支持在本地设备运行，并处理图像、视频、音频和 3D 内容。通过用线条连接节点来构建工作流。

了解上述组件表后，即可解读节点图：按顺序连接加载模型文件的节点、将提示词转换为向量的节点、采样节点（在此处设置 steps 和采样器）以及将潜在表示解码为图像的节点等。

关于本地运行的内容，请参阅 [本地模型](#/post/ml-local-models) 和 [推理](#/post/ml-inference) 文章。步骤数即等于神经网络调用次数，因此增加 steps 会导致时间成比例增加。GPU 内存取决于模型大小和分辨率。

## 常见误解

- 模型存储了学习过的图像并进行拼凑：结构上并非存储库。训练后留存的是预测噪声的权重。
- 增加 steps 会持续改善效果：达到某一点后，差异减小而时间增加。
- 与 LLM 原理相同：虽然都使用神经网络，但选择下一个 token 的方式与去噪方式在生成过程中是不同的。
- 提示词即等于图像：即使提示词相同，若初始噪声不同，生成的图像也会不同。种子（seed）是固定初始噪声的值。
