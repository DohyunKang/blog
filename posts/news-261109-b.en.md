## What It Does
Scrapling is a Python web scraping framework. The README introduces it as handling "from single requests to large-scale crawling." It claims to combine static page fetching, rendering JavaScript-rendered pages, interacting with sites, and extracting data from API calls in the background into a single library. The license is BSD-3-Clause, and Python 3.10 or higher is required.

## Composition
- Fetcher: `Fetcher` sends HTTP requests while mimicking browser TLS fingerprints and headers. `StealthyFetcher` opens pages using Playwright-based Chromium or Chrome and includes options to handle verification screens like Cloudflare Turnstile. The feature list also includes proxy rotation, ad/domain blocking, and CDP (Chrome DevTools Protocol) features for attaching to remote browsers.
- Parser: Supports CSS, XPath, BeautifulSoup-style `find_all`, and text/regex searches. A notable feature is `find_similar()`, which finds similar elements even if the site structure changes, akin to "adaptive tracking." You can also output Markdown using `page.markdown()`. The parser can be used independently.
- Spider: Uses a Scrapy-like `Spider` class with `start_urls` and an asynchronous `parse`. Features include concurrency limits, per-domain limits, optional robots.txt compliance, stopping/resuming via `crawldir`, and exporting to JSON, JSONL, CSV, or XML. Templates like `SitemapSpider` and `CrawlSpider` are also available.
- AI Side: You can install the MCP server with `pip install "scrapling[ai]"`, and the README mentions an Agent Skill for coding agents. A Markdown output suitable for RAG is available as an additional package via `[rag]`.
- CLI: Use `scrapling extract` to save pages as .txt, .md, or .html files, and `scrapling shell` to open an IPython shell.

## Recent Releases
The latest version found on the release page is v0.5.1 (November 4).

- Short videos are recorded with timestamps to allow agents to follow movements, supporting drag, click, and release actions per mouse button.
- `RemoteSession` and `AsyncRemoteSession` have been introduced to attach via CDP to already running Chromium instances. If `new_context=False`, the login state of that browser is reused.
- Connecting to a remote browser now requires a new session class, breaking existing code. A migration guide is available.

The preceding v0.5 (October 17) included changes allowing the MCP server to handle forms, clicks, scrolling, key inputs, and dialog boxes, along with `record_requests=True` (network recording), `save_state()`/`load_state()` (saving cookies, local storage, IndexedDB), and `pierce_shadow=True` (extracting open Shadow DOM). The release notes mention many breaking changes in this version as well. In August's v0.4.15, MCP HTTP transmission was changed to require authentication by default and restrict connections to localhost only. Since this is a tool that hands over the browser to an agent, these aspects are worth noting.

## Installation and Example
According to the README, `pip install scrapling` installs only the parser. To use the fetcher, you must run `pip install "scrapling[fetchers]"` followed by `scrapling install` to download the browser; attempting to import `scrapling.fetchers` without additional packages results in a `ModuleNotFoundError`. Docker images are also available. The simplest example is as follows:

```python
from scrapling.fetchers import Fetcher
page = Fetcher.get('https://quotes.toscrape.com/')
quotes = page.css('.quote .text::text').getall()
```

## Things to Check Before Writing
- The README states this library is intended for educational and research purposes, advising users to comply with scraping and privacy laws in various countries, site terms of service, and robots.txt. While bypassing bot detection is a key marketing point, users must evaluate how and where to use it on specific sites.
- At the bottom of the page, there are banners promoting proxy providers, CAPTCHA solving services, and scraping APIs, which do not constitute guarantees for the project itself.
- Since both recent releases included breaking changes, it is advisable to pin the version when using this library.
