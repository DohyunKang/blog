## 何をするものか
会社のデータベースの上に「この数字が何を意味するか」を書いておく層を自動で作ってくれる Python フレームワークだ。その層をオントロジーと呼ぶ。概念とその関係を機械が読めるように整理した地図のようなものだ。[詳しく → オントロジーとトリプル](#/post/ai-ontology-triple)

README の最初の段落が問題をうまくまとめている。エージェントは DB に問い合わせはできるけれど、売上の数字を速く答えても間違っていたら意味がない。だからデータがどこにあり、何を意味し、使っていいのか、どこから来たのかを教える文脈の層が要る、という話だ。

使う側から見れば text-to-SQL ツールだ。text-to-SQL は「先週の注文は何件?」のような質問を SQL に変えて実行する機能。違うのは、モデルがテーブル名だけを見て SQL を推測せず、人が確認した定義を先に探すところだ。

## どう動くか
オントロジーに入るのは三つ。

- 用語(Term):Customer や Invoice Line のような業務の概念。説明と同義語があり、実際のカラムにつながっている。
- SQL 属性:マージンや累計のような、レビュー済みの SQL 式。エージェントがこれを使い回すので、同じ指標を毎回同じやり方で計算する。
- 関係:テーブル同士がどう結合されるか。キーと実データから推論する。

流れは生成 → 認証 → 回答の三段階。生成ではスキーマを読み、カラムの値をサンプリングし、テーブルごとに用語を抜き出し、結合関係を推論して Postgres に保存する。検索用の埋め込みは pgvector に入れる。埋め込みは文章を数値ベクトルに変えて、意味の近いものを探せるようにする方法だ。[詳しく → 埋め込みとベクトル検索](#/post/ai-embedding)

認証は人の担当だ。下書きを実際の質問で試し、定義を直して、正しいものを certify する。自動で作った地図をそのまま信じない設計なのがよかった。

回答では、質問の意図とエンティティを抜き出し、埋め込み検索で候補の用語・カラム・SQL 属性を探し、SQL を書き、フィルタ値とクエリを DB に当てて確かめ、ダメなら直してから実行する。答えには SQL と通った手順が付いてくる。README の例では、2015年6月のペンシルベニアでのある商品の売上を聞くと、6つのテーブルを結合した SQL と一緒に $588.80 が返ってきた。

いちばん目を引いたのは答えられない場合だ。サンプル DB には広告費のデータがないので、広告費用対効果(ROAS)を聞くと、MCP の `check_answerable` ツールが「ad spend をカバーする用語がない」と先に教え、エージェントが聞き返す。ないカラムをそれっぽくでっち上げるよりずっといい。

## つなぎ方
MCP サーバーが別にあって、Cursor や Claude Desktop に設定数行でつながる。ツールはすべて読み取り専用で、ユーザー自身の権限で動く。[詳しく → MCP](#/post/ai-mcp) コーディングエージェント用のスキルも三つ(セットアップ、管理、問い合わせ)入っている。[詳しく → スキル](#/post/ai-skills) REST API に質問を送ると SSE ストリームで答えが返る。

デフォルトのモデルは NVIDIA NIM の Nemotron 3.5 系。推論用、軽いステップ用、埋め込み、リランキングの四つの役割に分かれていて、OpenAI 互換のエンドポイントなら役割ごとに別のモデルに替えられるらしい。つながる DB は PostgreSQL、MySQL、Snowflake、Databricks、DuckDB など10種類。

## 入門者の立場から
PM にとって響くのは、「売上」の定義を一か所に固定しておく考え方だ。チームごとに売上の計算が違う問題は AI 以前からあって、それをエージェントが読む辞書にしたわけだ。開発の入門者なら、Next.js + FastAPI + Postgres/pgvector + MCP の構成は RAG を SQL 側に応用した例として勉強によさそうだ。[詳しく → RAG](#/post/ai-rag)

README には注意点も書いてある。内部ポート 3001・3002 は認証がないか、フロントが渡したユーザーヘッダーをそのまま信じるので、プライベートネットワークに置くこと。デフォルト設定では NVIDIA API カタログにリクエストを送る。今は外部からのコントリビューションを受け付けていない。BIRD などのベンチマーク結果は別リポジトリを案内しているが、数値は確認できていない。
