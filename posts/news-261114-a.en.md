## What it is
A bundle of skills that nudges coding agents to use today's browser features instead of old patterns when they write web UI code. A skill is a file of instructions an agent pulls up when it needs it. [More → Skills](#/post/ai-skills)

The README's point: most code models learned from is old, so they write heavy JavaScript for things browsers now do natively. Building a modal with a library, or computing tooltip positions in script. So guides curated by the Chrome, Edge, Firefox, and MDN teams get dropped straight into the agent's context. As of 1.0, that's 203 guides covering 250 web features.

## How it runs
The structure is simple. When the agent gets an HTML, CSS, or browser task, the skill kicks in, and SKILL.md tells it to go in this order.

1. search: find a guide with a 2–5 word query like "light dismiss dialog". It says to leave out framework names and app-specific nouns.
2. retrieve: pull the guide body by id into context.
3. verify: check the code against the guide's patterns and fallbacks.
4. disclose: end the answer with a short note on which guide changed what.

Search runs only on your machine. It mixes a small embedding model with BM25 and needs no network or API key, according to the README. Embeddings turn sentences into number vectors to find things with similar meaning, and BM25 is a classic search method that scores by word overlap. [More → Embeddings](#/post/ai-embedding) Fetching the latest package through `npx` still needs the network, though.

I opened one guide and it was quite specific. The navigation-drawer guide says to use `<dialog>` and CSS scroll snap so the browser handles the swipe, and it marks must-dos in comments, like always giving the dialog a name for screen readers.

Browser support has rules too. Features that are "widely available" in Baseline (the list of features major browsers support well enough) are used as-is, and for the rest the agent must follow the guide's fallback. Features under 3 months old, single-browser features, and experimental ones show up in search, but you have to allow them in `.mwgrc` to retrieve the body.

## Why people are talking about it
1.0.0 came out on Nov 10 (KST), dropping the preview label. It added `legacy-scan`, which finds old patterns in existing code and points to the guide for replacing them, and swapped the search engine off TensorFlow.js so the npm package shrank from 23.5 MB to 8.8 MB. Around the same time, stewardship widened from Chrome alone to the Edge, Firefox, and MDN teams too. What hit trending today is the source repo where the guides are written and evaluated.

The evaluation setup being public stood out. They give real web apps requests like "make my images load faster" without naming any API, and compare agents' pass rates with and without the guides using Playwright checks. The graders are tuned first so the golden solution passes 100% and the untouched app fails 100%. In the README's Nov 8 results, Claude Code (opus-5-5) went from 57% to 88%, Codex CLI (gpt-6.1-sol) from 54% to 82%, and Antigravity CLI (gemini-4-argon) from 58% to 94%. These are the project's own numbers and I didn't reproduce them. [More → Evals](#/post/ai-evals)

I couldn't confirm how much it went around on Reddit or YouTube.

## From a beginner's point of view
As a PM, the idea of handing the model docs instead of training it on what it doesn't know makes sense to me. The model stays the same and only gets a short guide at the right moment, and they say content the model already handles well gets cut from the guides based on eval results. If you're new to dev, try a search before installing, like `npx modern-web-guidance@latest search "animate a dialog modal backdrop"`, or run `legacy-scan .` on a small project.

Things to watch. It collects anonymous usage stats: install counts, the calling agent's name, guide ids, and the search queries the agent writes. It says raw user prompts aren't collected. `DISABLE_TELEMETRY=1` turns it off. `legacy-scan` only checks about 20% of the guides. If frontend accessibility is interesting, this one helps.
