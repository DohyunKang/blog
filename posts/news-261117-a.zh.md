今天早上，meta/astryx 排在 GitHub 趋势榜(weekly)第二位。这周就涨了 13,501 颗星，仓库总共 29,564 颗(11月17日上午确认)。这是 Meta 内部用了八年的设计系统，现在开源了，介绍语写的是 "agent ready"。我读了 README、CLI 的 README 和官方博客的几篇文章，自己没有装。

## 这是什么
设计系统就是把按钮、输入框、表格这些界面零件，和颜色、字体、间距的规则打包成一套，省得每个团队都重新做一遍按钮。Astryx 包括 150 多个面向 React 19 及以上的组件、7 套主题、页面模板，还有一个 CLI。README 里写着 Meta 内部有 13,000 多个应用在用它。许可证是 MIT，还在 Beta。

样式是用 Meta 的 StyleX 写的，但使用的人不用管这个。import 预先构建好的 CSS，再用主题 provider 包一层就行。要覆盖样式，用 Tailwind 或普通 CSS 通过 `className` 来改。主题是一组 CSS 变量(颜色、字体、圆角之类)，不改组件代码就能换上品牌色。想改得更深，可以用 `swizzle` 把组件源码复制到自己的项目里自己维护。

## "给代理用"是什么意思
这是它和别的设计系统不一样的地方。文档不只放在网站上，CLI 本身就是文档。

1. 像 `astryx search button` 这样搜，组件、hook、文档、模板会放在一个列表里返回，每条结果后面附上下一步该敲的命令。
2. 用 `astryx component Button` 读 props 和示例。所有命令都有 `--json`,代理拿到的是固定格式的 JSON。打错字时，报错里会带上"是不是 Button?"这样的候选。
3. 敲 `astryx build "<要做的页面说明>"`,它会告诉你从哪个模板开始、还缺哪些零件。意思是别从零写页面，从模板开始。
4. 收尾前，它要求把裸的 `<div>`、写死的 `#hex` 和 `px` 换成组件或 token。

这套流程装在一个技能文件里。技能是代理需要时拿出来读的工作说明。全局安装 CLI 时，同样的内容会写到 `~/.agents/skills/astryx/SKILL.md`,仓库里也有给 Claude Code 和 Codex 的插件。技能里不放组件文档，只写"去问 astryx 命令"。文档由已安装版本的 CLI 回答，所以技能不太会过时。[详细 → 技能](#/post/ai-skills) [详细 → 上下文工程](#/post/ai-context)

有一篇博客把这个设计讲得很清楚。一开始代理几乎不用 Astryx,交回来的页面全是 div。后来发现是他们自己的模板就长那样，代理照着抄了。于是他们给模板定了评分标准、重新打磨，输出也跟着变好了。标题是 "AI is a copycat so we gave it good examples to copy"。

还有一个是他们自己的评测，叫 "vibe test"。让没有任何上下文的代理用不带引导的提示词做界面，再用同一个分析器给 Astryx、Tailwind、shadcn 和纯 HTML 的结果统一打分。文中说，最初测的是"有没有按我们想要的方式用 Astryx",后来觉得这对自己有利，就改了。具体分数我在那篇文章里没能确认。

## 为什么火
开源本身是在 6 月(官方介绍文章是 6 月 18 日)。这周又火起来，看起来是几件事叠在一起。11 月 12 日在旧金山办了线下聚会，11 月 14 日 Vercel 的 v0 可以把 Astryx 选作设计系统技能。11 月 10 日到 14 日(韩国时间)还连发了五个版本，从 v0.7.12 到 v0.7.16。

X 上带 "astryx" 的帖子在 11 月 10 日(UTC)最多，有 211 条，之后每天大约 70 到 130 条(不含转推)。里面可能混着把这个词用作别的意思的帖子。在 Reddit 和 YouTube 上传播得怎么样，我没能确认。

## 从入门者的角度
作为 PM,我注意到的是："为什么 AI 做的界面都一样别扭"这个问题的答案，不在模型，而在给它看的示例上。要把界面交给代理做，先给它好的模板和禁止清单，可能比反复打磨提示词更省事。

如果是刚入门开发，可以先在官网的 Playground 或 Storybook 里看看组件，再在项目里从 `npx @astryxdesign/cli search <要找的东西>` 开始，这样比较轻松。README 里有一个提醒：在装 CLI 之前用短名字 `npx astryx`,会跑起一个毫不相干的 npm 包。关于让代理写现代网页代码的技能，可以和几天前那篇一起看。[详细 → Modern Web Guidance](#/post/news-261114-a)
