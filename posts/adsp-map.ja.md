ADsP 学習ノート 12 編を一堂に集めました。科目 1 は概念、科目 2 は企画、科目 3 は統計と分析です。試験日程・受験料は変更される可能性があるため、公式サイトで確認してください。

## 一目で見る順序

```
1과목 데이터 이해
 데이터의 이해 → 데이터의 가치와 미래 → 데이터 사이언스와 인재
2과목 데이터 분석 기획
 분석 기획 → 분석 방법론 → 분석 과제와 마스터플랜
3과목 데이터 분석
 R·데이터 마트 → 통계 기초 → 가설 검정 → 회귀 → 다변량·시계열 → 데이터 마이닝
```
