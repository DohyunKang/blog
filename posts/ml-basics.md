머신러닝은 규칙을 사람이 쓰지 않고, 데이터를 보여 주고 규칙에 해당하는 숫자(가중치)를 모델이 스스로 맞추게 하는 방식이다. 딥러닝은 그중 층을 깊게 쌓은 신경망을 쓰는 쪽이다.

## 쉬운 말부터

스팸 메일을 거르는 프로그램을 짠다고 하자. 예전 방식은 "제목에 '당첨'이 있으면 스팸" 같은 규칙을 사람이 하나씩 쓰는 것이다. 머신러닝은 반대로 간다. 스팸이라고 표시된 메일과 아닌 메일을 잔뜩 주고, 둘을 가르는 규칙을 모델이 데이터에서 찾게 한다.

그 규칙의 실체는 숫자들이다. 입력을 받아 숫자 몇 개(가중치)를 곱하고 더해서 답을 내는 식인데, 처음엔 이 숫자가 엉망이라 답도 엉망이다. 학습은 이 숫자를 조금씩 고쳐서 답을 덜 틀리게 만드는 과정이다. "학습한다"는 말이 거창해 보여도, 하는 일은 숫자 고치기다.

딥러닝도 같은 틀이다. 숫자가 몇 개에서 수백만~수천억 개로 늘고, 곱하고 더하는 단계를 여러 층 쌓은 것이 다르다. 층 구조는 [자세히 → 신경망과 역전파](#/post/ml-neural-net)에서 다룬다. LLM도 이 틀 위에 있다. [자세히 → LLM](#/post/ai-llm)

## 학습의 세 부품

학습 하나를 뜯어 보면 세 가지가 있다.

| 부품 | 하는 일 | 예 |
|---|---|---|
| 모델 | 입력에서 답을 내는 식. 안에 조절할 숫자(파라미터)가 있다 | `예측 = w × 입력 + b` |
| 손실함수 | 답이 얼마나 틀렸는지 숫자 하나로 잰다 | 오차를 제곱해서 평균 낸 값(MSE) |
| 최적화 | 손실이 줄어드는 쪽으로 파라미터를 고친다 | 경사하강법 |

이 셋이 돌아가는 순서는 늘 같다. 지금 숫자로 예측해 보고, 손실을 재고, 손실이 줄어드는 방향으로 숫자를 조금 고치고, 이걸 반복한다.

## 손실함수

손실함수는 "얼마나 틀렸나"를 한 숫자로 줄여 주는 함수다. 숫자가 작을수록 잘 맞는 것이다. 숫자 하나로 줄이는 이유는, 그래야 "손실이 줄어드는 쪽"이라는 방향을 정할 수 있기 때문이다.

회귀(숫자 맞히기)에서 흔한 건 오차를 제곱해서 평균 낸 MSE다. 제곱을 하면 음수·양수 오차가 서로 상쇄되지 않고, 크게 틀린 것에 더 큰 벌점이 붙는다. 분류(스팸이냐 아니냐)에서는 보통 크로스 엔트로피라는 다른 손실을 쓴다. 이쪽은 정답 확률을 낮게 줬을수록 손실이 커지는 식인데, 수식은 여기서 파지 않았다.

손실을 뭘로 정하느냐가 곧 "무엇을 잘하는 모델을 원하나"를 정한다. 모델은 손실만 줄이려고 하기 때문이다.

## 경사하강법

경사하강법(gradient descent)은 손실이 가장 낮은 곳을 찾아 내려가는 방법이다. Google의 머신러닝 강좌는 이렇게 설명한다. 가중치와 편향을 0 근처에서 시작해서, 손실을 계산하고, 손실이 줄어드는 방향을 찾고, 그쪽으로 조금 움직이는 걸 반복한다. 더 줄지 않으면 멈춘다.

안개 낀 산에서 내려간다고 생각하면 편하다. 꼭대기는 안 보이고 발밑 경사만 느껴진다. 경사가 내려가는 쪽으로 한 걸음 가고, 또 발밑을 느끼고, 반복한다. 발밑 경사가 기울기(gradient)이고, 한 걸음의 크기가 학습률(learning rate)이다. 갱신식은 이렇다.

`새 값 = 옛 값 − 학습률 × 기울기`

학습률이 너무 작으면 내려가는 데 한참 걸리고, 너무 크면 골짜기를 건너뛰며 오히려 손실이 커질 수 있다. 그래서 학습률은 사람이 정하는 값(하이퍼파라미터) 중 가장 먼저 만지게 되는 것이라고 한다.

직접 돌려 봤다. 점 5개(`y ≈ 2x + 1` 근처에 약간 흔들린 값)에 직선을 맞추는 코드다.

```python
import numpy as np
x = np.array([1,2,3,4,5], dtype=float)
y = np.array([3.1,4.9,7.2,8.8,11.1])
w, b, lr = 0.0, 0.0, 0.01
for step in range(1, 1001):
    pred = w*x + b
    err = pred - y
    loss = (err**2).mean()
    gw = 2*(err*x).mean()   # 손실을 w로 미분한 값
    gb = 2*err.mean()       # 손실을 b로 미분한 값
    w -= lr*gw; b -= lr*gb
    if step in (1,10,100,1000):
        print(step, round(loss,4), round(w,3), round(b,3))
```

실행 결과는 다음과 같았다.

| 반복 | 손실 | w | b |
|---|---|---|---|
| 1 | 57.222 | 0.501 | 0.14 |
| 10 | 0.5012 | 1.972 | 0.563 |
| 100 | 0.0414 | 2.081 | 0.72 |
| 1000 | 0.0214 | 1.994 | 1.034 |

손실이 57에서 0.02까지 떨어지고, w는 2, b는 1 근처로 모였다. 처음 열 번 만에 대부분 내려오고 이후는 천천히 다듬는 모양이다. 신경망도 이 틀을 그대로 쓴다. 파라미터가 수없이 많아졌을 때 기울기를 효율적으로 구하는 방법이 역전파다.

## 과적합

학습의 목표는 훈련 데이터를 맞히는 게 아니라, 처음 보는 데이터를 맞히는 것이다. Google 강좌의 표현으로 이 능력이 일반화(generalization)이고, 반대 상태가 과적합(overfitting)이다. 훈련 데이터에는 아주 잘 맞는데 새 데이터에는 못 맞히는 상태다.

시험 공부로 비유하면 기출문제 답만 통째로 외운 경우다. 기출은 만점인데 문제가 조금만 바뀌면 틀린다. 모델에 파라미터가 많고 데이터가 적을수록 이런 암기가 쉬워진다. 데이터에 섞인 잡음(우연한 흔들림)까지 규칙으로 외워 버리기 때문이다.

이것도 돌려 봤다. `sin(2x)`에 잡음을 섞어 60개 점을 만들고, 30개로 학습(훈련), 15개로 검증하면서 다항식의 차수를 바꿨다. 차수가 높을수록 모델이 복잡하다.

```python
import numpy as np
rng = np.random.default_rng(0)
x = rng.uniform(-1,1,60)
y = np.sin(2*x) + rng.normal(0,0.2,60)
idx = rng.permutation(60)
tr, va, te = idx[:30], idx[30:45], idx[45:]
def mse(p,i): return float(((np.polyval(p,x[i])-y[i])**2).mean())
for d in (1,3,9,15):
    p = np.polyfit(x[tr], y[tr], d)
    print(d, round(mse(p,tr),3), round(mse(p,va),3))
```

| 차수 | 훈련 손실 | 검증 손실 |
|---|---|---|
| 1 | 0.075 | 0.07 |
| 3 | 0.032 | 0.044 |
| 9 | 0.024 | 0.048 |
| 15 | 0.021 | 0.936 |

훈련 손실은 차수를 올릴수록 계속 내려간다. 검증 손실은 차수 3 근처에서 가장 낮고, 15에서 0.936으로 튀어 올랐다. 훈련 숫자만 봤다면 15차가 제일 좋은 모델로 보였을 것이다. 차수 1은 반대로 너무 단순해서 둘 다 높은데, 이쪽은 과소적합이라고 부른다.

Google 강좌도 같은 신호를 말한다. 훈련 손실은 계속 줄거나 평평한데 검증 손실이 어느 시점부터 오르면 과적합이다.

## 학습·검증·테스트

위 실험에서 검증 데이터가 없었다면 과적합을 못 알아챘을 것이다. 그래서 데이터를 보통 셋으로 나눈다.

| 데이터 | 쓰임 |
|---|---|
| 훈련(training) | 파라미터를 고치는 데 쓴다 |
| 검증(validation) | 훈련 중에 과적합인지 보고, 모델 종류·학습률 같은 선택을 하는 데 쓴다 |
| 테스트(test) | 마지막에 한 번, 실제 환경에서 얼마나 맞힐지 가늠하는 데 쓴다 |

테스트를 따로 두는 이유는 검증 데이터가 선택 과정에서 이미 "봐 버린" 데이터가 되기 때문이다. 검증 점수를 보며 여러 번 고르다 보면 모델이 검증에 슬쩍 맞춰진다. 테스트는 그런 선택에 한 번도 쓰지 않아야 값이 정직하다. 위 코드의 `te`가 그 자리이고, 이번 실험에서는 따로 쓰지 않고 비워 뒀다.

과적합을 줄이는 방법은 데이터를 늘리거나, 모델을 단순하게 하거나, 규제(파라미터가 커지는 것에 벌점을 주는 방식)를 쓰거나, 검증 손실이 오르기 시작할 때 학습을 멈추는(조기 종료) 것 등이 있다.

## 흔한 오해

- 훈련 정확도가 높으면 좋은 모델이다: 위 표처럼 훈련 손실은 복잡할수록 계속 내려간다. 봐야 하는 건 처음 보는 데이터에서의 값이다.
- 모델을 크게 만들수록 좋다: 데이터에 비해 너무 크면 과적합이 쉬워진다. 다만 대규모 LLM처럼 데이터도 엄청나게 쓰는 경우는 사정이 달라서, 이 글에서 다루는 작은 예와 그대로 겹쳐 생각하면 안 된다.
- 학습은 정답을 외우는 것이다: 외우는 건 과적합이다. 목표는 규칙(일반화)이다.
- 경사하강법은 항상 최솟값에 간다: 직선 맞추기처럼 손실 모양이 단순한(볼록한) 경우는 그렇다고 한다. 신경망처럼 복잡한 경우엔 그런 보장이 없다.
- 딥러닝은 머신러닝과 전혀 다른 것이다: 딥러닝은 머신러닝의 한 갈래다. 위의 세 부품과 데이터 분할이 그대로 적용된다.

## 이어서 볼 것

학습이 숫자 조정이라는 걸 잡고 나면 질문이 두 방향으로 갈린다. 하나는 "그 숫자를 담는 구조가 어떻게 생겼나"([자세히 → 신경망과 역전파](#/post/ml-neural-net)), 다른 하나는 "대규모 모델은 무엇을 보고 어떻게 먼저 학습하나"([자세히 → 사전학습과 RLHF](#/post/ml-pretraining))다. 이미 학습된 모델을 내 데이터로 더 맞추는 건 [자세히 → 파인튜닝](#/post/ml-finetuning)에 나온다. 글자를 숫자 벡터로 바꾸는 [자세히 → 임베딩](#/post/ai-embedding)도 같은 "숫자 조정" 위에 있다.

<details>
<summary>자세한 풀이: 경사하강법 한 스텝 손으로 계산</summary>

점 하나 `(x=2, y=5)`, 모델 `예측 = w × x`, 처음 `w = 0`, 학습률 `0.1`이라고 하자.

- 예측 = 0 × 2 = 0, 오차 = 0 − 5 = −5
- 손실 = 오차² = 25
- 손실을 w로 미분하면 `2 × 오차 × x = 2 × (−5) × 2 = −20`
- 새 w = 0 − 0.1 × (−20) = 2

기울기가 음수면 "w를 키우면 손실이 준다"는 뜻이고, 갱신식의 마이너스 부호가 w를 키우는 쪽으로 보낸다. 새 w = 2에서 예측은 4, 오차 −1로 줄었다. 한 번 더 하면 기울기는 `2 × (−1) × 2 = −4`, w = 2.4가 된다. 정답인 2.5에 가까워진다.

위 numpy 코드는 이걸 점 5개의 평균으로 하고, w와 b 둘에 대해 같이 한 것이다.
