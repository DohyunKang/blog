拡散モデル（Diffusion Model）は、画像に少しずつノイズを混ぜる過程を逆転させる手法を学習したモデルであり、画像を作成する際には純粋なノイズから始まり、それを何度もに分けて除去していく。

## まず一言で言うと

文章を書く LLM は次のトークンを一つずつ選ぶ（[詳細 → LLM](#/post/ai-llm)）。画像生成は方式が異なる。ピクセルを順番に描くのではなく、画面全体がノイズの状態から始め、「これほどノイズっぽく見えないためにはどう変えるべきか」を数十回繰り返す。反復が完了するとノイズが消え、絵が残る。

この手法を拡散（diffusion）モデルと呼ぶ。名前は物理の拡散（インクが水に広がること）から来ている。DDPM 論文の要旨も、非平衡熱力学から着想を得た潜在変数モデルであると紹介している。[生成 AI](#/post/ai-generative) の中で画像を担当する部分は、概ねこの系列である。

## 原理：壊す道と戻す道

二つの方向がある。

| | やること | 誰がやるか |
|---|---|---|
| 正方向 (noising) | 真の画像にノイズを段階的に混ぜ、最後に純粋なノイズにする | 決まった式、学習なし |
| 逆方向 (denoising) | ノイズ混じりの画像からノイズを少しずつ除去する | ニューラルネットワーク、これが学習対象 |

正方向は単なる式である。混ぜる量はスケジュール（何段階に分けてどれくらい混ぜるか）で決める。学習時は以下のように行う。

1. 学習用の画像の一つを選ぶ。
2. ステップ t を任意の一つ選ぶ。
3. そのステップ分だけノイズを混ぜた画像を作る。
4. ニューラルネットワークに「ここ混ぜたノイズは何だったか」当てさせる。正解は我々が混ぜたので既に知っている。
5. 間違えた分だけ重みを修正する。これを数百万枚の画像に対して繰り返す。

DDPM 論文の要旨によると、この学習は加重変分下界（weighted variational bound）を用いており、ノイズ除去スコアマッチングとランジュバン動力学の接続から導かれたものである。簡単に言えば、混ぜたノイズを当てる回帰問題である。

生成する際には正解画像がない。純粋なノイズから出発し、ニューラルネットワークが予測したノイズを少し引いて、また予測して、また引くことを決まった回数行う。この回数が UI で見る steps の値である。ニューラルネットワークの構造は U-Net が長く使われており、最近は [トランスフォーマー](#/post/ml-transformer) 系も使う（Hugging Face ドキュメントのモデルフォルダに unets と transformers が別々にある）。どちらも [ニューラルネットワーク](#/post/ml-neural-net) という点では同じである。

<details>
<summary>詳しい解説：正方向の式を直接動かしてみた</summary>

正方向は一度に目的のステップへ飛び越えることができる。元画像を x0、標準正規分布のノイズを eps とし、累積積 abar_t を使えば以下のようになる。

    x_t = sqrt(abar_t) * x0 + sqrt(1 - abar_t) * eps

t が大きくなるほど abar_t は 0 に近づき、元画像はほとんど残らなくなる。ニューラルネットワークが eps を正確に当てれば、上記の式を逆にして x0 を即座に復元できる。以下はこの式を 8 ビットの信号で動かしてみたものである（numpy で直接実行して確認）。スケジュールは線形（beta を 1e-4 から 0.02 まで、T=1000）に設定した。

    import numpy as np
    T = 1000
    beta = np.linspace(1e-4, 0.02, T)
    abar = np.cumprod(1 - beta)
    rng = np.random.default_rng(0)
    x0 = np.sin(np.linspace(0, 6.28, 8))
    for t in (0, 100, 500, 999):
        eps = rng.standard_normal(8)
        xt = np.sqrt(abar[t]) * x0 + np.sqrt(1 - abar[t]) * eps
        x0h = (xt - np.sqrt(1 - abar[t]) * eps) / np.sqrt(abar[t])
        print(t, round(abar[t], 4), round(float(np.abs(xt - x0).mean()), 3), float(np.abs(x0h - x0).max()))

出力は以下の通りだった（t, abar、元画像との平均差、復元誤差）。

| t | abar | 元画像との平均差 | 正しい eps で復元した誤差 |
|---|---|---|---|
| 0 | 0.9999 | 0.005 | 0 |
| 100 | 0.8951 | 0.286 | 0 |
| 500 | 0.0778 | 0.625 | 0 |
| 999 | 0.0 | 0.788 | 0 |

t=999 では元画像の成分は実質的に 0 であり、ほぼ純粋なノイズである。復元誤差が 0 ののは eps を正解として入れたためであり、実際のモデルは eps を近似でしか当てないため誤差が生じる。これは式の正しさを確認した玩具実験であり、画像モデルではない。

</details>

## 왜 잠재 공간에서 하나

픽셀 그대로 확산을 돌리면 비싸다。512x512 컬러 이미지는 값이 78 만 개가 넘고、それを数十回もニューラルネットワークに通す必要がある。Latent Diffusion 論文（Stable Diffusion の基盤）の要旨は、ピクセル空間での拡散モデルは最適化に「数百の GPU」を要し、推論も順次評価のため高価であると指摘している。その解決策は、事前学習されたオートエンコーダーの潜在空間（latent space）で拡散を行うことだ。

流れは以下の通りである。

    画像 --(エンコーダ)--> 小さな潜在表現 --(拡散：ノイズを除去する反復)--> きれいな潜在表現 --(デコーダ)--> 画像

画像を小さく圧縮した表現上でノイズを除去し、最後に一度だけデコーダでピクセルに展開する。同じ作業がはるかに小さなテンソルで行われるため計算量が減る。論文の要旨は計算要件が「相当に減少する」としか書いていない。

[埋め込み](#/post/ai-embedding)とは似たような感覚だが、用途は異なる。埋め込みは意味を比較するために作成されたベクトルであり、ここでは潜在表現は画像を復元できるように圧縮したものである。

## テキストで条件をつける

ただ動かすと何の絵も出てくる。プロンプト通りに出すためには、ニューラルネットワークにテキスト情報も同時に与える必要がある。Latent Diffusion 論文では、アーキテクチャにクロスアテンション層を追加し、テキストやバウンディングボックスなどの条件入力を受け付けるようにしたと述べている。テキストは別々のテキストエンコーダーでベクトルに変換して投入する。Hugging Face のドキュメントでは、パイプライン部品としてテキストエンコーダー、U-Net、VAE をそれぞれ個別に挙げている。文字と画像を同時に扱う話は [マルチモーダル](#/post/ai-multimodal) で続いている。

## パイプラインの部品たち

diffusers のドキュメントでは、パイプラインをモデルとスケジューラーの組み合わせとして説明している。整理すると以下の通りだ。

| 部品 | 役割 |
|---|---|
| テキストエンコーダー | プロンプトをベクトルに変換する |
| ノイズ予測モデル（U-Net など） | 現在の画像のノイズを予測する |
| スケジューラー（サンプラー） | 予測を受け取り、「一歩だけノイズが少ない」画像を計算する |
| VAE（オートエンコーダー） | 画像と潜在表現を行き来して変換する |

ドキュメントで目立つように強調されているのは、スケジューラーがモデルから分離されている点だ。スケジューラーは学習時にはノイズスケジュールを定め、推論時には step 関数で x_t を受け取り、前段階の x_(t-1) を返す。そのため同じモデルにスケジューラーだけを交換して使えるという。これが UI でサンプラーを選ぶ欄がある理由に見える。

## ComfyUI はこれらの部品をどのように提示するか

ComfyUI のドキュメントでは、自身を生成 AI 用のノードベースインターフェースかつ推論エンジンとして紹介している。ローカルデバイスで動作させられ、画像・動画・オーディオ・3D を扱えるという。ノードを線でつなぎワークフローを作成する。

上記の部品表を知っていればノードグラフが読み取れる。モデルファイルをロードするノード、プロンプトをベクトルに変換するノード、サンプリングノード（ここで steps とサンプラーを設定する）、潜在表現を画像に展開するノードが順次つながっているようなものだ。

ローカルで動かす話は [ローカルモデル](#/post/ml-local-models) と [推論](#/post/ml-inference) の記事で続ける。ステップ数はニューラルネットワークの呼び出し回数に相当するため、steps を上げると時間は比例して増える。GPU メモリはモデルサイズと解像度に左右される。

## よくある誤解

- モデルが学習画像を保存しておいて組み立てている：構造上ストレージではない。学習で残るのはノイズを予測する重みだ。
- steps を増やすほど良くなる：ある地点からは差が減り、時間だけが伸びる。
- LLM と同じ原理だ：ニューラルネットワークを使う点は同じだが、次のトークンを選ぶ方式とノイズを除去する方式是生成プロセスが異なる。
- プロンプトそのものが絵だ：同じプロンプトでも最初のノイズが異なれば別の絵が出る。シード（seed）はこの初期ノイズを固定する値だ。
