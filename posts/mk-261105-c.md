이메일 뉴스레터는 마케팅 자동화에서 가장 오래된 채널이다. 목록을 모으고, 템플릿에 내용을 채워 예약 발송하는 흐름은 스크립트로 쉽게 만든다. 어려운 쪽은 보내는 일이 아니라 받은편지함에 도착하게 하는 일이고, 여기에는 지켜야 할 요건이 정해져 있다. Google이 발신자 가이드라인에 적어 둔 내용을 기준으로 정리한다.

## 전체 흐름

1. 구독자 목록(동의받은 사람만)에서 세그먼트를 고른다.
2. 템플릿에 내용을 넣어 메시지를 만든다. 사람이 한 번 확인하는 지점을 둔다.
3. 발송 서비스(또는 SMTP)로 보낸다. 이때 도메인 인증과 헤더가 붙는다.
4. 반응(열람, 클릭, 수신 거부, 스팸 신고)을 모아 다음 발송의 대상을 정한다.

1, 2, 4는 콘텐츠 캘린더·대시보드 자동화와 같은 구조다. 3번이 이메일에만 있는 부분이다.

## 모든 발신자가 지킬 것

Google 가이드라인은 2024년 2월 1일부터 모든 발신자에게 다음을 요구한다고 적고 있다.

- 발신 도메인에 SPF 또는 DKIM 인증을 설정한다.
- Postmaster Tools에서 확인되는 스팸 신고율을 0.3% 미만으로 유지한다.
- 전송에 TLS 연결을 쓴다.
- 발신 도메인이나 IP에 정방향·역방향 DNS(PTR) 레코드가 있어야 한다.
- 메시지를 RFC 5322 형식에 맞춘다.

스팸 신고율은 요건(0.3% 미만)과 권장 목표(0.10% 미만)가 다르다. 0.30% 이상이 되는 것은 피하라고 적혀 있다.

## 대량 발신자는 더 요구한다

하루 5,000통을 넘게 보내는 발신자에게는 이 내용이 더해진다.

| 항목 | 요구 |
|---|---|
| 인증 | SPF와 DKIM에 더해 DMARC. DMARC 정책은 `none`이어도 된다 |
| 도메인 정렬 | From: 도메인이 SPF 또는 DKIM 도메인과 맞아야 한다 |
| 수신 거부 | 마케팅·구독 메시지는 원클릭 수신 거부를 지원하고, 본문에 눈에 띄는 수신 거부 링크를 둔다 |
| DKIM 키 | 개인 Gmail로 보내려면 1024비트 이상, 2048비트 권장 |

개인 뉴스레터는 하루 5,000통에 못 미치겠지만, 모든 발신자 요건(SPF 또는 DKIM, 스팸 신고율)은 그대로 적용된다.

## 원클릭 수신 거부는 헤더로 구현한다

원클릭 수신 거부는 RFC 8058이 정한 방식이다. 메시지에 헤더 두 개를 넣는다.

```
List-Unsubscribe: <https://example.com/u/abc123>
List-Unsubscribe-Post: List-Unsubscribe=One-Click
```

받는 쪽 메일 서비스는 사용자가 수신 거부 버튼을 누르면 `List-Unsubscribe`의 HTTPS 주소로 POST 요청을 보낸다. 본문은 `List-Unsubscribe=One-Click`이다. 그러니 발송 쪽에는 이 주소를 받아 해당 구독자를 목록에서 빼는 엔드포인트가 필요하다.

RFC 8058에 적힌 조건은 몇 가지 더 있다.

- 메시지에 유효한 DKIM 서명이 하나 이상 있어야 하고, 서명이 두 헤더를 모두 덮어야(`h=` 태그에 포함) 한다. 서명이 없으면 받는 쪽은 원클릭 수신 거부를 제공하지 않아야 한다.
- URI에는 위조하기 어려운 값이 들어가야 하고 서버가 그것을 검증해야 한다.
- 이 POST에 HTTPS 리다이렉트로 응답하면 안 된다.

<details>
<summary>파이썬으로 헤더 붙여 보기 (직접 실행해 확인)</summary>

표준 라이브러리 `email`로 메시지를 만들고 두 헤더를 붙인 것이다. 출력에 두 헤더가 그대로 나오는 것까지 확인했다. 실제 발송과 DKIM 서명은 이 코드에 없다. 서명은 발송 서비스나 메일 서버 쪽에서 붙이는 단계다.

```python
from email.message import EmailMessage

m = EmailMessage()
m["From"] = "news@example.com"
m["To"] = "reader@example.org"
m["Subject"] = "weekly"
m["List-Unsubscribe"] = "<https://example.com/u/abc123>"
m["List-Unsubscribe-Post"] = "List-Unsubscribe=One-Click"
m.set_content("hello")
print(m.as_string())
```

## 자동화할 때 놓치기 쉬운 것

- 수신 거부 처리를 나중으로 미루면 스팸 신고율이 올라갈 수 있다. 신고율 한도가 있으니 수신 거부 엔드포인트를 먼저 만든다.
- 도메인 인증(SPF·DKIM·DMARC)은 DNS 설정이라 코드 밖에서 한 번 해 두는 일이다. 파이프라인에는 "인증 통과 확인" 단계 정도만 둔다.
- 전체 목록에 한 번에 나가는 구조 대신 소수에게 먼저 보내 신고율을 보는 단계를 두는 방법도 있다. 위 문서에 나온 내용은 아니고 운영 방식의 한 예다.

AI를 쓴다면 제목·본문 초안과 세그먼트별 문구 변형 정도가 들어갈 자리다. 발송 대상과 최종 확인은 사람이 맡는 편이 안전하다.
