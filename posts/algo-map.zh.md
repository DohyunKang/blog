看代码测试题时，往往从“这是什么类型”就开始卡壳。因此，我按题型整理了十篇算法文章，每篇只写了一行总结。首先根据复杂度判断能否在时限内通过，随后按照“数据结构 → 搜索 → 图论 → 优化”的顺序进行了分类。详细的解题思路和代码都在对应的文章中。

## 看题后选择的顺序

| 题目中显现的特征 | 首先想到的题型 |
|---|---|
| 输入规模很大，双重循环会导致超时 | 估算复杂度 → 哈希、前缀和、双指针 |
| “是否已见过该值”、计数 | 哈希 |
| 连续区间的和或长度 | 前缀和、双指针、滑动窗口 |
| 括号匹配、“右侧第一个更大的数”、顺序处理 | 栈·队列 |
| 在排序数据中查找，“最大能到多少” | 二分查找，参数化搜索 |
| 尝试所有情况但卡住时回溯 | 递归·回溯 |
| 由格子、点或边连接而成的结构 | BFS·DFS |
| 边带有权重、合并同类项、处理先后关系 | 迪杰斯特拉 (Dijkstra)、并查集 (Union-Find)、拓扑排序 |
| 复用子问题的答案 | 动态规划 (DP) |
| 似乎每次只需选择最优解 | 贪心 (需验证反例) |
| 反复取出最小（或最大）的元素 | 堆·优先级队列 |

## 1. 基础：复杂度

**时间复杂度与 Python 基础**：仅凭输入规模判断“该解法能否在时限内通过”的方法，Python 中常见的性能瓶颈点，以及代码测试用的基本输入输出。
[详情 → 时间复杂度与 Python 基础](#/post/algo-complexity)

## 2. 用数据结构解决的题型

**数组·字符串·哈希**：这类题型的关键在于不要重复计数，而是一次性统计并记录下来。记录的位置通常是前缀和数组或哈希表（dict, set）。
[详情 → 数组·字符串·哈希](#/post/algo-array-hash)

**栈·队列·双端队列**：区别在于是取出最后放入的元素，还是先放入的元素。括号检查、下一个更大元素、旋转卡片等问题都属于此类。在 Python 中，只需区分列表和 deque 即可解决大部分问题。
[详情 → 栈·队列·双端队列](#/post/algo-stack-queue)

**树·堆·优先级队列**：关于树的问题，能否直接用代码写出遍历顺序是解题的关键之一；而堆则用于需要不断取出最小（或最大）元素的问题，通常使用 `heapq` 解决。
[详情 → 树·堆·优先级队列](#/post/algo-tree-heap)

## 3. 缩小范围的题型

**双指针·滑动窗口·前缀和**：在连续区间问题中，这三种方法通过只移动右边界而不重复累加区间，将复杂度降至 O(N)。
[详情 → 双指针·滑动窗口·前缀和](#/post/algo-two-pointer)

**排序与二分查找**：排序几乎总是以 `sorted()` 结尾；需要练习的是在已排序数据中每次舍弃一半的二分查找，以及直接对答案进行二分搜索的参数化搜索。
[详情 → 排序与二分查找](#/post/algo-sort-search)

## 4. 遍历情况的题型

**递归与回溯**：递归是将大问题转化为更小的同类问题；回溯则是通过递归尝试每一个选项，遇到死路时回退的搜索方式。排列、组合和 N-Queens 是典型问题。
[详情 → 递归与回溯](#/post/algo-recursion)

**BFS·DFS 与图论**：两者的区别仅在于将下一个待访问节点存入队列还是栈。连通分量、迷宫最短路径、区域大小等网格问题均可用同一框架解决。
[详情 → BFS·DFS 与图论](#/post/algo-graph-search)

**最短路径·并查集·拓扑排序**：这是基于 BFS/DFS 之上常见的三种题型。带权重的寻路（迪杰斯特拉）、合并同类项（并查集）、确定先后顺序（拓扑排序）。
[详情 → 最短路径·并查集·拓扑排序](#/post/algo-shortest-path)

## 5. 优化答案的题型

**动态规划 (DP)**：这是一种记录答案以避免重复解决相同子问题的方法。只要建立递推式，代码自然迎刃而解。涵盖背包问题、最长上升子序列 (LIS)、硬币问题等。
[详情 → 动态规划 (DP)](#/post/algo-dp)

**贪心**：这是一种在每一步都选择当前看似最优且不再回溯的方式。区分适用该方法的题目与不适用题目的关键在于验证反例，因此也会一并讨论。
[详情 → 贪心](#/post/algo-greedy)

## 学习顺序建议

建议在掌握复杂度概念后，按以下顺序学习：数据结构（哈希、栈·队列）→ 二分查找·双指针 → 递归·BFS·DFS → DP·贪心。这样前面的内容会成为后面内容的铺垫。迪杰斯特拉和堆最好在学完图论和数据结构之后再接触，会更容易理解。
