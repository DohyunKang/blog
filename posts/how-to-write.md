## 새 글 올리기

1. `posts/` 폴더에 `글이름.md` 파일을 만들고 마크다운으로 씁니다.
2. `posts/index.json` 맨 위에 한 줄 추가합니다.

```json
{"slug":"글이름","title":"제목","date":"2026-10-23","tags":["태그"],"summary":"한 줄 요약"}
```

3. `git add -A && git commit -m "새 글" && git push` — 1분쯤 뒤 사이트에 보입니다.

> 코드 블록, 표, 인용, 이미지(`![설명](주소)`)가 모두 됩니다.
